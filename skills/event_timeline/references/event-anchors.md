# 事件锚点

本页帮助确认「是不是同一件事」。判定三档不在这里重写。

## 事件身份

- 发布:同一次发布才可对照。后续另一款产品的发布不是这次发布的改写。
- 监管口径:同一条口径的原文改口,才是该前提被推翻。相邻话题的新表态单独成主张。
- 访谈改口:同一场访谈或同一口头口径的后续文本,才用来对照。另一位受访者的话不是这一场的改口。

## 快照

- T0 是签发时快照,T1 是复验时快照。
- T0 里事件仍成立、T1 里同一事件被改写或删除,这是快照取代。
- 日历日经过、有效期字段空白,都不单独构成推翻。

## 缺口

- 「未复测」「无新测量」「不再列入跟踪」记录的是覆盖不足。
- 覆盖不足走缺口,不把原事件写成已被撤回。
