# 怎么读 patch diff

本页说明正文差和复验证据各管什么。它不写入事件账。

## 两个字段

- before_text 是改前主张正文。
- after_text 是改后主张正文。
- 两侧都要能逐行读完。空的一侧就是没有行,计数为零,不是另一套状态。

## 行差

- 只在 before_text 出现的行,是改前有、改后无。
- 只在 after_text 出现的行,是改后新增。
- 行差回答「字面变了什么」。它不回答「T1 是否仍支持」。

## 与账本的分界

- 人确认之前,草案留在草案。未确认文本不进入正式事件账。
- 正式账上的 before_text / after_text 只供审计对照。
- 复验引用的是 T1 原文里的 evidence_id,不是 diff 的行号。
