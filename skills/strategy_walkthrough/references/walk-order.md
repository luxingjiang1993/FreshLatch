# 策略走查顺序

本页把发前走查收成固定顺序。它不新增判定档。

## 顺序

1. 读已签发主张,按前提拆开。窗口、成本、定价、口径各算各的。
2. 在 T1 快照检索同维段落,必要时读原文。
3. 每个前提都有 T1 原句支持,才走到 fresh。
4. 同维原句明确推翻某个前提,才走到 stale,并写明因果句。
5. 有前提没有 T1 覆盖,走到 unknown,并记下缺口。
6. 结束走查。不在文末追加进入或不进入。

## 与包结论的分界

- 单条主张的结果仍是 fresh、stale、unknown。
- 可发、需补丁、勿发是报告级聚合,由产品既有规则汇总。
- 本页不把聚合结果写回单条主张的状态。
