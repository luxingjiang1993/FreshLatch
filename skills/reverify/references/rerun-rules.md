# 重跑与名单约束(Lead 侧)

## 作废名单(invalidation list)

- 被人工作废的主张是终态;你重跑时**不得**把它改回 fresh——规则闸按名单机械打回,你的工具调用只会计步。
- 名单的存储真相是 SQLite `invalidation_list` 表,随课题持久;你每轮会话启动时会在系统提示里看到它的当前内容。
- 认为某条作废有误?那是 HumanLatch 的人审决定,由人撤销,不经你的工具。

## 隔离名单(quarantine)

- 记忆条目被人移出召回集后进入隔离;W9 起与本课题相关。W1–W4 隔离名单恒为空,见到非空名单说明记忆卫生模块已上线,届时以新工单的人格为准。

## 续命为什么必须带新 T1 evidence_id

- 「续命」= 人对一条黄灯主张确认继续有效。它能成立的唯一依据是**复验时刻**的原文,不是签发时的旧证据——旧证据只能证明「曾经为真」。
- 因此续命携带的 evidence_id 必须锚 T1 且过规则闸;checksum 对不上同样不得续命(W5 起 checksum 启用)。
