# 记忆条目 schema 与三标记操作定义

## 条目字段

| 字段 | 含义 |
|---|---|
| `entry_id` | 条目唯一 id |
| `content` | 记忆正文(一条一个事实,不堆叠) |
| `source_ref` | 出处指针(doc_id / 会话 / 人审记录);**缺失即不可核**,与内容真假无关 |
| `recorded_at` | 录入时间 |
| `status` | active(在召回集)/ quarantined(已隔离)/ void(随主张作废) |

## 三标记操作定义

- **dead(死事实)**:条目依赖的前提已被推翻(如旧价格、旧监管口径),或条目所属主张已进入作废名单。判据与复验的 stale 同构,但作用于记忆层。
- **contradictory(互斥)**:与同课题另一条 active 记忆在同一维度给出不可并存的表述(如 99 美元 vs 79 美元同为「当前报价」)。需要两条 entry_id 一起记录。
- **unverified(不可核)**:无 `source_ref` 或出处不可回溯。**不可核 ≠ 假**;它只是不能继续无条件服务复验。

## 隔离语义

- 隔离 = 移出召回集(reversible),不是删除(不可逆);条目留盘,可随时回滚。
- `propose_quarantine` 只是提案;人确认前条目仍是 active。
- 作废(void)随主张走:主张被人作废后,其衍生的记忆条目一并标 void,由 HumanLatch 闭环触发。
