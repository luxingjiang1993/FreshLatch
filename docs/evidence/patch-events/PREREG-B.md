## 固定 k 选取（R · 已锁）

主指标仍是固定放行率下的误放率（false-accept rate）。放行率对齐用 T 的自然放行数：

- **k** := T 的自然放行条数。  
- **k < 10**：不得激活冲甲正式主跑；不得称冲甲主张。  
- 对臂 ∈ {C, T, B1, B2}：令该臂自然放行集为决策为放行的候选集合，大小为 m。  
  - **m ≥ k**：在该集合内按 `claim_id` **升序**取前 k 条，作为固定 k 集合。  
  - **m < k**：该臂固定 k 误放率 = **无定义**；依赖该臂的主比较不得「成立」。  
- 主比较**不再**对 T/B1/B2 使用「全体候选上按 score / 空分后 claim_id 取 top-k」。  
- 主比较**不再**对 C 使用旧页 `coverage_c` 从全体候选随机抽 k。  
- 禁止用 `construction_gold`、评委标签、用户裁决构造 score 或选取。  
- 本期不启用 S / S+R。

## 主比较与成立（不放宽）

顺序写死：T 对 C → T 对 B1 → T 对 B2。  
配对差 = 对照的误放率 − T 的误放率。  
一条比较成立，当且仅当：点估计 > 0，且 95% bootstrap 区间下界 > 0。无定义不是成立。

统计：配对 bootstrap **10000** 次；单位候选 id；种子 **20261007**；流名 **`bootstrap`**。95% 区间线性插值百分位。误拒率等只报告，不参与成立。

结果表三条 false-accept 与 k **只抄**同一次 `compare_primary` 输出。成立格不得手填。
