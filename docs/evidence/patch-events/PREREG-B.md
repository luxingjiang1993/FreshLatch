## 构造算子

正确修改：改完的事实与所绑 T1 chunk 一致，evidence id 指向该 chunk。

- 数值：换成该 T1 chunk 里同一指标、同一对象的数字。
- 日期：换成该 T1 chunk 里同一事件的日期。
- 条款替换：换成该 T1 chunk 里同一义务主体的对应条款表述。
- 删除：删掉该 T1 chunk 已经写明废止或不再存在的限定。

坏修改：表面像一次更新，但与证据矛盾，或证据不能支撑。层内坏槽按出现顺序从 0 编号，算子 = 编号 mod 4。符号由编号 // 4 决定：偶数用加号或放大，奇数用减号或缩小。扰动结果若与正确值相同，该槽作废，不另选算子。

数值：

0. 正确数字 ±10% 后取整。原数是整数则取整数，否则保留两位小数。0.5 远离 0。
1. 正确数字 ×10 或 ÷10。
2. 换成同一 chunk 里另一个不同的数字。chunk 里少于两个不同数字则该槽作废。
3. 保留正确数字，单位在 `%`、`个百分点`、`元`、`万元` 中换成下一项（循环）。换完与原文相同则该槽作废。

日期：

0. 正确日期的年份 ±1。
1. 正确日期的月份 ±1，跨年则进位。
2. 换成同一文档里另一个不同的日期。没有则该槽作废。
3. 日期文本用正确值，evidence id 改指同一文档的 T0 chunk。没有 T0 则该槽作废。

条款替换：

0. 义务方向对调：`应当` 与 `不得` 对调。两者都没有时，在主要动词上加上或去掉 `不`。文本没有变化则该槽作废。
1. 义务主体换成同一文档里点名的另一个主体。没有则该槽作废。
2. 换成同一文档里另一条条款。没有则该槽作废。
3. 条款文本用正确值，evidence id 改指文档顺序中的下一块，且那一块不含该条款。下一块仍含该条款则该槽作废。

删除：

0. 删掉 T1 仍然肯定的限定。
1. 删掉例外或谓语，使主张范围变大，且所绑证据不支持这个放大。
2. 删除文本与正确删除相同，但 evidence id 为空。
3. 只删一个不改变金标事实的修饰，并在修改说明里写「按新证据必须更新」。

## 实验组

四组吃同一批候选。生成侧若要调用模型，只用本仓 `DEFAULT_MODEL`，即 `qwen-flash`。不得为了本实验改这个默认值，也不得改草稿解码预锁。温度或种子缺省则该次生成作废，不许事后补填。

| 组 | 做法 |
|---|---|
| C | 无证据改写。不绑定 chunk，不跑自动核验，不 hard reject。生成成功即自然放行。 |
| T | attested patch，fail-closed。与 B1 **共用同一份** rewrite `after_text`（同 after 再分叉）。修改必须绑定 chunk 级证据，且 evidence id 属于本次已入库 T1；自动核验不过则 hard reject，不写回。 |
| B1 | post-hoc verify。先改后验，RARR 式。与 T **共用同一份** rewrite `after_text` 后，**不**跑已入库 T1 绑定闸；核验发生在该 after 之上。核验不过则拒绝。不得把这种拒绝记成 T。禁止把 B1 做成核验失败仍放行或更弱核验来凑 T−B1 差。 |
| B2 | KPR 式 claim → diff。先从主张得到 claim，再生成 diff。核验不过不自动 hard reject。 |

**同 after 再分叉（激活前修订 · 可执行）**：对同一 `claim_id`，T 与 B1 先得到同一 `after_text`（及同一候选 `evidence_id` 字段），再分别决策。T：绑定 ∧ 核验 ok → release。B1：仅核验 ok → release。两边核验函数与「不过则 hard reject」同构；差异只在绑定闸。分臂独立生成、靠提示噪声拉开集合，**不是**本页承认的 T/B1 对照定义。

**抬 T 自然放行（k）**：主杠杆是降低正确样在 T 上的核验假阴性（生成更常与 `evidence_text` 一致）。禁止靠放松 T 的 hard reject / 逐字核验 / 绑定闸把 T 做成 B1 来凑 k≥10。禁止无限加 n 或夹具伪抬 k。

主实验里 T 的检索只读生产常量：`PRODUCTION_RETRIEVAL_MODE = "hybrid+rerank"`。本实验不改这一行。

消融只在 T 上做，不进入主比较顺序。四项都要报，任一单项不得改写主比较的判决：

- 拿掉 chunk 绑定
- 拿掉自动核验
- hard reject 换成 soft warning
- 检索臂在脚本里换成 BM25，另记一列 hybrid+rerank。生产赋值不动。主臂已经是 hybrid+rerank 时，这一列与主臂相同，仍单独记账。

## 指标

放行率 = 放行数 / 候选数。

误放率 = 放行且构造金标为坏的条数 / 放行数。放行数为 0 时无定义，禁止记成 0。

误拒率 = 构造金标为正确且被拒绝的条数 / 构造金标为正确的条数。

错改率 = 放行且构造金标为坏的条数 / 候选数。它是全体上的坏放行比例，不是放行集里的风险。

可复验率 = 放行样本中，evidence id 非空、能解析到本次已入库 T1 chunk、且有再验记录的条数 / 放行数。放行数为 0 时无定义。

延迟：每条候选从输入到放行或拒绝的 wall time，报中位数和 p95。不含模型加载。

成本：该臂若调用付费 API，按当次 token 与单价记账；没有调用则记 0，并写明没有调用。单价记账单上的数字，不在本页预填。

主指标是固定放行率下的误放率（edit-level risk-coverage）。误拒率必须同时报。错改率、可复验率、延迟、成本都报，但不参与「成立」。各臂自己的自然放行率另报，不替代主指标。

## 固定 k 选取（R · 已锁）

固定放行率用 T 的自然放行数 k。k = 0 时，固定放行率上的误放率无定义，主比较不成立。

- **k** := T 的自然放行条数。  
- **k < 10**：不得激活冲甲正式主跑；不得称冲甲主张。  
- 对臂 ∈ {C, T, B1, B2}：令该臂自然放行集为决策为放行的候选集合，大小为 m。  
  - **m ≥ k**：在该集合内按 `claim_id` **升序**取前 k 条，作为固定 k 集合。  
  - **m < k**：该臂固定 k 误放率 = **无定义**；依赖该臂的主比较不得「成立」。  
- 主比较**不再**对 T/B1/B2 使用「全体候选上按 score / 空分后 claim_id 取 top-k」。  
- 主比较**不再**对 C 使用旧页 `coverage_c` 从全体候选随机抽 k。  
- 禁止用 `construction_gold`、评委标签、用户裁决构造 score 或选取。  
- 本期不启用 S / S+R。  
- `score` 字段可继续为空；高分不代表放行也不代表拒绝（继承补定纪律）。放行只使用已经写好的 `decision`。

## 主比较与成立（不放宽）

比较顺序写死，一次只推进到下一条：

1. 第一主比较：T 对 C 的误放率。
2. 第二：T 对 B1 的误放率。
3. 第三：T 对 B2 的误放率。

配对差 = 对照的误放率 − T 的误放率。正值表示 T 更低。

一条比较成立，当且仅当：点估计 > 0，且 95% bootstrap 区间下界 > 0。下界 ≤ 0 或点估计 ≤ 0，该条不成立。无定义不是成立。

统计：配对 bootstrap **10000** 次。单位是候选 id。每次有放回抽取与原样本等长的 id，两组用同一批 id 重算指标（重算时的固定 k 集合必须仍按本页 R 规则，在重抽样后的自然放行集上取）。95% 区间用线性插值百分位。

名为 `bootstrap` 的 `random.Random(20261007)` 单独一条，按比较顺序消耗。每个比较内部的指标顺序是：误放率、误拒率、错改率、可复验率。每个指标 10000 次。误拒率及以后的区间只报告，不参与「成立」。某次重抽样导致某臂固定 k 集合无定义（含 m<k 或放行数为 0），该次误放率或可复验率丢弃，不填 0。丢弃比例超过 5% 时，该指标无定义。

延迟和成本不进这条 bootstrap。

消融放在三条主比较之后，用各自的自然规则报告，不占用 `bootstrap` 这条随机流的前三个比较。消融若要区间，另起一条 `random.Random(20261007)`，名字是 `bootstrap_ablation`。

结果表三条 false-accept 与 k **只抄**同一次 `compare_primary`（R）输出。成立格不得手填。
