## 规则声明（与 PREREG-B · R 一致）

照抄预注册有效条款，本报告不另定选取：

- **k** := T 的自然放行条数。
- 对臂 ∈ {C, T, B1, B2}：自然放行集 = `decision == "release"` 的候选集合，大小为 m。
  - **m ≥ k**：集内按 `claim_id` **升序**取前 k，作为固定 k 集合。
  - **m < k**：该臂固定 k 误放率 = **无定义**。
- 主比较**不再**对 T/B1/B2 使用「全体候选上空分后 claim_id top-k」。
- 禁止用 `construction_gold`、评委标签、用户裁决构造 score 或选取；`score` 可空。
- 配对差 = 对照臂固定 k 误放率 − T 固定 k 误放率；**正值表示 T 更低**（方向为正）。
- 误放率 = 放行且构造金标为坏的条数 / 放行数；放行数为 0 时无定义，禁止记成 0。

过门须**同时**满足（`PREREG-B` 门闩节）：

1. T 相对 B1 的固定 k 误放差方向为正；
2. T 相对 B2 的固定 k 误放差方向为正；
3. T 的 k ≥ 10。
