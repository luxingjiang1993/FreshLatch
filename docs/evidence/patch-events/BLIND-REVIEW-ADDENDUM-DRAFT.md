## 4. 盲态与独立（必须写进定稿）

1. **双人盲**：审阅材料经去臂标签导出；材料内不得出现 arm / condition / system / T|C|B1|B2 等可识别组别字段。  
2. **独立提交**：两名真人在互不可见答案的窗口内各自完成；先交者不得因后交者改判。  
3. **与用户抽检的关系**：用户单人抽检（`spotcheck`）仍按 `PREREG-B` / 旧页规则服务冲突裁决与一致率；**不**算作本附加的两名真人之一。  
4. **与模型评委的关系**：三家 API 评委协议不变；本附加不替换评委、不进 Fleiss' κ、不改 κ 算法。定稿后可另报：两名真人两两一致率 / κ，以及（可选）真人相对评委最终标签的一致率——**均不回写主成立格**。
