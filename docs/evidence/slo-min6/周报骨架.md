# FreshLatch · 生产观测最小 6 SLI · 周报骨架

> **生产观测 ≠ 乙尺。**  
> **≠模型变好 / ≠验收绿灯**（ADR-0023）。override rate 不作验收绿灯。  
> unknown / abstain 与 fresh / stale 三分并存。拒识算能力，不是失败。装绿违例只作既有硬闸指针，无证不得填 0。禁止把 abstention 重标成 false-accept / false-reject。  
> 本骨架未编辑 `RESULT-Y` / `PREREG-Y` / SESOI。  
> 填表只写本文件或当周副本。禁止把数字回写路线 Y 的成立格。  
> 成员定义以 [`docs/ops/生产观测最小6-索引.md`](../../ops/生产观测最小6-索引.md) 为准。  
> SLI 1·2 成对格的填法以 [`docs/ops/抽检-放行误放误拒.md`](../../ops/抽检-放行误放误拒.md) 为准（#558）。SLI 3 的填法以 [`docs/ops/判定-unknown三分协议.md`](../../ops/判定-unknown三分协议.md) 为准（#560）。SLI 4 的填法以 [`docs/ops/人审-override周报.md`](../../ops/人审-override周报.md) 为准（#559）。本文件仍不填比率、不填假数字。T5–T6 的格子保持空骨架。

## unknown / abstention（SLI 3 · 同一 window · 与 fresh/stale 三分并存）
| 字段 | 填写 |
| window | <起止 · Asia/Shanghai> · fresh / stale / unknown 同一窗 |
| fresh_n | 落档 fresh 条数；无数字时留空，禁止编造 |
| stale_n | 落档 stale 条数；无数字时留空，禁止编造 |
| unknown_n | 显式 unknown/abstain 条数；拒识算能力，不是失败分子 |
| N_exit | 分母 = fresh_n + stale_n + unknown_n；0 或窗口不可划定则三格占比写「样本不足」，禁止写 0% |
| unknown/abstain 占比 | unknown_n / N_exit；不足则「样本不足」。分母大于 0 且确实数到 0 时写 0/N_exit，notes 写明这不是失败率，也不是装绿已清零 |
| fresh 占比 / stale 占比 | 同窗并列；禁止只报 unknown 或只报 fresh |
| 装绿违例 | 指针：既有硬闸（无证不得 fresh、unknown 不得绿灯、D3 无 T1 绿灯目标 0、C5 自红转绿目标 0）。未计数写「未计」，禁止无证填 0。目标句：目标 0（硬闸指针） |
| notes | 禁把 abstention 重标成 false-accept / false-reject；禁把 unknown 压进 B2/B3 分母；不新建平行失败三分；不回写 Y |
