## 放行闸

能说的只有预注册主比较的结论。数字只抄 `docs/evidence/patch-events/RESULT.md` 里同一次 `compare_primary`。

- 固定放行数 k=3。k 是 T 的自然放行数。各臂表里的自然放行数四格仍是「未填」，念的时候用 k，不把那四格补上。
- T 对 C：点估计 0.3333333333333334，95% 区间 -1 到 1，不成立。
- T 对 B1：点估计 0，区间 0 到 0，不成立。
- T 对 B2：点估计 0，区间 0 到 0，不成立。
- 成立只有点估计大于 0 且区间下界大于 0。这三条都不成立。
- 因此不能说 T 更好。T 对 C 的点估计大于 0，只说明样本差的方向；区间下界不是大于 0，预注册不算成立。T 对 B1、T 对 B2 的差是 0，没有证明误放更少。
- 论文若写主结论，只能写：在这 30 条上，预注册没有证明 T 的固定放行 false-accept 低于 C、B1 或 B2。`PREREG.md` 写明 n=30 的区间只描述这 30 条的重抽样噪声，不写成总体结论。

不能写进主结论的，结果表里仍是「未填」或「未做」：误拒率、错改率、可复验率、消融、延迟、成本、抽检一致率、用户对评委的 Cohen's κ、共形预留 false-accept rate 上界。三家评委之间已经写入的 Cohen's κ 和 Fleiss' κ 不是这些空格。

放行闸金标是跑前写死的构造标。身份常量是「模型评委加单人抽检」。不能写成两名真人盲审。

已保存的生成记录没有种子。不能说原请求带了 seed 20261007。补定 draft 不是预注册原文。

「过期、冲突、或没有已入库 T1 的主张不能保持绿」是产品机制，不是这次 n=30 证明的统计优势。改写和证据绑定补丁仍是冒烟，没有论文级效果数。n=100 和两名真人盲审都还没做。Docker 也在这篇之后。
