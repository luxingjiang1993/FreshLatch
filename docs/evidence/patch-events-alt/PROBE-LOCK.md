## 主表指标（D1）

各臂报告：

- 自然放行率 = 放行数 / 候选数  
- 自然误放率 = 放行且构造金标为坏的条数 / 放行数；放行数为 0 时无定义，禁止记成 0  

T 相对 B1′、相对 B2：报告自然误放差方向。必须同时看 T 自然放行率，防止「全拒装干净」。

固定 k 误放只进附录，不进升级闸。
