## 一行一个字段

```text
| 字段 | 单位（钉死） | 数值 | 分母 | 备注 |
| token_in | token | <未填 / 未计 / 样本不足> | n_usage=<未填> | 不进 SLI 5 第三格；不抄 cost.json |
| token_out | token | <未填 / 未计 / 样本不足> | 同上 | |
| token_total | token | <未填 / 未计 / 样本不足> | 同上 | 入出都是整数时等于二者之和；不是 CNY，不是 gpu_s |
| api_cny | CNY | <未填 / 未计 / 样本不足> | n_bill=<未填> | 无账单写未计；不乘估价常数 |
| gpu_s | gpu_s | <未填 / 未计 / 样本不足> | n_gpu=<未填> | 无计量写未计；cuda:false 不是 0 |
```

单位列只填 `token`、`CNY`、`gpu_s`。不要填 `ms`、`s`、`bytes`、`kb`、`USD`。

`n_usage`、`n_bill`、`n_gpu` 没有当周账时留空。禁止编造 0 来表示「没测到」。没测到写「未计」或「样本不足」，句式抄 [`docs/ops/成本周报.md`](../../ops/成本周报.md) §4。

摘要进周报附录 P5 行，不进 min-6 的 SLI 5 格。
