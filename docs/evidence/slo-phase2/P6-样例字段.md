## 一行一个信号

```text
| 信号 | 字段 | 数值 | 分母 | 备注 |
| confirm后回改 | post_confirm_edit | <未填 / 未计 / 样本不足> | n_confirm=<未填> | 不进生产 score；草案与 arm=C 不进 |
| 重开 | reopen | <未填 / 未计 / 样本不足 / 分列不一致> | n_void_eligible=<未填> | 计 rerun_log；不是新动词 |
| latch再审 | latch_rereview | <未填 / 未计 / 样本不足> | n_latched=<未填> | 序列未计；不写入 c2_rate |
| 补丁回滚迹象 | patch_rollback_sign | <未填 / 未计 / 样本不足> | n_confirm=<未填> | 迹象 ≠ 回滚动词；与回改不互减 |
| 未列信号 | — | 未计 | — | 禁止写成 0 |
```

`n_confirm`、`n_void_eligible`、`n_latched` 没有当周账时留空。禁止编造 0 来表示「没读到」。没读到写「未计」。分母读到且为 0 时写「样本不足」。句式抄 [`docs/ops/弱信号Watch.md`](../../ops/弱信号Watch.md) §5。
