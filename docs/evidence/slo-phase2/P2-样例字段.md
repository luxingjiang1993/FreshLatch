## 一行一条

```text
| sample_id | claim_id | window | fail_bucket | err_kind | gold_or_human | machine_status | package_disp | layer | trajectory_ptr | evidence_md | runnable | ts | actor | notes |
| <id> | <id> | <起止 · Asia/Shanghai> | <找不到|找错|没用上> | <漏拦|误拦> | <gold|human> | <只读 status> | <可发|需补丁|勿发|空> | 观测/Watch · 离线评测标签 | <路径或空> | <路径或空> | <true|replay_trace_only|空> | <时间> | <人> | ADR-0028 ≠ fresh/stale/unknown；不进 rule_gate |
```

`fail_bucket` 只填找不到、找错、没用上之一。`err_kind` 只填漏拦或误拦之一。`machine_status` 只读抄录既有 `status`。`package_disp` 只读抄录可发 / 需补丁 / 勿发，或不填。`gold_or_human` 留在本表，不进生产 score。

写不进三桶的行不要加第四列。备注写「未归桶」，并且该行不进 `n_fail`。

## 交叉计数（2×3 · 不是第四桶）

六格之和应等于 `n_fail`。`n_fail` 为 0 时，六格都写「样本不足」，禁止写 0% 或 0。摘要进周报附录 P2 行，不进 min-6 主行，不进 SLI 3。

```text
|  | 找不到 | 找错 | 没用上 |
| 漏拦 | … / 样本不足 | … / 样本不足 | … / 样本不足 |
| 误拦 | … / 样本不足 | … / 样本不足 | … / 样本不足 |
| n_fail | 失败样本 n_fail=… · 每条恰一桶 |  |  |
```
