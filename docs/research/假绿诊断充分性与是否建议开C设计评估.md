## §拍板 + 逐项子决策

**拍板:D1-(a) + D2-(a) + D3-(A→C) + D4-(2) + D5-(b) + D6-(a) + D7-(ii)。**

3. **下一动作 = 诚实收口 A + 弱建议他日 C**:
   - **A**:本预登记仪器下对照不成立(全 unknown)为合法负结果;诊断闭合;不追绿、不软化。
   - **弱建议 C**:他日若仍要测假绿基线能否打出,须**另开努力 + 新预登记**;C 须处理「现在是否仍然成立 + 仅 T0 → 弃权」的构念张力;不得用本次 0/4 校准 C 的通过线;本票**不写** C 预登记、**不跑** C。
4. **唯一可摘引句**(诊断层,锁定):
   > 假绿全 unknown 诊断（qwen-flash，temp=0.0，seed=None，n=1，同一预登记仪器；原料为两次有效跑）仅表明 must_stale 假绿 0/4 全 unknown 与「现在是否仍然成立 + 仅 T0 短摘录 → 系统性弃权」假说相容，且已排除矛盾 prompt / unparseable / 全局只 unknown /（当前库路径）空摘录；不是对照成立，不是仪器已证明产品无假绿，也不是可放宽 4/4 alive，也不是一期评测闭合。

## §面试讲法(grilling 预案)

**Q:全 unknown 的原因搞清楚了吗?**
A:仪器故障类假说(矛盾 prompt、unparseable、全局只 unknown、当前库空摘录等)已排除。最贴合的开放解释是预登记已预见的构念弃权(「现在仍成立」+ 仅 T0)。这是诊断充分,不是因果法庭结案。

**Q:为什么不再做换模型/改温度探针?**
A:那些读数不能引用为对照成立/不成立,且 temp=0 冒烟探针不能当确认。本图 Destination 是诊断+建议,不是探针实验;配额 0。

**Q:要不要开新仪器 C?**
A:本图停在诚实收口 A。弱建议:他日若还要测假绿基线能否打出,另开努力并新预登记,且须面对「现在仍成立 → 弃权」张力;不得用这次 0/4 校准通过线。本票不写不跑 C。

**Q:诊断是不是证明产品没有假绿?**
A:不是。唯一可引用句是评估里的「仅表明」长句;显式排除「仪器已证明产品无假绿」。

**Q:能不能改 4/4 或开第二份预登记?**
A:不能。见格子后改线 = HARKing(ADR-0007)。同预登记追跑配额已在 #68 用尽。

**Q:为什么不新开 ADR?**
A:难反转纪律已在 ADR-0007;对照不成立收口在 #56;本票只锁诊断停规、0 探针与 A→C 建议分层。
