## 2. 框架使用地图(已验证)

- **LangGraph 1.0.x**:多处在用(StateGraph/ToolNode/bind_tools)。**⚠️ 全库无 checkpointer/MemorySaver/interrupt()/Command(resume) 用法**——需新写(→ 研究工单)。最接近替代:project 多agent 的 blocked_for_human 门闩、OpenManus ask_human。
- **LangChain 1.x**:结构化输出、FAISS/DashScope embeddings、EnsembleRetriever。
- **Agently 4.1.4.x**:03–07、09、11–17 课主力。
- **原生 OpenAI 兼容 chat.completions+tools**:06课、OpenManus、RAG-cy。
- **MCP**:FastMCP 3.1/3.4.7(08/09/11/17课)、mcp 1.7.1(CASE-MCP)。
- **向量/RAG**:FAISS+DashScope+BM25 混合+本地 reranker;**无 Chroma、无 sqlite 向量库**;project 多agent 用零依赖词袋检索(离线可演示)。
- **UI**:Streamlit 仅 RAG-cy;FastAPI:project 多agent、OpenManus、05/08课。
- **模型生态**:DashScope/Qwen 为主(ChatTongyi、qwen_agent),另有 OpenAI/Gemini 兼容接口。

## 4. Python/依赖惯例

- 每课/CASE 独立 `requirements.txt`,精确 pin 版本(agently==4.1.4.x、langgraph==1.0.x、fastmcp==3.1.x、pydantic 2.x);无 pyproject(OpenManus 用 uv + Python 3.12)。
- 实际运行主力 **Python 3.11**,与立项切片一致。
- 通用惯例:`python-dotenv` + `.env`、OpenAI-compatible base_url 环境变量、中文注释、pytest 仅 project 多agent 与 10 课出现。
