## 1. 问题 + 前置约束

实验侧有尺（固定 k 误放差等），生产几乎无数字 SLO。路线 Y 主跑已判**丙**（背景事实：T−C 点≈0.063、下界≤0；问题=过闸≠改对）。可双管（改质量 + 放行闸）但须**另页**；生产变绿 ≠ RESULT-Y 改判。

| 前置 | 来源 | 锁死作用 |
|------|------|----------|

验收层身份：**运营纪律页 + 观测/硬闸分层**（非实验乙成立格；非单次 demo 冒充总体）。

**Anthropic 清单命中与修正：**

1. **demo≠测量**：本页显式分层——硬闸不变量 / 周报观测 / 离线评测 / 实验乙尺；禁止用单次 Exit 冒充生产总体。  
2. **随机多跑**：D1 `must_stale` 要求 multi-run；n 小只称冒烟，不报方差充总体。  
3. **默认≠规格**：采集点、抽检频率、Watch 线写进运营页与规格；解码/模型漂移条款不进 CONTEXT。  
4. **词表上下文无关**：&lt;5%、T−C、乙尺、固定 k 差只进评估/运营/规格；CONTEXT 只收产品级「生产补丁/放行 SLO」与「实验—生产防火墙」。  
5. **止损预注册**：起步阈值与分层先于首周看板数字写死；事后改门槛凑绿 = 本评估作废重签。  
6. **复现两层**：硬闸层（无证/未确认出门、自红转绿、无 T1 绿灯）逐事件=0；观测层给周报容差与抽检协议。  
7. **ADR 三条件**：防火墙若靠「改文档便宜」跳过 ADR，事后把生产绿写进 RESULT-Y 会毁灭实验意义 → 必须 ADR。

**被否原推荐（写透）：** 若把「生产放行率升高」或「确认后少报错」直接写成 RESULT-Y 乙/软乙——等于用运营叙事覆盖已冻结的丙，违反一门一跑与投稿映射；原「同页兼写实验尺」在 grilling 中否决。

## 4. 拍板 + 子决策

1. **运营真源页** = `docs/ops/生产补丁放行SLO.md`（指标定义、分层、起步阈值、采集点、周报字段、与 Y 边界声明）。  
2. **防火墙**：生产 SLO 改善 **不得** 回写 PREREG-Y / RESULT-Y / formal-generations-y；不得同页二跑凑乙；不得称甲/软甲；机制大改 → **新预注册另页**。  
3. **指标集合（生产）**：  
   - **改**：A1 硬闸；A2 抽检；A3 改对率（人标抽检主指标）；A4 错改率成对；A5 流程有；A6 再验失败率周报；A7 槽位可核对率观测。  
   - **放行**：B2/B3 成对周报（或抽检折算）；B6/B7=100% 硬闸；B1 只与误放同看；B4/B5 **实验-only** 不进生产 KPI。  
   - **人审**：C1 作废率；C2 override rate；C3 续命带证率硬闸；C4 确认耗时观测；C5=0；C6 导出前拦截次数。  
   - **复验**：D1 must_stale multi-run 北星；D2 must_fresh 不误杀；D3=0；D4 包结论分布；D5 multi-run pass@k。  
4. **实验切开（E）**：乙尺/门闩/一门一跑/金标隔离/投稿映射只读引用；本页不填成立格。  
5. **起步阈值**：  
   - 无证/未确认出门 = **0**（硬闸）  
   - Agent 自红转绿 = **0**（硬闸）  
   - 无 T1 绿灯 = **0**（硬闸）  
   - 确认后严重错改抽检：先 **观测-only**；Watch 讨论线 **&lt;5%**（需人标样本；不作本波 Gate 生死）  
   - 补丁后仍「勿发/需补丁」占比：只观测  
   - must_stale multi-run：不得低于当前 Hard-Gold/金标门（离线评测轨）  
6. **金标**：只在离线评测；**禁止**进生产 score / 在线放行器。  
7. **ADR-0034** + CONTEXT 产品词 + 本评估 + 运营页。  
8. **实现边界**：本决议会话 **不写业务代码**；to-spec → to-tickets → enrich；before-implement 前人批。

## 6. 面试讲法

**Q: 实验丙了，你们还谈生产 SLO 干什么？**  
A: 丙暴露的是「过闸≠改对」。生产要的是改质量、放行纪律、人审自治和复验北星——用运营尺管产品，不是回头改 RESULT-Y 凑乙。

**Q: 为什么不把固定 k 误放差直接当生产 KPI？**  
A: 那是实验乙尺（预注册、配对 bootstrap、门闩 k）。生产几乎无同构对照臂；硬套会把不可比数字当成成功。生产看误放/误拒成对观测与硬闸不变量。

**Q: 严重错改 &lt;5% 是不是已经 Gate？**  
A: 不是。本波是 Watch 观测线，等人标样本协议落地再谈是否升 Gate。不变量（无证出门、自红转绿、无 T1 绿灯）才是 0。

**Q: 金标为什么不能进生产 score？**  
A: 金标是离线可复现评测；进在线放行或生产刷分会激励「对着答案做」，毁掉 must_stale 北星意义。

**Q: 生产 SLO 变绿能写进论文主实验成功吗？**  
A: 不能。丙已冻结；投稿映射不 Industry 成功叙事。机制大改必须新预注册另页。
