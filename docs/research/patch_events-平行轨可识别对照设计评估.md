## 1. 问题 + 前置约束

### 1.1 要拍什么

在不 HARKing 冲甲主链的前提下，检验一组「可识别、更干净」的对照设计，回答：

> 有没有一种比较方式能稳定露出 T 相对 B1/B2 的差异，且更适合产品叙事？

本轨成功 ≠ 甲成立。本轨成功 = 设计结论可升级与否的拍板 +（可选）旁路缝 / 小探针证据。

五道 frontier（D1–D5）：

1. 主指标  
2. 生成结构（分头 vs 同文四闸）  
3. B1 真对照信息集  
4. 「不能假绿」与本轨主表关系  
5. 升级闸（探针 → 是否另开主论文级新预注册）

### 1.2 与冲甲主链的边界（为何平行）

| 轨 | 地图 | 目标 | 主仪表 |
|---|---|---|---|
| **冲甲主链（路线 B）** | #431 / #432 | 打开结果甲的可识别性；新预注册 `PREREG-B`；选取 R；仓外门闩 | 主 `compare_primary` + 固定 k（R） |
| **本平行轨** | #434 / #435 | 更干净对照设计是否值得升级为另页主论文预注册 | 旁路 `compare_alt_*` + 自然误放/放行率；同文四闸；B1′ |

**防火墙硬句**：本轨对冲甲主链预注册正文（含草稿 `PREREG-B.md`）与主 `compare_primary` 语义保持**零 diff**；不得用本轨数字填主 `RESULT` 成立格；不得削弱对照；不得金标进排序；不得对外宣称主假设成立；不得回写旧 `PREREG.md`。

**为何必须平行（不得并进主链）**：

1. 主链已拍 R + k 下限 + 门闩，求验目标是甲；本轨北极星是设计可升级性，层身份不同。  
2. 若把「同文四闸 / 自然率 / B1′」直接写进冲甲页，等于在门闩与正式主跑前改主仪器，构成对主预注册的 HARKing 风险。  
3. 旧 n=30「T-B1/T-B2 差为 0」只证明现页空分固定 k **不可识别**，合法动机是「另开探针」，不是「见 0 后改主成立定义」。

### 1.3 前置约束（已被钉死）

| 约束 | 出处 | 含义 |
|---|---|---|
| `main` `a5e424c`（#416）后 RESULT：k=3；T-C 不成立；T-B1/T-B2 点估计 0 | `RESULT.md` | 旧链未打开甲；本轨动机附录 |
| 空分固定 k → T/B1/B2 同集 → 差锁 0 | `compare_primary` / `_top_positions` | 结构病；只加 n 打不开（路线 A 已废） |
| 路线 A（#419–#430）整链废除 | 关单 | 禁止复活 |
| 冲甲主链 #431/#432：R · k≥10 · 门闩未过 | 主轨决议 | 本轨零 diff 其预注册与主 compare 语义 |
| 旧 `PREREG.md` 不得回写 | 用户硬禁止 | 本轨结论不写进旧页 |
| 云端默认不发模型；真数据探针须明文授权 | 用户硬禁止 | 夹具可先做 |

| 合法动作仅旁路 / 只读复用 | 用户硬禁止 | `compare_alt_*`、`docs/evidence/patch-events-alt/` |

### 1.4 被否 · 「直接改主 compare_primary 追甲」（写透）

诱惑：看见主链 T-B1/T-B2 差为 0，立刻改主 `compare_primary`（换选取、换指标、收紧 B1、塞同文）好让冲甲页尽快出正差。

**否决理由**：

1. **层身份错位**：冲甲页的成立符号（甲/乙/丙）与选取 R 已在 #432 预锁；本轨若改主缝，等于在主预注册激活前偷改仪器。  
2. **HARKing**：见主链结果后改主成立路径或对照定义追甲 = 清单 #5 违例。  
3. **防火墙**：用户硬禁止本轨改主 `compare_primary` 语义与主预注册正文。  
4. **可逆叙事陷阱**：「改起来便宜」不能跳过 ADR；事后改主缝会毁灭主链止损/门闩意义（清单 #7）。

正确动作：旁路实装 → 探针读数 → 升级闸决定是否**另开新文件**的主论文级预注册；**永不**用旁路读数填冲甲 RESULT。

## 3. 逐路线评估

### 3.1 D1

| 维度 | (A) 固定 k | (B) 自然率成对 | (C) Pareto |
|---|---|---|---|
| 可识别性（空分同集病） | ❌ 空分 top-k 再现锁零；抄 R 则与冲甲重叠 | ✅ 无同集病 | ✅ 但过重 |
| 产品叙事 | 绕「固定覆盖率」 | ✅「这闸放多少、放错多少」 | 难单句 |
| 与冲甲增量 | 低（仪表同构） | ✅ 回答「更干净吗」 | 探针期难锁升级闸 |
| 探针可实现 | 须旁路 R 或仍病 | ✅ 夹具即可 | 散点可附录 |

**拍板 (B)**。固定 k（含拟议 R）**只进附录**，证明与主链仪表盘可对照，不充当本轨升级判据。

**被否 (A) 作本轨主指标**：与冲甲重叠；空分则锁零；改 R 等于旁路重复主链，答不出「更干净」。  
**被否 (C) 作本期主指标**：小 n/夹具撑不起前沿；可作附录散点。

### 3.2 D2

| 维度 | 分头 | 同文四闸 |
|---|---|---|
| 噪声源 | 改写器+闸 | 主要是闸 |
| 「更干净」可答性 | 弱 | ✅ |
| 夹具可非零 | 难构造稳定差 | ✅ 允许构造 T 拒、B2 放 |
| 与主链重叠 | 高 | 低（结构不同） |

**拍板：同文四闸**为主探针结构。分头生成仅附录。

**被否分头作探针主结构**：与主链噪声源相同；易诱改生成凑差。

### 3.3 D3

| 维度 | 现 B1 | 禁 id | 延迟 | 禁 id+延迟 |
|---|---|---|---|---|
| 与 T 距离 | 过近 | 中 | 中 | ✅ 真事后 |
| binding 捷径 | 可能 | 堵住 | 仍可能有 | ✅ 堵住 |
| 产品可叙事 | 弱（假对照） | 中 | 中 | ✅ 「事后核验 ≠ attested」 |

**拍板：B1′ = 禁 id + 延迟正文核验**。同文确定后，B1′ 才获 evidence 正文（及可选检索命中），**永不**获正确 binding id；核验不过则拒，且不得把该拒绝记成 T。T 仍要求 attested 绑定（id∈已入库 T1）+ 同时刻核验。

**被否维持现 B1**：与 T 同吃 `evidence_text`，对照偏假。  
**被否只禁 id 却生成前给正文且等同 T 时序**：仍可能塌缩。  
**被否让 B1 看 binding id**：事后臂开 attested 后门。

### 3.4 D4

**拍板：另测**。「不能假绿」构念是主张级绿灯纪律，不是 edit-level 放行闸误放；对齐已关地图 #428。本轨主表与升级闸**绝不**含假绿仪器读数。

**被否塞 / 混一句**：构念污染；叙事偷渡。

### 3.5 D5

**拍板：三档预锁**（§4.5）。见结果后改闸 = 作废。

**被否**见结果再定闸；夹具可分开即对外称更好；升级时改主 `compare_primary`；本轨成功写成冲甲甲成立。

## 4. 拍板 + 逐项子决策

### 4.1 D1 主指标 = 自然误放 + 自然放行率

1. 本轨主表报告各臂：**自然放行率**、**自然误放率**（放行数为 0 → 误放无定义，禁止记 0）。  
2. T 相对 B1′、相对 B2：看**自然误放差方向**；同时检查 T 放行率，防止「全拒装干净」。  
3. 固定 k 误放（含 R）只进**附录**，不进升级闸。  
4. 误拒率建议同表旁报，不单独充当升级判据（升级闸用 §4.5）。

### 4.2 D2 同文四闸

1. 共享 `after_text` 来源（跑前写死其一）：夹具金改 / 只读复用已有 jsonl 行 / **明文授权后**单次生成。  
2. 闸判信息集与时序：

| 臂 | 见 after_text | 见 evidence 正文 | 见 evidence id / 绑定 | 时序 |
|---|---|---|---|---|
| C | ✅ | ❌ | ❌ | 无核验；同文下 = 恒放行对照 |
| T | ✅ | ✅ | ✅ 且须属已入库 T1；不过 hard reject | 绑定+核验同时刻 |
| B1′ | ✅ | ✅（**延迟**至同文锁定后） | ❌ | 先有文，再核验；拒不得记成 T |
| B2 | ✅ | 按松闸语义裁剪 | 不要求 attested 绑定 | 核验不过不自动 hard reject |

3. 分头四臂生成 = 附录/对照，证明同文结论非夹具伪影时另票。

### 4.3 D3 B1′

见上表。禁止把 B1′ 的拒绝记成 T。禁止 B1′ 获得正确 binding id 捷径。

### 4.4 D4 假绿另测

本轨主表与升级闸不含假绿仪器。假绿另图另预注册（#428 精神）。

### 4.5 D5 升级闸（预锁）

升级 = 允许另开**新文件**的主论文级对照预注册候选（如未来 `PREREG-ALT.md` 类），**不取代**冲甲页，不回写旧 `PREREG.md`，不改主 `compare_primary`。

| 结果档 | 预锁条件 | 处置 |
|---|---|---|
| **可分开** | 夹具断言通过；且（若已授权）小 n 真数据旁路中 T 相对 B2 **与** 相对 B1′ 的自然误放差方向均 >0；且 T 未「全拒装干净」（跑前写死：建议 T 自然放行数 ≥ 1 且自然放行率 ≥ max(1/n, 0.05)，`/to-spec` 可微调数字但不得删档） | 允许另开主论文级新预注册决议/文件；仍须独立预注册与止损；**不**自动激活；**不**填冲甲 RESULT |
| **分不开** | 夹具构不出非零；或真数据上 T−B2 或 T−B1′ 自然误放差 ≤0（探针容差内） | 不升级；写技术报告；可改设计另开探针票；**禁止**放宽本闸冒充可分开 |
| **不值得升级** | 可分开但叙事/工程代价过高（极端收紧 B1′ 才分开且产品无法对应；或与冲甲 R 仪表同构无增量） | 放弃主论文级旁路预注册；归档；冲甲主链继续自有门闩 |

探针 n 小 = 冒烟/可扔。可分开 ≠ 主假设成立 ≠ 甲。

## 6. 面试讲法

**Q: 冲甲不是已经在做可识别性了吗？为什么还要平行轨？**

> 冲甲轨锁的是固定 k（R）下的甲/乙/丙求验。平行轨问的是另一件事：有没有更干净、更贴产品叙事的对照（同文四闸 + 自然率 + 真事后 B1′）。两轨层身份不同；混进主链会在门闩前改主仪器，有 HARKing 风险。

**Q: 为什么不直接改 compare_primary？**

> 见主链差为 0 后改主缝追甲，是事后改仪器。本轨只许旁路；升级也只许另开新预注册文件，不取代冲甲页，不填主 RESULT。

**Q: 同文四闸是不是太假？真实系统四臂都会改写。**

> 探针先回答「闸差是否可分开」。分头生成留附录。若只有同文能分开、分头分不开，升级闸可判「不值得升级」或要求补分头探针——这正是闸的用途。

**Q: B1′ 收紧是不是削弱对照？**

> 相反：现 B1 与 T 信息集过近，对照偏假。收紧是让事后核验成为真对照，不是把 B1 打成稻草人。禁止 B1′ 看 binding id，防止 attested 后门。

**Q: 可分开是不是就是甲？**

> 不是。可分开是探针档，允许另开主论文级预注册候选。甲/乙/丙只属于冲甲主预注册链。

**Q: 「不能假绿」为什么不放进这张表？**

> 构念是主张级绿灯纪律，不是 edit 放行误放。塞进来会污染升级叙事。另图测（#428）。
