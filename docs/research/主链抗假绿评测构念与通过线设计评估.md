## §拍板 + 逐项子决策

1. **构念**:主链抗假绿 = 在真实主链跑法(`run_gold`)下,must_stale 不得假绿(不得判 `fresh`)。层级=产品侧冒烟证明,不是统计测量,不是仪器 C。
2. **主张集**:`c1,c2,c3,c7`(同构 gold must_stale)。
3. **Decoding / 预算**:qwen-flash;`temp=0`;`seed=None`;n=3;入口 `run_gold` / `python -m freshlatch.eval run`(参数面 #84 落)。
4. **通过线**:预算内 must_stale→fresh **合计 = 0** 即过;任一格 fresh = **未过**(可引用);**不得**事后放宽。stale/unknown 细账进报告、不进通过线。
5. **作废线**(整刀作废,非未过):缺原料/报告不完整/偏离预登记 decoding;跑后改通过线/作废线/decoding/主张集;动 C 预登记/`CONTROL_PROMPT_C`/旧 control;改 `gold.json` 或已锁 K 通过线;must_stale 任一条 `unparseable`。
6. **与 C/K**:独立预登记与独立仅表明句;可引用 C 对照成立作「假绿可诱导」前提;不得改写 C/旧仪器/K3/K6-4 已锁句;K3/K6-4 must_stale 读数不得升格为本证明。
7. **成功仅表明句**(逐字;落 ACCEPTANCE 归证明跑票):

> 主链抗假绿（qwen-flash，temp=0，seed=None，n=3，主链抗假绿预登记；入口 run_gold）仅表明 must_stale（c1/c2/c3/c7）判 fresh 合计为 0；以假绿仪器 C 对照成立为假绿可诱导前提；不是一期评测闭合，不是判定层已愈，不是产品已愈假绿的统计证明，也不改写 C / 旧仪器 / K3 / K6-4 已锁仅表明句。

8. **失败仅表明句**(逐字;`{k}`/`{逐条摘要}` 跑时填):

> 主链抗假绿（qwen-flash，temp=0，seed=None，n=3，主链抗假绿预登记；入口 run_gold）仅表明 must_stale 判 fresh 合计为 {k}>0（{逐条摘要}）→ 未过且不作废；不得放宽 fresh=0 通过线；失败处置走修窗（策略票）；不改写 C 对照成立句，也不写成判定层已愈或一期闭合。

9. **未过入口**:有效跑未过 → **必须**开修窗;#83 拍改闸/策略/工具;禁见格子改本通过线/gold/C。
10. **预登记路径**:`docs/evidence/w4/main-chain-anti-false-green-prereg.md` → #84 落盘(本票不写文件)。
11. **ADR / CONTEXT**:不新开 ADR;不进词表。

## §面试讲法

**Q:C 都 4/4 假绿了,为什么还要另开「主链抗假绿」?**  
A:C 是无工具假绿对照,只证明基线能诱导 alive。产品主张是「有复验主链时必须红(不得假绿)」。对照成立 ≠ 产品已愈——父图写死异构另条证明。

**Q:这和 K3「must_stale 判 fresh=0」有什么不同?**  
A:数字形状可以同构,但预登记、仅表明句、修窗入口独立。父图禁止把 K3/K6-4 已有读数自动升格为本图证明。本条还显式挂 C 对照成立作前提,讲的是「假绿仪器绿了之后工程怎么收」。

**Q:为什么通过线是 fresh=0 而不是四条全 stale?**  
A:产品侧假绿的违例定义是不该绿却绿。unknown 是缺口/打回,不是绿灯假绿。全红门槛会把「没复验到位」和「假绿」绑死,修窗容易变成凑红。

**Q:temp=0、n=3 能当测量结论吗?**  
A:不能。诚实标冒烟:不估运行间噪声、不报方差、不是一期评测闭合、不是判定层已愈、不是产品已愈假绿的统计证明。

**Q:过不了怎么办?能改通过线吗?**  
A:不能。有效跑未过 → 必须开修窗,策略归下一票;见格子改 fresh=0 / 缩名单 / 改 n = HARKing,整刀作废纪律与 C 同构。

**Q:为什么不新开 ADR、不进 CONTEXT?**  
A:跑前预登记与引用纪律 ADR-0007 已覆盖;「主链抗假绿」是评测标签不是产品本体词。词表里「假绿对照」「must_stale」够用。
