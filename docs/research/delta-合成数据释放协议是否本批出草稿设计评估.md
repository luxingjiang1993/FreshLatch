## 1. 问题 + 前置约束

拍板：合成数据**释放协议**是否在本批产出可审计草稿（许可、脱敏、synthetic 标明、对外分发边界），或只留 RESEARCH/HOLD；若出草稿，最低完备字段与「草稿 ≠ 已释放」链条。

| 前置 | 来源 | 锁死作用 |
|---|---|---|
| Batch 4 含数据释放草稿 | 三曲线设计总表 | 倾向出草稿而非纯 HOLD |
| 平行包须标 synthetic；释放正文归本票 | ADR-0020 | 本票补齐协议 |
| 释放范围随 P1；禁 backlog 升格多垂类 | ADR-0019 | 覆盖面收敛 |
| 本批默认不宣称已对外可用 | 票面 | 草稿≠释放 |
| 评测联网禁用、synthetic 纪律 | 票面勿重开 | 继承 |
| OUT | 真连接器/十垂类/改闸/主会对照 | 继承 |

**给谁看（非应用代码）**: 合成评测材料（gold/语料/P1 包）的使用与外发规矩——未来的你、Agent、作品集/面试读者；不是 FreshLatch 产品功能说明书。

## 4. 拍板

1. 本批产出可审计草稿；**不**执行对外发布。  
2. 覆盖：第一课题合成包 + P1（同一骨架）；backlog 不进释放范围。  
3. 最低字段 1–8 落 `docs/research/C4-合成数据释放协议草稿.md`。  
4. 许可 = 占位（释放前必选 SPDX；草稿未授权再分发）。  
5. 「已释放」= SPDX 已填 + 人显式批准与版本号 + 分发物与卡一致；推进 main ≠ 释放。  
6. ADR-0021；δ 三票齐 → 另会话 `/to-spec`（仅 Batch 4）。  
7. 本会话不 `/implement`。

## 6. 面试讲法

**Q: 你们开源数据集了吗？**  
A: 没有。C4 是释放**协议草稿**；已释放须许可选定+人批准+版本。卡在仓里 ≠ 数据已对外。

**Q: 这页纸是产品文档吗？**  
A: 不是。管的是合成评测材料怎么标明、能不能给人，不管 Lead/闸怎么跑。

**Q: 为什么不把 P3–P9 写进可释放范围？**  
A: 那些只是 backlog；写进去等于宣称多垂类数据集，与 Port 测量诚实冲突。
