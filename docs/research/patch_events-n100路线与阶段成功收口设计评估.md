**Anthropic 评审命中记录**（推荐前主动过清单）:

1. **演示可过 ≠ 测量可信**:仓外试改 T 是工程探索层，不得假装成主表统计；n=100 数字仍只抄 `compare_primary`。
2. **单次运行判生死**:n=30 的 k=3 使区间极宽（T-C 下界 -1），不能据此改判据「凑」成立；也不得用一次试改绿就宣称主假设成立。
3. **默认不是规格**:正式生成仍锁 `DEFAULT_MODEL` / 温度 / 种子消费顺序；缺 seed 不得事后补。
4. **词表定义上下文无关**:结果甲/乙/丙、仓外试改、成立格不进 `CONTEXT.md`；归评估与 DECISION-LOG。
5. **止损/验收判据预先锁定**:见 n=30 丙后把 `PREREG.md` 作废重写 = HARKing；路线 B 仅当 T 的可执行定义必须改时才开，且须明文作废旧链。
6. **复现两层**:闸与名单确定性层逐位；评委 API 随机层近似；违例级含跑后改 PREREG、夹具填主表、偷换 T 定义仍挂路线 A。
7. **ADR 三条件**:「n=30 不成立 → 想改预注册」靠「改起来便宜」跳过纪律；事后改判据毁灭实验意义 → 三条件齐备，开 ADR-0034。

## §面试讲法（grilling 预案）

**Q: n=30 已经三条都不成立，为什么还走路线 A？**  
A: 因为 PREREG 事先写了 n=30 是小样本门槛、n=100 是满样本；见丙后作废重写是 HARKing。k=3 说明功效不足或 T 过紧，不等于判据写错。

**Q: 那为什么允许仓外试改 T？**  
A: 只回答「自然放行是否有机会离开个位数」。试改不进主表。若必须改 T 定义，就转路线 B 并明文作废旧链，而不是在 A 下偷换。

**Q: 乙算不算「T 更好」？**  
A: 算阶段成功：只主张相对无证据改写（C）的 fail-closed。不写优于 RARR/KPR。甲才写三条。

**Q: 实现票绿了是不是主假设成立？**  
A: 不是。实现票只缝与抄表；成立格只看 `compare_primary` 输出。

**Q: 能不能说两名真人盲审 / 全库金标？**  
A: 不能，直到附加预注册完成、人做完。现行句仍是「模型评委加单人抽检」；检索金标仍非全库人工。

**Q: 「不能保持绿」这次能写进论文主结论吗？**  
A: 不能用本 false-accept 主表证。要另开测量。
