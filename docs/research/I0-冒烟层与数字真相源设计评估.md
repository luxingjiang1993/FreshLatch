## 6. 面试讲法

**Q: 你们不是测过 hybrid 了吗，为什么还默认 BM25？**  
A: 冒烟集上 hybrid 与 BM25 持平，dense 更差，rerank 没有严格增益。预登记门槛是「严格更好才开默认」，而且改生产臂还要另开 Hard-Gold。有表 ≠ 已证明该换。

**Q: n=36 能说明什么？**  
A: 只能说明冒烟对照与门判决可复跑，不能报方差或统计显著。文首写死了。

**Q: 这和 agentic RAG / 发前闭环是一回事吗？**  
A: 不是。Phase A / I0 只交付可测 retrieve 与默认臂纪律。发前闭环是 V1+；Evidence-bound 是 V1.5。贡献清单 v0 有黑名单。
