## §拍板 + 逐项子决策

**拍板:D1-(c) + D2-(B) + D3-(1) + D4-(β) + D5-(ii)。**

### 本阶段唯一允许摘引句(逐字)

1. **K3(统计层·已过)** — #47 已锁模板:
   > K3（temp=0.7，seed 11/22/33，每 seed n=5）仅表明 c2 stale ≥14/15 且 must_stale 判 fresh 合计为 0，不是一期评测闭合，也不是 must_fresh 已愈，也不改写判定层冒烟未愈。

2. **K1(demo·否定式达标)**:
   > K1（demo）仅表明 `src/` 无 MCP server/listener 且 inspector 未连，不是 MCP 安全证书，也不是一期评测闭合。

3. **K6-2(机制层冒烟·倾向过,本批 n=3,temp=0)**:
   > K6-2（n=3，temp=0）仅表明本批机制层冒烟：c5/c6 非 stale 5/6 且 must_stale 各 3/3 stale；三次均为 temp=0，不作为运行间噪声估计，不是统计测量，不是判定层已愈，也不改写 K6-4 未愈。

4. **K2(demo·部分过 + K2-1 备案)**:
   > K2（demo）仅表明 Auditor 自动在场与单轮判定在金标跑中可见；`spawn_auditor` 不在 `LEAD_TOOLS_W3`，与 K2-1 字面冲突已按 ADR-0009/0010 与 spec 03 §3.6 备案，不是 K2-1 字面全过，也不是一期评测闭合。

5. **总判禁令(必挂)**:
   > 产品可运行（单测绿、UI 起、金标链跑通）。闸层可复现。不符合 W5–W8 全量验收通过。不得写成一期评测闭合。

### 明确禁止升格句(含同义改写)

- 「W5–W8 全量验收通过」「一期(评测/测量)闭合」「一期测量已闭合」

- 把「对照不成立」写成「假绿对照通过」或「仪器作废」
- **单摘** ACCEPTANCE_SUMMARY 表头「过 / 倾向过 / 部分过」当结论

## §面试讲法(grilling 预案)

**Q:K3 过了,一期评测闭合了吗?**
A:没有。唯一能摘的是「仅表明 c2 stale ≥14/15 且 must_stale 判 fresh 合计为 0,不是一期评测闭合,也不是 must_fresh 已愈,也不改写判定层冒烟未愈。」表头写「过」不能当结论摘。

**Q:K6-2 倾向过是不是判定层好了?**
A:不是。那是 n=3、temp=0 的机制层冒烟;三次不估运行间噪声。K6-4 仍未愈。可摘句把「不改写 K6-4 未愈」写在主动范围里。

**Q:K2 不是 Auditor 实装过了吗?**
A:demo 层仅表明自动在场与单轮判定可见;`spawn_auditor` 不在白名单,与 K2-1 字面冲突已备案。不是 K2-1 字面全过。

**Q:为什么不给 K7 一句「仅表明」?**
A:「部分过」单句会被截成「收口过了」。导出/token 缺口已由总判「不符合全量验收」覆盖;细节挂 K4/K5 登记票。

**Q:为什么不新开 ADR?**
A:难反转的是「事后改判据/改引用句毁实验」,ADR-0007 已写。本票是把已锁模板落实到本批读数,不是新架构取舍。
