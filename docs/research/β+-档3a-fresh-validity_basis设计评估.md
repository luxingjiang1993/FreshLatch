## 3. 逐路线评估

### 3.1 处置姿态（A/B/C）

| 对照 | A 明确不做 | B 做实装 | C 只锁方向 |
|---|---|---|---|
| 与票面「是否/何时」 | 答「不做」 | 答「现在做」 | 答「形状锁死、何时另开」 |
| 假牙风险 | 低（诚实空转） | 高（若形状未齐就动手） | 低（本批不动手） |
| 给 3b 的「方向」 | 有（=不做）但无形状意图 | 有 | **有形状意图且不偷换实装** |
| Anthropic #5 | 无实装预锁对象 | 须本票内齐预登记 | 方向预登记本票齐；实装另票再锁负例跑通 |

**Anthropic 否决的原诱惑**：把「锁方向」做成关单即开实装票（维度七-3）——演示排期感冒充已决议实现。否决 B：list 动 schema+闸，未另开实装预登记跑通即动手 = 违例。否决 A：本票标题核心是单 doc vs list；只说「不做」会把形状再踢回雾里，3b 意图层无处对齐。

**拍板：C。**

### 3.2 主动机（1/2/3）

| 对照 | 1 不变量 | 2 铺 3b | 3 叙事 |
|---|---|---|---|
| 层声明 | 正确：闭合闸输入 | 副：意图对齐 | **demo 层冒充测量** |
| 与形状 | 推 list 全员受检 | 不单独决定形状 | 易接受单 doc 假牙 |

**拍板：主动机 1，副 2；否决 3 作主动机。**

### 3.3 形状（A/B/C）

| 对照 | A 单 doc 主证 | B list | C 不锁 |
|---|---|---|---|
| 多 `t1_evidence_ids` 诚实性 | **假牙**：只校一份，叙事像全链 | 全员受检 | 无方向 |
| 与主动机 1 | 弱 | 对齐 | 无 |
| 本批代价 | 零（不实装） | 零（不实装）；将来高 | 零但废票 |

**拍板：B。** 单 doc 主证据路径写入**被否（作为激活方向）**。

### 3.4 list 语义（A/B/C）

去重按 `doc_id`、全员比对，与「声称的依据集合」同构。按 evidence 逐条无额外语义。抽检子集 = 假牙变种。

**拍板：A。**

### 3.5 renew 同构（A/B/C）

一个域概念一种形状；renew 一元 list 不改人审「选一条」。双形状永久分叉污染词表与闸。多选 renew 过载本票。

**拍板：A。**

### 3.6 与 3b（A/B/C）

票面要的是方向清晰，不是实装完成。硬瀑布（B）不合理。忽略意图（C）浪费本票。

**拍板：A**——事实层：今日仅 renew 写单对象；意图层：将来若做 3a 则 list 全员受检。

### 3.7 实装触发（1/2/3）

**拍板：1 硬门闩；2 可选信号；禁止 3。**

### 3.8 存量（A/B/C）

与「统一 list」一致：迁成一元 list，不长期双读。脚本与验收在实装票；本票锁目标。

**拍板：A。**

### 3.9 交付（A/B/C）

锁 list 且否决单 doc，后人会问「为什么不先做单 doc」——三条件齐，须新 ADR。补丁 0017 糊档。不开 ADR 则方向易被实装单顺手改。Batch 2–5 地图已关且声明 β+ 不在范围 → 另开薄地图。

**拍板：A → ADR-0024 + β+ 地图。**

## 4. 拍板 + 逐项子决策

1. **本批不实装**：fresh 继续不构造 `validity_basis`；ADR-0017 半激活叙事不变。
2. **方向 = list 同构**：
   - 目标形状 `[{doc_id, checksum}, …]`；
   - 由 `t1_evidence_ids` **按 `doc_id` 去重**构造；
   - 闸对**每一项**现算比对，**任一不符** → `CHECKSUM_MISMATCH`；
   - renew 将来写**一元 list**（人选一条交互不变）；
   - **否决**单 doc 主证据激活；**否决**闸抽检子集。
3. **存量**：实装时单对象 → 一元 list；不长期双读。
4. **动机**：主动机不变量闭合；副为 3b 意图对齐；不为演示叙事。
5. **3b 解阻**：可独立 grilling；必须分开事实层 / 意图层。
6. **实装门闩**：仅显式新开实装/规格票 + 负例与构造规则预登记；禁止本票关单即 ready-for-agent。
7. **验收层**：本票 = 决议/方向预登记；**不得**声称 fresh checksum 半边已启用或 latch 已证明。
8. **落点**：ADR-0024 + 本评估 + CONTEXT 半激活指针 + 契约 §6 + β+ 地图；本会话不 `/implement`。

## 6. 面试讲法（grilling 预案）

**Q:档 2 都做了，为什么 fresh 还不补 validity_basis？**
A:补的时候必须先答单 doc 还是 list。单 doc 在多 evidence 下是假牙——只校主证却像全链有 checksum。我们宁可半边诚实空转，也不把假牙写成「已激活」。方向上锁的是 list，本批不实装。

**Q:那你们是不是永远不做 3a？**
A:不是。本票锁的是「若做则 list 同构 + 全员受检 + renew 一元 list + 存量迁一元 list」。实装必须另开票并预登记负例，不能从本票关单自动派生。

**Q:为什么不直接实装 list？**
A:动 schema、闸循环、投影/导出、存量迁移——这是实现批，不是方向批。方向先锁死，避免实装单里再吵单 doc「先顶上」。

**Q:3b 能不能开？**
A:能。但必须写清：今天写侧只有 renew 的单对象 basis；将来若做 3a，意图是 list。不能把意图当成当前事实，也不能假装没有意图。

**Q:这算不算 checksum 已证明 latch？**
A:不算。本票连 fresh 半边都没启用。预锁句在 ADR-0017；本票只加方向，不改激活宣称。

## 7. 将来实装票预登记模板（本票不跑通，只钉清单）

实装/规格票开启前必须书面锁死（可增补，不可事后为凑绿改判）：

1. 构造：`t1_evidence_ids` → 按 `doc_id` 去重 → 现算 checksum 填 list；
2. 闸：逐项比对；任一不符 → `CHECKSUM_MISMATCH`；仍禁读库列；
3. renew：写一元 list；人选一条交互不变；
4. 迁移：存量单对象 → 一元 list；验收无双读残留；
5. 负例至少：篡改 list 中任一 doc 的语料 → fresh（或带 basis 的闸路径）拒绝；空/`t1_evidence_ids` 缺失仍由既有不变量拦。
