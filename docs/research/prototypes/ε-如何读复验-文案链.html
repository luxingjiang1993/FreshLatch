变体 A · 复验单旁路「读法卡」（短）

如何读本复验单 1. 绿灯/红灯是机器判定（fresh / stale / unknown），不是商业裁决。 2. 已作废灰显是人的决定（void），可与 stale 并存；作废后重跑不得再绿。 3. 本单非法律意见、非自动决策；不得据此「进入/不进入」。 4. 主叙事是卖作废：能闩住已死主张，不是证明「建议可行」。 误读禁区：把 Time-to-Sheet / rubric 勾选说成「产品已验证 / 客户会付费」。
禁升格（旁路可见）
· demo 可读 ≠ 付费成功 · demo 可读 ≠ 一期验证闭合 · 不得从 override/续命推断「模型变好」

「如何读复验」文案链已挂复验单旁路与 Client Memo 附注，且含非法律/非自动决策与 void/stale 分工； 仅表明误读边界可被人工勾选核对，不表明产品验证成功或付费意愿。

变体 B · 折叠 FAQ（职人默认收起一行）

如何读 ▸ 机器灯 ≠ 人作废 ≠ 商业裁决
Q1 绿灯是不是「可以投」？ 否。绿灯只表示在既定 T1 下机器未判死；非自动决策。
Q2 灰显「已作废」和红灯 stale 一样吗？ 不一样。stale=Auditor/机器；void=人审 discard。可并存。作废进作废名单，重跑不得再绿。
Q3 这算法律/合规意见吗？ 非法律意见。仅复验投影。
Q4 演示跑通了算验证成功吗？ 否。demo 可读 ≠ 付费/验证成功。latch 由 Void→Stay-Red / 闸证明，不靠文案或 Time-to-Sheet。
禁升格 · 目录/文案存在 ≠ 仪器已过 · override 次数 ↓ ≠ 模型变好

变体 C · 单一「读法源」三出口投影

读法源（canonical，to-spec 落一处） 【身份】本产出是复验投影，主叙事卖作废。 【机器】fresh / stale / unknown = 闸与角色判定；不是投资建议。 【人】void = HumanLatch discard；与 stale 并存不互斥；进作废名单。 【边界】非法律意见 · 非自动决策 · 禁止「建议进入/不进入」。 【验收诚实】文案链 ACCEPTANCE 只证明「误读边界在场」；demo 可读 ≠ 付费/验证成功；不得把 override 当模型变好。 —— 投影出口 —— · 复验单旁路：上列前四条缩写 · Client Memo：免责声明段引用【边界】+【人】/【机器】一句 · ACCEPTANCE 索引：只摘【验收诚实】整句
禁：三出口各写各的导致漂移；事后为「好懂」删掉 void/stale 分工。
ACCEPTANCE 可引用句（推荐作本批 canonical）
