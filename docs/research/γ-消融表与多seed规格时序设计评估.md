## 1. 问题 + 前置约束

Batch 3（γ）：消融表与多 seed——本批**只写规格**还是**规格与实跑同步**；若只写规格，实跑推到哪条曲线/哪次 to-spec；多 seed 在 temp/托管漂移下的诚实框定（冒烟 vs 方差声称）。

验收层：invariant + smoke（规格层写死；实跑若本批不做则明确「未跑 ≠ 已证明」）。

| 前置 | 来源 | 锁死作用 |
|---|---|---|
| 随机单次判生死不合格；n 小框定冒烟不报方差 | 票面勿重开；Anthropic #2 | 不得锁未预登记的方差通过线 |
| C3 卡不锁多 seed 方差；消融划给本票 | C3 §3/§4 | 本票补规格，不重开 γ-INV |
| 三曲线 Batch 3 = 消融/多 seed **规格**；实跑在 NEXT | 三曲线设计总表 | 默认只写规格 |
| 禁改 gold | ADR-0018 | 规格/实跑皆不得靠改 gold 凑 |

## 4. 拍板 + 预锁句 + 消融表规格骨架

### 4.1 决议

1. Batch 3 **仅锁规格**；**实跑未做**。  
2. 实跑 → 独立 `/to-spec` 或 NEXT；Batch 3 to-spec 须注明「消融/多 seed 规格已锁、实跑未做」。  
3. 多 seed 默认 smoke：记录模型/温度/日期/seed/n；**不报方差/显著**。  
4. 不开新 ADR；更新 C3 卡非范围指针。

### 4.2 预锁可引用句

> Batch 3：消融表与多 seed **仅锁规格**（表头/记录字段/smoke 框）；**实跑未做**；未跑 ≠ 已证明；不得报方差/显著。实跑另开 to-spec/NEXT。禁改 gold 仍受 ADR-0018 约束。

| 消融因子（示例，实现时填具体） | 对照条件 | 期望方向（定性） | 记录字段 | 层 | 禁升格 |

## 6. 面试讲法

**Q:Batch 3 为什么没跑消融？**  
A:三曲线就写了本批锁**规格**。在托管漂移和 n 小的情况下同步实跑，容易把冒烟当成方差证明。我们写死未跑 ≠ 已证明，实跑另开。

**Q:那多 seed 写在规格里干什么？**  
A:锁记录字段和 smoke 框，避免以后实跑时随口报显著。要方差必须另预登记。
