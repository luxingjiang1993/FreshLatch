## 1. 问题 + 前置约束

### 1.1 要拍什么

在路线 B / 选取 R / 仓外门闩已锁、且 #438 门闩**未过**的前提下，只钉两件供后续工程票的事（冲甲仍为目标，**不保证**得到甲）：

1. **T 与 B1 的可执行差异**：使 B1 成为真「先改后验」对照，T 保持 fail-closed attested；仓外重测时 T−B1 固定 k 误放差方向**可为正**。  
2. **抬 T 的自然放行（正确样本）**：不把 T 做成 B1；使 T 的 k 有合理路径 ≥10（机制/生成质量/假阴性，不是无限加 n）。  
3. **重申仓外门闩复测协议**：改完后必须用与 PREREG-B 一致的 R 再跑可扔报告；三条件全过才允许激活；未过不得正式生成。

三道 frontier（已烤）：

1. B1 相对 T 的可执行差异清单（字段/时序/拒绝语义）  
2. 抬 k 的主杠杆  
3. 门闩复测数据源；PREREG 修订形态

### 1.4 为何门闩未过（根因写透）

只读回放 pe_v2 n=30 + `formal-generations.jsonl`（与 #438 一致）得：

| 臂 | 自然放行 m | 自然误放 | 主拒因（回放） |
|---|---:|---:|---|
| T | 3 | 0 | 核验不过 25；未绑定已入库 T1 **2**（皆坏样） |
| B1 | 3 | 0 | 核验不过 27 |
| B2 | 30 | 15 | 不 hard reject |

**T−B1 差 = 0 的机制解释（不是「又同集」）**：

- 在 R 下 T/B1 固定 k 集合**已可不完全同集**（T:`c006,c010,d009` vs B1:`a012,c006,d009`），旧空分同集病不再是本失败的主因。  
- 两边固定 k 误放率都是 **0**：都没有放出坏样。  
- 现实现同构点：共用 `verify_edit`（去空白逐字相同）；核验不过两边 hard reject；T/B1 rewrite 都带请求内 `evidence_text`（措辞微差）。  
- 结构性决策差几乎只剩 T 的 `_bound_t1`。例：`b007`（坏·T0）上 T 的 after **已与 evidence 逐字相同**却因绑定拒；B1 因**生成 after 不同**走「核验不过」→ **绑定缝被生成噪声盖住**，B1 吃不到本该有的误放。  
- 放行集分歧（`c010` vs `a012`）来自生成分歧，不是对照语义。

**k = 3 &lt; 10 的机制解释**：

- T 上「正确」假阴性 **12**，拒因**全是核验不过**；绑定杀死的正确样 **0**。  
- 抬 k 的主矛盾在「生成 → 精确核验」假阴性，不在绑定过严。

**T−B2 已为正**：B2 不 hard reject，机制差真实；门闩卡在 T−B1 与 k。

Anthropic 清单对照：不得把 #438 冒烟数字升格为甲；不得见差=0 后放宽成立定义；改的是 T/B1 **可执行定义**（激活前修订），不是选取 R 或成立判据。

## 4. 拍板 + 逐项子决策

### 4.1 Q1 · 可执行差异（D1）

**同构点（事实，跑前登记）**：

1. 生成阶段均为 `rewrite`，请求携带同一候选的 `before_text` / `evidence_text` / `evidence_id`。  
2. 核验共用 `verify_edit`：`after_text` 去首尾空白后与 `evidence_text` 逐字相同。  
3. 核验不过 → T 与 B1 均为 `decision=reject`（hard）。  
4. 字段形状同构；**仅 T** 在核验前执行「evidence id ∈ 本次已入库 T1」。

**最小差异集（拍板）**：

1. **同 after 再分叉**：对同一 `claim_id`，T 与 B1 消费**同一份** rewrite `after_text`（及同一 `evidence_id` 候选字段），再分别走决策闸。  
2. **T**：`_bound_t1` ∧ 核验 ok → release；否则 hard reject（绑定失败理由保持「证据未绑定已入库 T1」）。  
3. **B1**：不跑绑定闸；仅核验 ok → release；核验不过 → reject（**不得**记成 T 的拒绝）。  
4. **禁止**本期把 B1 改成核验失败仍放行 / soft warning（D2）；禁止 B1 专用弱核验（D3）。

### 4.2 Q2 · 抬 k（L1）

1. 主杠杆 = **降低正确样在 T 上的核验假阴性**（生成侧更常产出与证据一致的 after）。  
2. 绑定路径确认非正确样瓶颈；**禁止**放松绑定或 hard reject 来凑 k。  
3. 禁止无限加 n、夹具伪抬 k。  
4. D1 与 L1 可同工程波次，但验收必须分开：D1 看「同 after 上 T/B1 自然放行集可不同」；L1 看「正确样过 T 的路径」，不得用放宽闸冒充 L1。

### 4.3 Q3 · 复测与修订形态

1. 复测序：S2 → S1 →（可选）S3；禁止 S4。  
2. 复测规则必须与 PREREG-B 的 R 一致；报告可扔、不进主表、不填 `RESULT-B` 成立格。  
3. 三条件仍同时满足才允许激活批注；未过不得 #440 正式生成进主表。  
4. 预注册形态 = **激活前修订 + 修订记录**（P-rev），不另开 B2。

### 4.4 `/to-spec` 边界

| 允许 | 禁止 |
|---|---|
| 修订 `PREREG-B` 可执行定义条款（本拍板已写入修订记录） | 激活正式主跑；改文首为已激活 |
| `/to-spec` 增量：T/B1 行为差缝 + 门闩复测夹具 | 未过门 #440 进主表；发模型（除非人授小探针票另开） |
| 第一张工程票见 §4.5 | 复活 A；回写旧 PREREG；金标进 score；D2/D3；放松 T hard reject |
| 人轨/平行轨另票 | 用复测数字填 RESULT-B 成立格 |

**结论：可以 `/to-spec`（增量缝）**；**不可以**激活或正式生成进主表。

### 4.5 第一张工程票（建议）

**标题意向**：T/B1 同 after 再分叉（D1）+ 门闩复测夹具（含报告格式）。

**Acceptance（可执行，至少）**：

1. 同 after（或同候选强制共用 rewrite 产物）上，T/B1 自然放行集**可以不同**（绑定缝类坏样：T reject / B1 release）。  
2. T 在核验不过时仍 hard reject；B1 核验不过仍 reject（不是 soft 放行）。  
3. 仓外复测报告格式与 `PREREG-B` R 一致（自然放行/自然误放/固定 k 误放/三条件判定/激活建议）；标明可扔、不进主表。  
4. 不读密钥、默认不发网络；不激活 `PREREG-B`；不写 `RESULT-B` 成立格。

抬 k 的生成质量补丁可作为**同波次第二张票**或同票第二 Acceptance，但不得用放宽核验替代。

## 6. 面试讲法

**Q: 选取都改成 R 了，为什么门闩还是不过？**

> R 打开的是可识别性：固定 k 集合可以不同。#438 里集合已经不同，但 T 与 B1 的固定 k 误放率都是 0，差仍为 0。根因是对照机制被生成噪声盖住，不是又同集。

**Q: 为什么要「同 after 再分叉」，而不是让 B1 核验失败也放行？**

> 后者是削弱 B1 凑差。PREREG 写的是 B1 核验不过则拒绝；真对照应是：同一改稿上，T 多一道已入库 T1 绑定闸。同 after 才能让绑定缝变成可观测的误放差，而不是比谁更会抄提示词。

**Q: 见门闩失败再改 T/B1 定义，是不是 HARKing？**

> 改的是可执行对照定义（激活前修订并留修订记录），不是成立定义，也不是选取 R。正式主张仍只认激活后的新跑。若修订后仍分不开，收口乙/丙，禁止再改成立判据追甲。

**Q: k 怎么抬到 ≥10？放宽核验行不行？**

> 不行。回放显示正确假阴性全是核验不过，绑定没杀正确样。主杠杆是生成侧降低假阴性。放宽 hard reject 等于把 T 做成 B1，对照语义崩塌。

**Q: 复测用旧 n=30 还是新跑？**

> 机制改完先夹具 + 只读旧生成冒烟；要主张真分离再用小探针。都可扔，不进主表。未过三条件不得激活、不得正式生成。

**Q: 为什么不另开 PREREG-B2？**

> 成立定义与 R 未变；只修订 T/B1 可执行条款。同页激活前修订 + 修订记录足够透明。另页增加读者负担，本期无增量必要。
