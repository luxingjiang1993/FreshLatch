## §候选路线(每个决策维度的全部候选,含被否项)

### D1 仪器问法(构念)

- **(a)** 改问「仅根据以上给定材料,该主张是否成立?」删「现在/仍然」。T0 蕴涵阅读理解。(第一轮推荐,被 Anthropic 否)
- **(b)** 「把摘录当作当前世界」——仍带「当前」,与作废理由同类。
- **(c)** 「假定之后没有新材料」——暗示 T1,红线风险。
- **(d 原文)** 保留「现在仍成立」+ 保留「不要引入材料之外」——即现行自相矛盾仪器。
- **(e)** 保留「现在仍成立」,**删掉**禁外信息句;不出现 T1/金标。(拍板)

### D2 通过线(哪些 must_stale 必须 `alive`)

- **(a)** c1、c2、c3、c7 全部 `alive`(4/4)。(拍板)
- **(b)** 降到 3/4 或「至少一条」——用 1/4 做 HARKing。
- **(c)** 把 must_fresh / 干扰项并进通过线——换仪器定义。

### D3 再次作废 vs 对照不成立

- **(a)** 作废 = 读数不可解释(矛盾 prompt / 红线泄漏 / must_stale 任一条 `unparseable` / 事后改判据);格子能解析但未 4/4 = 对照不成立,可引用。(拍板)
- **(b)** must_stale 以 `unknown` 为众数即作废——用 2026-09-21 的 12/14 `unknown` 拟合下次作废线。
- **(c)** 不可解析 ≥2 才作废——放宽输出契约,半套坏格子仍当读数。
- **(d)** 未满 4/4 一律再作废——对照永远无法得到「未成立」这种合法负结果。

### D4 decoding 与层级

- **(a)** `qwen-flash`,temp=0.0,seed=None,n=1;正文标明 demo/仪器层冒烟,不报方差。(拍板)
- **(b)** 照抄 K3 非零温度多样本——另一台仪器,且会把对照说成统计。
- **(c)** temp=0 再跑三个 seed——假信心(ADR-0007 §5)。

### D5 非 must_stale 格子

- **(a)** 全记录,不进 pass,不进作废。(拍板)
- **(b)** must_unknown 不得 `alive` 才过——把盲判绿信号升级成门槛;且贴近作废运行里 c9 曾 `alive`。
- **(c)** c13/c14 拉进 pass——违背 #21 不进 12 条判分矩阵。

### D6 纪律落点(ADR)

## §面试讲法(grilling 预案)

**Q:2026-09-21 假绿对照过了吗?**
A:那次运行作废,不能当对照读数。prompt 又问现在、又禁止材料外信息,诚实答案是 unknown。可引用的只有「那次作废」。

**Q:新仪器为什么还问「现在仍成立」?那不是作废理由吗?**
A:作废的是两句话绑在一起,不是「现在」三个字。假绿对照要测的是无工具时会不会把已死主张放行。改成「根据材料是否成立」能打出绿,但那是阅读理解,不是这个实验。所以只拆禁外信息句。

**Q:如果新 prompt 跑出来大量 unknown?**
A:对照不成立。说明这台模型在「现在还成不成立、手里只有旧摘录」时选择弃权,并没有假绿。产品变红相对于「弃权基线」成立,相对于「假绿基线」不成立。不许再改成蕴涵问法去救出叙事。

**Q:为什么通过线还是 4/4?你们不是只有 1/4 吗?**
A:1/4 来自作废运行,用来放宽就是 HARKing。通过线在跑之前写死,与 W1-1 同一份名单:c1/c2/c3/c7。

**Q:一次 temp=0 算证明吗?**
A:不算。这是仪器层冒烟。通过只表示这一次 4/4 假绿。不报方差,不说一期测量闭合。K3 才是判定层采样,而且还没跑。

**Q:为什么不新开 ADR?**
A:「事后改判据毁实验」已经在 ADR-0007。本票没有换构念。若当时选了蕴涵基线还继续叫假绿对照,那才满足难反转+反直觉+真取舍,要另开 ADR。我们没走那条。

**Q:must_unknown 盲判绿算不算对照破了?**
A:只记录。把它加成通过线,会像是看见作废运行里 c9 的 alive 之后补门槛。
