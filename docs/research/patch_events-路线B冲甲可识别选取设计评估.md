## 1. 问题 + 前置约束

### 1.1 要拍什么

在「冲甲」纪律目标下，打开结果甲的**可识别性**，并锁死功率/止损与仓外门闩。本题只决议，不跑正式数、不发模型、不写业务代码。

三道 frontier：

1. 固定 k 选取：R / S / S+R  
2. k 下限与止损句  
3. 仓外试分离门闩协议（是否已过、如何过）

### 1.2 目标分层（禁止混为一谈）

| 层 | 内容 | 承诺强度 |
|---|---|---|
| **纪律目标** | 打开甲的可识别性；新预注册；止损与功率条款；结果只抄 `compare_primary` | 必须做到 |
| **求验目标** | 结果甲 = T-C、T-B1、T-B2 均成立（点估计>0 且 95% 区间下界>0） | 尽量抬高概率，**不保证** |
| **诚实收口** | 乙或丙仍合法；规划与对外叙事必须预留 | 预注册允许 |

禁止把「设计冲甲」写成「将得到甲」。

### 1.3 前置约束（已被钉死）

| 约束 | 出处 | 含义 |
|---|---|---|
| `main` `a5e424c`（#416）后 RESULT：k=3；T-C 不成立；T-B1/T-B2 点估计 0 | `docs/evidence/patch-events/RESULT.md` | 旧链主比较未打开甲 |
| 现页固定 k：score 全空时 T/B1/B2 按同一 `claim_id` 取同一集合 → 差锁 0 | `compare_primary` / `_top_positions` | **甲不可识别**；只加 n 打不开 |
| 路线 A（#419–#430）整链废除 | 关单评论 | 禁止复活；禁止继续现 `PREREG.md`→n=100 冒充冲甲 |
| 旧 `PREREG.md` + 现 n=30 主证据链不得当冲甲主证据 | 用户指令 · 路线 B | 可作动机附录；禁止回写旧页凑甲 |
| `formal-generations.jsonl` 前 120 行与哈希冻结纪律仍适用**旧链** | #398 等 | 新跑用新文件/新针 |
| 检索另层；五处冻表面在甲未成立前不动 | 口径 / 开工闸 | 检索数不能证明放行闸 |
| 盲审附加预注册；完成前不得写真人盲审 | `DECISION-LOG.md` | 人轨另票 |
| 合法杠杆仅：可识别选取、T 相对 B1/B2 真实分离、足够大的 k/n、跑前锁死、禁止 HARKing | 用户指令 | 禁止金标进 score、削弱对照、夹具填甲、事后改成立定义 |

### 1.4 为何必须废路线 A（被否写透）

路线 A 的主张是：继续现有 `PREREG.md`，把 n 扩到 100，用阶段成功（乙亦算）收口。

在现实现下，固定放行数 k = T 自然放行数；T/B1/B2 在 `score` 全空时一律 `_top_positions` → 缺分排后、同分按 `claim_id` → **三臂选出同一 k 条**。误放率在相同集合上计算 → T-B1、T-B2 配对差恒为 0。n 从 30 到 100 **不改变「同集」结构**，故甲的三条主比较在结构上不可识别。路线 A 整链（#419–#430）已关；评估与后续票禁止复活。

Anthropic 清单对照：若在看见 B1/B2 为 0 之后，**不改可识别结构、只改成立定义或回写旧 PREREG** 追甲 = HARKing，直接否决。

## 2. 候选路线

### 2.1 大路线（已定方向，本票落文）

| 候选 | 内容 | 本票处置 |
|---|---|---|
| **路线 A** | 继续旧 `PREREG.md`→n=100 | **弃**（§1.4） |
| **路线 B** | 新预注册文件；声明旧页 + 现 n=30 主证据链作废（动机附录可留）；改固定 k 臂间选取以打开可识别性 | **拍板** |

### 2.2 选取维度：R / S / S+R

| 候选 | 定义 |
|---|---|
| **R** | 固定 k 从各臂**自然放行集**取样。m≥k：按跑前写死规则取 k；m<k：跑前锁死处置。 |
| **S** | 各臂用跑前可辩护臂分排序后 top-k。臂分不得使用 `construction_gold` / 评委标签 / 用户裁决。 |
| **S+R** | 组合（例如先分后自然集，或分不开时回退）。仅当单 R 在仓外试跑仍分不开 T-B1 时再加。 |

### 2.3 功率 / 止损 / 门闩维度

| 维度 | 候选 |
|---|---|
| k 下限 | (a) 5；(b) **10**；(c) 15；(d) 不设下限只靠 n |
| n | (α) 仍瞄 **100**；(β) 试分离证明后可更小并改预注册；(γ) 为凑甲无限加 n |
| 仓外门闩 | (i) **未过不得锁正式冲甲页 / 不得开正式生成**；(ii) 先锁页再试；(iii) 无门闩直接正式跑 |
| 正式主跑次数 | (1) **同一预注册只许一次正式主跑**（或写死至多一次预注册内复核条件）；(2) 看结果后改 R/S 再跑 |

## 3. 逐路线评估

### 3.1 R vs S vs S+R

| 维度 | R | S | S+R |
|---|---|---|---|
| 可识别性（空分同集病） | ✅ 各臂自然放行集不同 → 固定 k 集合可不同 | ⚠️ 依赖臂分；无分时退化回 claim_id 同集 | ✅ 更强，但更复杂 |
| 把策略差送进主指标 | ✅ B2 通常更松，自然放行差直接进入 | ⚠️ 分与 decision 共线时再抽回近似同集 | 同左，增量需仓外证明 |
| 金标/评委泄漏风险 | ✅ 不碰 score | ❌ 仓内尚无已辩护公式；易诱惑用金标/评委造分 | 同 S |
| 仓外可试 | ✅ 夹具/小 n 即可报自然放行与固定 k 误放差 | ❌ 须先有跑前可辩护臂分 | 仅当 R 不够时 |
| 实现缝 | 改 `compare_primary` 选取，不发明新分 | 要定义并冻结臂分 | 两套逻辑 |
| 面试「为何不选另一条」 | 见下被否 | 见下 | 见下 |

**被否 · S（本期）**：仓外/仓内均无「跑前可辩护、且不得含 construction_gold / 评委 / 用户裁决」的臂分公式。若用核验置信或与 `decision` 共线的量，易再次选出近似同集，可识别性假打开。S 仅当仓外已有可辩护公式时再开决议。

**被否 · S+R（本期）**：单 R 尚未做仓外试分离；无增量理由。若仓外显示 T-B1 在 R 下分不开，优先改 T/B1 机制或改冲乙，**禁止**用金标打分硬拆；仅在那时另开选取修订（新预注册，不回写本页）。

**被否 · 继续 score top-k（旧页）**：即路线 A 结构，差锁 0。

### 3.2 k 下限 / n / 门闩 / 主跑次数

| 维度 | 拍板 | 被否理由 |
|---|---|---|
| k 下限=10 | **拍板** | 5：功率过弱，bootstrap 丢弃风险高；15：在 T 偏严时可能长期触不到、逼出「降目标」前空转；不设下限：k=3 级再跑仍不可信 |
| n 瞄 100 | **拍板** | 无限加 n 不改预注册 = 禁；更小 n 须试分离证明并改预注册正文 |
| 门闩未过不得锁正式冲甲页 | **拍板** | 先锁页再试 = 把求验当成已承诺；无门闩 = 用不可识别或未分离结构烧正式主跑 |
| 同一预注册一次正式主跑 | **拍板** | 看结果改 R/S 再跑 = HARKing |

### 3.3 Anthropic 清单主动评审（原推荐修正）

| # | 清单项 | 对本案 | 处置 |
|---|---|---|---|
| 1 | 演示可过 ≠ 测量可信 | 仓外试分离 = 冒烟/可扔层；正式主张只来自激活后的新预注册主跑 | 评估与协议页分层写死 |
| 2 | 随机系统单次判生死 | bootstrap 10000；n=30 旧数只作结构锁零说明；小 n 仓外不报方差冒充 | 旧数禁止升格 |
| 3 | 「默认」不是规格 | 种子/流名/次数/选取规则显式写入协议页；托管端点漂移限制继承 | 实装 |
| 4 | 词表上下文无关 | 甲/乙/丙成立判据、k 下限数字细节留评估/协议页；CONTEXT 只收路线 B / R 选取 / 门闩产品级词 | 实装 |
| 5 | 判据预注册 | 门闩过之前不激活正式冲甲主跑；激活后不得改成立定义追甲 | ADR |
| 6 | 复现两层 | 确定性：选取、种子、流；随机：评委层容差继承旧纪律 | 实装 |

- 「夹具里把三臂集合填成能出甲」→ 伪造测量，否。

## 4. 拍板 + 逐项子决策

### 4.1 大路线

**路线 B**。新预注册；旧 `docs/evidence/patch-events/PREREG.md` + 现 n=30 主证据链**作废作为冲甲主证据**（可作动机附录）。禁止回写旧页凑甲。禁止复活 #419–#430。

### 4.2 选取 = R

**固定 k 从各臂自然放行集取样。**

子决策（跑前锁死，写入 `PREREG-B.md`）：

1. **k** := T 的自然放行数（与旧页「覆盖率对齐」语义同构，但选取不再走空分 top-k）。  
2. **m≥k**：在该臂自然放行集中，按 `claim_id` **升序**取前 k 条（确定性；不引入新随机流；不是置信 top-k）。  
3. **m<k**：该臂固定 k 误放率 = **无定义**；凡依赖该臂的主比较不得「成立」。  
4. **T 的 k < 10**：不得激活/主张冲甲正式主跑；主比较不得称为冲甲主张。  
5. **C**：同样从其自然放行集按上款取 k（不再用旧页 `coverage_c` 对全体候选随机抽 k 作为主比较选取）。`coverage_c` 流名可留位给非主比较，不参与路线 B 主选取。  
6. **S / S+R**：本期弃。仓外单 R 仍分不开 T-B1 时：优先改 T/B1 机制或改冲乙；若另决议 S，必须新预注册文件，不回写本协议。

### 4.3 功率 / bootstrap / 止损

1. **k 下限 = 10**。  
2. **n** 瞄准 100（样本框/配额由 `/to-spec` 抄入协议页；不得为凑甲无限加 n 而不改预注册）。  
3. **bootstrap**：次数 10000；种子 `20261007`；流名 `bootstrap`（与旧纪律同构，但消费对象是新选取下的指标）；成立定义重申：点估计>0 且 95% 区间下界>0。  
4. **止损**：正式主跑后若 T-B1 或 T-B2 的 false-accept 配对差**点估计 ≤ 0** → **不得称甲**；按乙或丙收口；**禁止**改选取/改成立定义后重跑同一预注册冒充原计划。  
5. **同一预注册只允许一次正式主跑**（预注册内复核条件若需要，必须在激活前写死；默认不设「看结果后再来一次」）。

### 4.4 仓外试分离门闩（当前：**未过**）

**状态**：本决议会话**未执行**仓外试分离 → **门闩未过**。

**协议（过门前强制）**：

1. 用与拟锁页一致的 R 规则，在仓外（不进主表、可扔）报告：  
   - T/B1/B2 自然放行数、自然误放；  
   - 按 R 取出的固定 k 误放率及 T 相对 B1、相对 B2 的差。  
2. **过门条件（同时）**：  
   - T 相对 B1 的固定 k 误放差方向为正；  
   - T 相对 B2 的固定 k 误放差方向为正；  
   - T 的 k ≥ 10。  
3. **未过门**：不得把 `PREREG-B.md` 从「协议/未激活」改为「冲甲正式主跑已激活」；不得开正式生成票；不得声称冲甲正式页已锁。  
4. **T-B1 分不开**：优先改 T/B1 机制或放弃甲（改冲乙）；禁止金标/评委打分硬拆。  
5. **k 长期 < 10**：禁止开冲甲正式页；先改 T 或降级目标（乙）并另写预注册。

### 4.5 反 HARKing 专节（见差为 0 后改选取）

**论证结构必须是**：

1. 旧 n=30 数字的唯一合法用途：说明在旧选取下存在**结构锁零**（同集 → 差恒 0），甲不可识别。  
2. 改的是「可识别性缺陷」（选取定义），**不是**「看见 B1/B2 为 0 之后改成立判据追甲」。  
3. 成立定义（点估计>0 且下界>0；甲/乙/丙分界）与旧 `DECISION-LOG` 同构继承，不放宽。  
4. 正式主张**只来自**新预注册激活后的新跑数；旧 RESULT 不得填入新主表成立格。  
5. 若门闩或正式跑失败，收口乙/丙，而不是改 R 公式再跑同一预注册。

违反任一条 = 违例级背离。

### 4.6 `/to-spec` 边界

| 允许 | 禁止 |
|---|---|
| 把本拍板抄入 `PREREG-B.md` 完整骨架（配额/算子/评委等继承条款） | 激活冲甲正式主跑（门闩未过） |
| 第一张工程票：`compare_primary`（或等价缝）按 R 选取；Acceptance 含「夹具上 T/B1/B2 固定 k 可不同」且「空分+claim_id 旧病被拒绝或不再适用」 | 复活 A 票；回写旧 PREREG |
| 样本名单/构造按新页 n（可与门闩并行准备） | 未授权发模型；正式生成产物进主表 |
| 人轨另票（盲审附加预注册、检索全库金标、「不能保持绿」另图） | 金标进 score；削弱 B1/B2；夹具填甲 |

**结论：可以 `/to-spec`**（缝 + 协议骨架 + 门闩前工程），**不可以**在门闩未过时开正式生成或宣称冲甲正式页已激活。

## 6. 面试讲法

**Q: 为什么废掉路线 A？不是已经有 PREREG 了吗？**

> 旧页在 score 全空时用同一 claim_id 序给 T/B1/B2 取固定 k，三臂同集，差锁 0。甲要求三条主比较都成立，结构上不可识别。把 n 加到 100 只放大同集噪声，不打开可识别性。所以 A 整链关掉，改走路线 B：新预注册 + 改选取。

**Q: 看见 B1/B2 差为 0 再改选取，是不是 HARKing？**

> 改的是可识别性缺陷，不是成立定义。旧数字只用来证明「同集 → 锁零」；甲/乙/丙与「点估计>0 且下界>0」不放宽。正式主张只认新页激活后的新跑。若正式跑仍点估计≤0，按乙/丙收口，禁止改公式重跑同一预注册。

**Q: 为什么选 R 不选 S？**

> R 直接用各臂自然放行集，B2 更松时集合差就是策略差。S 需要跑前可辩护臂分；仓内没有，且分一旦与 decision 共线，又会抽回近似同集。S+R 等仓外证明单 R 不够再另决议。

**Q: 为什么门闩未过还说可以 /to-spec？**

> /to-spec 做的是缝与协议骨架（compare_primary 按 R、夹具再现旧病被拒）。门闩挡的是「激活冲甲正式主跑」和「正式生成」。纪律目标先打开可识别性；求验目标在门闩与正式跑之后才可能发生，且不保证。

**Q: k 下限 10 会不会让你永远开不了甲？**

> 可能。那是止损，不是 bug。k 长期低于 10 说明 T 过严或样本不够分离，应改 T 或降级冲乙，而不是用不可信的小 k 宣称甲。

**Q: 旧 n=30 还能怎么说？**

> 只能说：在旧预注册选取下，主比较没有证明 T 更好；且结构上 T-B1/T-B2 差锁 0。不能把旧表抄进新主表成立格，也不能说统计成功关闭。
