## 现在以什么为准

检测顺序与操作定义:

1. **unverified**: 无 `source_ref`,或文档在 T0/T1 都不存在。不可核 ≠ 假。
2. **dead**: 对照 `source_ref` 的 T1 原文。无 T1 不下死事实。T1 写「从 99 降至 79」时,99 仍出现在原文也不算 live。
3. **contradictory**: 在未标 dead/unverified 的条目中,同属性且具体对象相交(或都未点名具体对象)时,数字冲突或反义共现。

论文路径:可发表的是 T1 锚定的 fail-closed 记忆闩及其测量,不是本文原列「算法名」。`must_quarantine` 必须按评估文档 §7 预注册后另提交填写,不得用一次 demo 回填。

原 §4–§6 的指标名词、研究假设、会议清单全部降级为未采纳草稿,不构成决议。
