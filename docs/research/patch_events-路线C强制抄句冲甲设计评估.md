## 1. 问题 + 前置约束

### 1.1 要拍什么

在路线 B 正式主跑已判**丙**、且机制（选取 R · 同 after · 对齐提示 · 门闩）已验证可过门的前提下，旁路再开一次冲甲：新预注册 `PREREG-C`，默认增量 = **强制抄证据句**，加大可辩护的 T 相对差；叙事收窄为 attested / copy-constrained。本题只决议，不跑正式数、不发模型、不写业务代码、不改 B 成立格。

四道 frontier：

1. 抄句强制点：构造算子 / 生成器 / 二者  
2. ALT 的 B1′ / 同文四闸：进 C 主表 / 仅附录 / 不吸收  
3. 门闩 n · 名单针；正式 n  
4. 对 B（RESULT-B 丙）的对外引用句与负结果附录写法  

### 1.2 目标分层（禁止混为一谈）

| 层 | 内容 | 承诺强度 |
|---|---|---|
| **纪律目标** | 甲可识别；新预注册；门闩；一次正式主跑；结果只抄同一次主比较 | 必须做到 |
| **求验目标** | 结果甲 = T-C、T-B1、T-B2 均成立 | 尽量抬高，**不保证** |
| **诚实收口** | 乙或丙仍合法；C 失败 → 关 C、删 C 分支；A/B/ALT 归档全留 | 预注册允许 |

禁止把「设计冲甲」写成「将得到甲」。禁止同页二次主跑。禁止改矮甲定义。

### 1.3 前置约束（已被钉死 · 勿装从零开始）

| 约束 | 出处 | 含义 |
|---|---|---|
| 旧 PREREG + n=30：T-C 不成立；T-B1/B2 曾差锁 0 | `RESULT.md` / 空分 top-k | 空分 + claim_id top-k **禁止**再作主选取 |
| 路线 A（#419–#430）整链废除 | 关单 | 禁止只加 n=100、不改选取就冲甲 |
| 路线 B：选取 **R**、k≥10、门闩、T/B1 **同 after**、L1 对齐提示 | #431/#432/#466 · ADR-0034/0035 | **整包继承为 C 默认基线**（本票明文改者除外） |
| B 抬 k 探针 gate_passed（k=11） | #479 | 证明对齐生成可过门闩；**探针≠甲** |
| B 正式主跑 **丙**：点估计>0，CI 下界均≤0；k=42 | #480 · RESULT-B | **效应偏小**为核心教训；B=**丙归档冻结** |
| ALT：夹具可分开；升级暂缓 | #435/#455 | 可读参考；C 不与 ALT 抢主表 |
| 不能假绿 / 检索金标另轨 | #446/#445 等 | 继续分层；检索 Recall 不得证明放行闸 |
| 甲定义 / 身份 | DECISION-LOG | 不改矮；模型评委+单人抽检；补定 draft ≠ 预注册原文 |

### 1.4 为何开 C 而不是同页翻 B（被否写透）

B 已过门仍丙：三条主比较点估计为正，但 95% CI 下界均 ≤0。结构上「比得动」（可识别、非差锁 0），统计上效应不够。同页再跑 B、降 CI、拿掉 B1 翻盘 = HARKing / 改矮甲，已禁。

合法动作只有：**新预注册**换增量假设（强制抄句），继承已证机制，一次正式主跑；失败则关 C、删 C 分支，不动 A/B/ALT 归档。

Anthropic 清单对照：若在看见 B 丙之后，**不换预注册、只改成立定义或同页二跑**追甲 = HARKing，直接否决。

## 3. 逐路线评估

### 3.1 Q1 · 强制点

| 维度 | (a) 仅构造 | (b) 仅生成器 | (c) 二者 |
|---|---|---|---|
| 相对 B 的可辩护增量 | 弱（近 L1） | 强 | **强且可跑稳** |
| 门闩 k 稳定性 | 中 | 低（不可抄→假阴性） | **高** |
| 产品叙事 | 含糊 | copy-constrained | **copy-constrained + 可构造** |
| 削弱对照风险 | 低 | 中（若连带松闸） | 须锁：不松 hard reject |
| 面试「为何不选另一条」 | 难答「为何再开 C」 | 易被追问假阴性 | 见被否 |

**被否 · (a)**：与 B 已做的生成对齐提示同族；B 已过门仍丙，只拧构造解释不了「旁路再冲」。

**被否 · (b)**：正确槽若证据句不可作 after，强制抄句制造结构性假阴性，门闩 k 与正式功率不稳。

**拍板 · (c)**：生成器对 T 做**硬契约**抄句（非软提示）；构造保证正确槽可抄；坏槽不改矮；B1 仍同 after 再分叉；不放松 T hard reject / 绑定 / 逐字核验。

## 4. 拍板 + 逐项子决策

### 4.1 大路线

**路线 C**。新预注册 `docs/evidence/patch-events/PREREG-C.md`。产物：`RESULT-C.md` · `formal-generations-c.jsonl`（或 `patch-events-c/`）。**不删、不改** A/B/ALT 归档。失败：关 C 票、删 C 分支。

### 4.2 继承包（默认基线 · 本票不改）

1. 选取 **R**（ADR-0034）  
2. k 下限 **10**；成立定义不放宽  
3. T/B1 **同 after 再分叉**（ADR-0035）  
4. 不放松 hard reject / 绑定 / 逐字核验凑 k  
5. 结果只抄同一次主比较；同一预注册一次正式主跑  
6. 禁止金标/评委进 score；禁止复活 A  

### 4.3 Q1 · 强制抄句 = 二者（生成器主）

1. **T 生成器**：`after_text` 由强制抄句契约产出，去空白后与请求内 `evidence_text` 逐字相同（硬契约，非 B 软提示）。  
2. **同 after**：B1 消费与 T 同一份 after，再分叉闸（绑定缝仍为唯一决策差）。  
3. **构造**：正确槽必须可抄；不可抄则槽作废换下一条。坏槽算子不改矮。  
4. **叙事**：对外称 attested / **copy-constrained** patch；不得称自由 rewrite 全面 SOTA / 优于 RARR·KPR。

### 4.4 Q2 · ALT 仅附录

主表四臂不变。B1′ / 同文四闸 / `compare_alt_*` 仅附录引用；不改主 `compare_primary` 追甲。

### 4.5 Q3 · n 与门闩

- 正式 **n=100**。  
- 门闩三条件同 B；须对 **C 机制** 新出可扔报告（如 `GATE-C-*.md`）；未过不得激活。  
- 名单以 `SPLIT-pe-v2.json` n100 为起点；实现票锁针。  
- 禁止写入 `formal-generations-b.jsonl` / 旧 `formal-generations.jsonl`。

### 4.6 Q4 · B 对外引用句（负结果附录）

> 路线 B（`PREREG-B` / `RESULT-B`，#480）在选取 R、T/B1 同 after、生成对齐提示齐备并过仓外门闩后，正式主跑一次：k=42；T−C / T−B1 / T−B2 点估计均 >0，但 95% CI 下界均 ≤0 → **结果丙**。说明「可识别 + 过门」≠ 甲；核心教训是**效应偏小**。B 全套冻结为丙归档；禁止同页二次主跑、禁止降 CI/拿掉 B1 翻盘。路线 C 另开 `PREREG-C`，增量假设为强制抄句加大可辩护 T 相对差；不保证甲。

### 4.7 `/to-spec` 边界

| 允许 | 禁止 |
|---|---|
| 锁 `PREREG-C` 协议骨架（未激活） | 激活正式主跑；发模型 |
| 规格卷 `26-…路线C…`；派工票 | 改 `PREREG-B`/`RESULT-B`/b jsonl |
| 第一张工程票：强制抄句生成缝 + 门闩夹具 | 未过门正式 n=100 进主表 |
| 人轨/ALT 附录指针 | 复活 A；改矮甲；金标进 score |

**结论：可以 `/to-spec`**；**不可以**激活或正式生成进主表。

### 4.8 第一张工程票（建议）

**标题意向**：T 强制抄句（copy-constrained）+ 同 after 继承 + 门闩复测夹具（C）。

**Acceptance（可执行，至少）**：

1. T 产出 after 去空白后与 `evidence_text` 逐字相同（契约/单测可证）；非仅提示词软约束。  
2. 同 after 上 T/B1 自然放行集仍可因绑定缝不同。  
3. 不放松 T hard reject / 绑定 / `verify_edit` 逐字语义。  
4. 可扔门闩报告格式与 R 一致；标明不进 `RESULT-C`。  
5. 不读密钥、默认不发网络；不激活 `PREREG-C`；不改 B 归档。

## 6. 面试讲法

**Q: 为什么 B 过门了还开 C？**  
A: 过门证明「比得动、k 够」；RESULT-B 丙证明效应偏小。C 换增量假设（强制抄句），不改甲定义、不同页翻 B。

**Q: 强制抄句是不是把题出简单了？**  
A: 产品叙事本来就是 attested edit；C **收窄**为 copy-constrained 并写进预注册。测量的是「抄证据句 + 绑定闸」相对无证/事后验的风险差，不装自由 rewrite SOTA。

**Q: 为什么不把 ALT 同文四闸并进主表？**  
A: ALT 升级暂缓；夹具可分开≠测量。并表会破防火墙、诱惑改主 `compare_primary` 追甲。

**Q: 失败怎么办？**  
A: 关 C、删 C 分支；A/B/ALT 丙/废归档全留。允许乙/丙收口；不保证甲。

**Q: 和 B 的 L1 对齐提示有何不同？**  
A: B=软提示；C=生成器硬契约必须产出与 evidence 逐字相同的 after，并有构造可抄保证。
