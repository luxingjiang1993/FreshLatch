## §拍板 + 逐项子决策

**拍板:D1-(A) + D2-(2) + D3-(α) + D4-(i) + D5-(σ)。**

1. **登记口径(可引用)**:K4、K5 均为 **demo 层工程缺口 / 未实装**;**不得**写成「已过」或测量失败证书。
2. **本图作用域**:只登记未过;不裁实装窗、不排期、不写代码。K4/K5 实装若做,**另开施工图**(不在本图 Destination 内)。
3. **§7.5**:不套用「工程失败 → 2 周窗」到 K4/K5;不因缺实装单独启动 §13 停止条件钟。
4. **K7**:维持「部分过」+「收口包未闭合」索引;归因含 K4/K5 未实装(及他票登记的未过项);禁止暗示 K7-1…4 字面因导出/token 失败。
5. **与 K6-4**:硬隔离,不连坐;#53 只裁 K6-4;#57 落档必须分条。
6. **词表 / ADR**:不新增;不新开 ADR。
7. **本工单**:不改代码、不改 gold/通过线、不关地图。

**给 #57 的依据句(本票交付)**:

> K4/K5:demo 层未实装,本图只登记;不启 §7.5 2 周钟;实装另开施工图。K7:子项可各自过/倾向过,收口包因 K4/K5(及他票未过)未闭合——索引陈述,非 K7-1…4 字面连坐。与 K6-4 分条,不合成一条「W5–W8 未过」。

## §面试讲法(grilling 预案)

**Q:K4/K5 没过,是不是该开两周修复窗?**
A:不。§7.5「工程失败」判例写的是 K1/K2/K3/K6,没写 K4/K5。缺的是 demo 层导出和 token 遥测,不是统计/行为测量失败。事后把未列项扩进止损钟 ≈ HARKing。本图只诚实登记「未实装」;要实装另开施工图,不绑 §7.5/§13。

**Q:那为什么 ACCEPTANCE_SUMMARY 还写「导出/token 缺则整包未收口」?是不是 K7 也没过?**
A:那是 **收口包** 的索引陈述,不是说 K7-1…4 字面因导出失败。K7 清单本身是作废名单/UI/MCP/单测;子项可以各自过或倾向过。包级未闭合必须写清归因(含 K4/K5 未实装),禁止暗示「K7-4 因为没导出所以红」。

**Q:和 K6-4 未过能不能合成一句「W5–W8 没过」?**
A:总判可以列多项未过,但处置和作用域必须分条。K6-4 是行为冒烟,#53 按 §7.5 裁;K4/K5 是 demo 缺件,本票只登记、不启同一口止损钟。跨条连坐违反 spec 09 作用域条款。

**Q:为什么本图不把导出和 token 做掉?**
A:本图 Destination 是诚实可引用状态,不是补齐 demo。做实装会把收口图变成施工图,决议边界崩。另开施工图再做。

**Q:为什么不新开 ADR?**
A:难反转的是预登记止损钟本身(已在 §7.5 / ADR-0007)。本次只是「未列项不扩钟 + 本图只登记」的作用域裁断,换一句登记即可反转,三条件不齐。
