## 1. 问题与诊断

**问题**: 在 `patch_events` 主实验上冲**结果乙**或**结果甲**(投稿映射见 `DECISION-LOG.md`),此前两档均未成立。

| 档 | 成立条件 | 投稿 |
|---|---|---|
| **冲乙** | 仅第一主比较成立:固定放行率下 T 误放率显著低于 C | arXiv + ACL Industry / Demo;贡献只写相对无证改写的 fail-closed |
| **冲甲** | T–C、T–B1、T–B2 三条都成立 | 同上 + 可冲 EMNLP Findings(须另补 2 名真人盲审附加预注册) |

「成立」= 配对差点估计 > 0 **且** 95% bootstrap 区间下界 > 0。

**当前读数(`RESULT.md`)**: `k=3`;T–C 点估计 ≈0.33、区间 `[-1,1]` → 不成立;T–B1 / T–B2 点估计 `0`、区间 `[0,0]` → 不成立。落在**结果丙**侧。

**根因分层**(非「理论无解」):

1. **`k=3`**: 逐字核验(`after.strip() == evidence`)过严 → 自然放行极少 → T–C 无功效。  
2. **T–B1 / T–B2 差恒 0**: **仪器坍缩**——`verify_edit` 恒 `score=None`;`compare_primary` 固定 `k` 按 score 在全候选排序,空分退化成 `claim_id` 字典序 → 三臂选同一批。`decision` 差异进不了主指标。  
3. 不是 attested 永远打不过 post-hoc;修好 score/拒识进池后差才**可测**。

## 2. 共享前置(乙甲都要做)

以下步骤是两条路径的公共地基。跳过则乙难过线、甲差仍可能结构性为 0。

### 2.1 新预注册(不得回改旧页)

对齐字段(参照 [Preregistering NLP](https://aclanthology.org/2021.naacl-main.51/)、[Preregistering for the Next LLM](https://ar5iv.labs.arxiv.org/html/2606.27687)、[Art of Abstention](https://aclanthology.org/2021.acl-long.84/)):

- decoding、种子流名、解析失败处置、eligible model  
- 声明旧 `PREREG.md` 作废关系  

### 2.2 仪器修复

| 项 | 动作 | 参照 |

## 3. 冲乙方案(整合版)

**目标**: 仅 T–C 成立。成功后主投 ACL Industry / Demo;不把 EMNLP Findings 当默认。

### 3.1 步骤

| 步 | 动作 | 参照 / 备注 |
|---|---|---|
| 乙-0 | 完成 §2 共享前置 | — |
| 乙-1 | 抬 T 正确放行:`k` 到可 bootstrap 量级 | 空 score / 逐字过严是主因 |
| 乙-2 | n=30 冒烟看 `k` 与 T–C 点估计方向 | 区间可能仍宽;不升格 |
| 乙-3 | **n=100** 正式判 T–C | 仓内满样本门槛 |
| 乙-4 | 只写结果乙贡献句;禁写优于 RARR/KPR | `DECISION-LOG` 结果乙 |
| 乙-5 | 投稿物料 | 见 §3.3 |

### 3.2 臂设定(乙只需对照 C 干净)

| 臂 | 乙阶段要求 |
|---|---|
| C | 无证、无核验、生成成功即放行;固定 `k` 仍用 `coverage_c` 随机对齐 |
| T | 入库 T1 绑定 + 核验不过 hard reject + 高分进固定覆盖 |
| B1 / B2 | 可跑通记账,但**不参与「乙成立」判决**;不必为乙强行差异化 |

### 3.3 投稿(乙)

| 轨 | 交付 | 参照 |
|---|---|---|
| ACL Industry | 部署/顾问发前约束叙事;显式 **human vs automated** 评测分工;可复现方法 | [ACL 2026 Industry](https://2026.aclweb.org/calls/industry_track/) |
| ACL Demo | ≤6 页 + 架构图/截图 + 评测(无评测可能 desk reject) + ≤2.5min screencast + 许可 | [ACL 2026 Demo](https://2026.aclweb.org/calls/system_demonstration/) |
| 负结果 | 若 T–C 仍不成立 → 结果丙:Workshop / 技术报告;Industry 欢迎 lessons learned | Industry 主题含 negative results |

### 3.4 Related Work 边界(乙)

- C 对照 = 无证据改写基线  
- 可点名但不宣称打赢:[RARR](https://arxiv.org/abs/2210.08726)、[KPR](https://arxiv.org/abs/2609.26634)、[ERASE](https://aclanthology.org/2025.findings-naacl.168/)——它们多管「答」或 KB 更新;本实验管「改不改」的放行风险  

### 3.5 乙成功可引用边界

> 仅表明:在新预注册与固定放行率下,T 相对 C 的误放率点估计与 95% 下界均 >0。不是一期产品已愈假绿,不是优于 RARR/KPR,不是 Findings 资格。

## 4. 冲甲方案(整合版)

**目标**: T–C、T–B1、T–B2 均成立。继承乙的全部地基,再拉开 B1/B2。

### 4.1 步骤

| 步 | 动作 | 参照 / 备注 |
|---|---|---|
| 甲-0 | 完成 §2 + 建议先过乙闸(或同跑但先看 T–C) | 乙不过则甲默认无定义路径按丙 |
| 甲-1 | **B1 真·事后**:先生成后验;阈值刻意松于 T,或无 chunk 绑定闸 | [RARR](https://arxiv.org/abs/2210.08726) · [RARR Unraveled](https://doi.org/10.1145/3726302.3730337)(agreement 最弱) |
| 甲-2 | **B2 真·软闸**:`decision` 恒放行;`score` 仍用核验置信,不过则低分挤出 top-`k` | [KPR](https://arxiv.org/abs/2609.26634);仓内 B2 设定 |
| 甲-3 | T 保持:绑定 + hard reject + 高分 | PIC fail-closed;ADR-0029 attested |
| 甲-4 | 确认固定 `k` 下三臂选出的集合已分化(非同一 `claim_id` 批) | 仓内仪器诊断 |
| 甲-5 | n=100 判三条;可选共形预留报误放上界(**不改**主比较判决) | [UniCR](https://arxiv.org/html/2509.01455) · [Conformal Abstention](https://arxiv.org/html/2405.01563) · [C-RAG](https://arxiv.org/abs/2402.03181) · [Selective CRC](https://arxiv.org/abs/2512.12844) |
| 甲-6 | 三条成立后:AIS 级双人盲审**附加预注册** → 才谈 Findings | 见 §4.3 |
| 甲-7 | 投稿物料 | 见 §4.4 |

### 4.2 臂设定(甲必须差异化)

| 臂 | 甲阶段要求 |
|---|---|
| C | 同乙 |
| T | 绑定 + hard reject + 高分 |
| B1 | 事后核验;**拒识策略 ≠ T**(更松阈值 / 无绑定),否则第二比较易再贴死 |
| B2 | 核验不过仍 `release`;低分不进 top-`k` → 固定覆盖下应更高误放 |

### 4.3 真人盲审附加页(仅甲 · Findings 前门)

不回写旧 `PREREG.md`。协议要素:

| 项 | 内容 | 参照 |
|---|---|---|
| 盲态 | 不见组别、不见系统名 | `DECISION-LOG` |
| 两阶段 | 先可解释性,再「是否完全可归因到所附证据」 | [AIS](https://arxiv.org/abs/2112.12870) · [指南与数据](https://github.com/google-research-datasets/AIS) |
| 人数 | 2 名真人;与「模型评委 + 单人抽检」分工写清 | `DECISION-LOG` |
| κ | 报 Cohen / Fleiss;复杂核验 κ≈0.65–0.68 仍可发表 | [FEVER](https://aclanthology.org/N18-1074.pdf) |
| 样本 | 附加页锁样本量与抽样规则 | — |

附加页完成前,对外仍只能写「模型评委加单人抽检」。

### 4.5 Related Work 边界(甲)

| 对照 | 角色 | 边界句 |
|---|---|---|

## 5. 统一执行顺序

```text
新预注册(score + 中文支撑度核验 + 拒识进池 + B1/B2 差异)
    → 核验敏感性闸(坏改算子)
    → 实装 + n=30 冒烟(k、三臂 fixed 集是否分化)
    → n=100 判 T–C                          …… 冲乙闸
    →(乙过)确认 B1 更松、B2 软闸后判 T–B1/T–B2 …… 冲甲闸
    →(甲过)AIS 双人盲审附加页 → Findings
    → 并行:Industry 叙事 + Demo 视频/截图(乙即可投)
```

**预期校准**(非保证):修好仪器后乙从「锁死」变为「可争」;甲从「差恒 0」变为「可测」,过线仍取决于核验排序与功效——不是极大概率,但**不是无解**。

## 8. Anthropic 清单自检(本方案)

1. **演示 ≠ 测量**:乙/甲成功句均「仅表明」;Demo 评测不得冒充 Findings 统计。  
2. **随机系统**:主比较靠 bootstrap;核验器若含 LLM 须锁 decoding 并登记端点漂移。  
3. **默认不是规格**:模型 id / 阈值 / score 公式进新预注册。  
4. **词表**:过程词(冲甲/冲乙/仪器坍缩)不进 `CONTEXT.md`。  
5. **止损预登记**:新页先于跑数;事后改阈值 = 作废。  
6. **复现两层**:配额/种子/公式确定性;API 评委近似。  
7. **ADR**:若拍板永久改核验语义且难反转,另开决议;本汇总页本身不替代 ADR。
