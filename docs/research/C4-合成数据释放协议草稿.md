## 1. 目的与非目的

| 目的 | 非目的 |
|---|---|
| 评测、演示、作品集附件、面试可审计引用 | 冒充真实市场/监管/报价情报 |
| 标明 synthetic 的合成语料与 gold | 法律意见、自动商业裁决、训练商用爬虫料 |
| 为**将来**对外分发预锁规矩 | 本文件存在 ≠ 数据集已对外可用 |

---

## 2. synthetic 标明（必须）

下列位置至少一处可见 **synthetic**（或中文「合成评测材料」），推荐多处同时标明：

- 课题包 README / 文件头元数据
- UI 使用内置合成评测包时（与 ADR-0016 T1 三卡一致）
- 对外附件或作品集说明（若进入分发）

未标明不得进入「可释放」候选。

---

## 3. 许可意向（占位）

- **草稿阶段**: **未选定** SPDX 许可；**未授权**第三方再分发本合成包。
- **对外释放前**: 必须选定 SPDX 标识（例：CC-BY-4.0 等）并写入本卡 §3 替换本占位句，否则不得宣称已释放。

---

## 4. 脱敏 / 合成声明

- 包内人名、公司名、报价、监管引用均为**虚构或公开常识改写的合成材料**。
- **禁止**纳入真实客户机密、未授权合同、真实报价 PDF 原文。
- 若未来误混入非合成材料：该版本不得释放；须剔除后重登本卡相关条款。

---

## 5. 对外分发边界

| 允许（仅在「已释放」成立后） | 禁止（无论是否释放） |
|---|---|
| 作品集/面试附件、带协议指针的公开镜像 | 声称「真实东南亚市场/真实供应商报价」数据 |
| 注明 synthetic + 许可的再分发（按所选 SPDX） | 用于训练未声明来源的商用爬虫/封闭模型语料而不附本协议 |
| 引用 gold 键形状做评测对照说明 | 把 backlog 未建包说成「多垂类已发布数据集」 |

---

## 6. 草稿 ≠ 已释放（操作句）

**默认: 未释放。**

「已释放」须**同时**满足，缺一不可：

1. 本卡 §3 已写入具体 SPDX 许可（占位已消除）；
2. 人在 GitHub 工单或 PR 中显式声明「批准释放」并给出**语义化版本号**（如 `synth-data-v0.1.0`）；
3. 实际对外分发物与本卡字段一致（含 synthetic 标明与范围仅限已批准包）。

把本文件或数据推进 `main` **不等于**已释放。

---

## 7. 评测纪律指针

- 评测期联网代码级禁用：继续有效（既有 harness 纪律）。
- 禁改 gold 凑绿：见 C3 卡 / ADR-0018；不得为释放或第二课题改第一课题 gold 凑绿。
- 软 Port / FP：见 ADR-0020；释放话术不得升格为「多垂类已 Port」。

---

## 8. 变更与作废

- 改本卡目的/边界/许可/释放门闩 = 须另开工单，声明旧草稿作废并重登。
- **若从未释放**: 版本号规则 N/A。
- **一旦已释放**: 不兼容变更须升主版本；仅澄清可升次版本；补丁级勘误升修订号。静默改卡而继续沿用旧「已释放」声明 = 该声明作废。

---

## 9. 本批明确不宣称

- 本卡落盘 ≠ 数据集已对外可用。
- P1 未建包前，不得预告「报价垂类数据集已发布」。
- δ backlog 不在本卡释放范围内。
