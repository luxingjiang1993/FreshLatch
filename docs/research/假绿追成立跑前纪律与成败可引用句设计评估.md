## §拍板 + 逐项子决策

**拍板:D1-(A) + D2-(A) + D3-(A) + D4-(1) + D5-(i) + D6-(x)。**

### 1. 成功句(canonical,4/4 alive 且不作废)

> 新假绿对照（qwen-flash，temp=0.0，seed=None，n=1，预登记仪器）仅表明 must_stale 假绿 4/4（c1/c2/c3/c7 全 alive）→ 对照成立；不是一期评测闭合，不是判定层已愈，不是可改 `gold.json` / 通过线，也不是产品已愈假绿（对照成立只说明无工具基线打出假绿）。

### 2. 失败句模板(未满 4/4 且不作废;替换 #56 句)

> 新假绿对照（qwen-flash，temp=0.0，seed=None，n=1，预登记仪器）仅表明 must_stale 假绿 {k}/4（{逐条:如 c1 unknown / c2 alive / …}）→ 对照不成立且不作废；不是仪器已证明产品无假绿，也不是可放宽 4/4 alive，也不是一期评测闭合。

### 3. 作废路径

- 触预登记作废线 → 落 `docs/evidence/w4/false-green-control-<date>-void.md`(对齐 #44 形态)。
- **不得**用该刀更新对照成立/不成立句;canonical 回退上一有效跑(现即 #56 句)。
- 作废**不消耗**「有效跑」名额;修到可跑后允许且**仅允许**再开一刀有效跑。
- 该有效跑若再作废 → 关图;不再同图补跑;另开努力。
- 有效读数(成功或失败不成立)一旦产出 → 本图有效跑配额用尽,不得再抽。

### 4. 跑前硬门闩(任一项红则禁跑)

1. `CONTROL_PROMPT` 与 `docs/evidence/w4/false-green-control-prereg.md` 锁定段逐字一致(含红线单测)。
2. decoding = qwen-flash / temp=0.0 / seed=None / n=1。
3. 不改 `gold.json`、不改预登记通过线/作废线/prompt 正文。
4. 本图尚未消耗「有效跑」配额(或处于作废后「允许补一刀有效跑」状态)。
5. 本决议已关;成功/失败/作废句已锁。

## §面试讲法(grilling 预案)

**Q:这图是不是又在重跑凑绿?**
A:不是收口图内钓鱼。#56 明确他日须同预登记另开努力;本图预算恰好一刀有效跑;未满 4/4 不得同图再抽。

**Q:4/4 了是不是假绿问题解决了 / 一期闭合了?**
A:不是。只表明这一次仪器冒烟打出 must_stale 假绿基线;产品必须相对该基线为红。禁升格。

**Q:又全 unknown 算不算作废?**
A:不算。作废只看矛盾 prompt / 红线 / unparseable / 事后改判据。失败句用新读数替换 #56 句。

**Q:作废了怎么办?**
A:落作废备忘,不改成立/不成立句;允许且仅允许再开一刀有效跑。再废则关图,另开努力。

**Q:为什么不新开 ADR?**
A:预登记纪律在 ADR-0007;作废/不成立二分在 #46;他日同预登记在 #56。本票只锁跑前句与门闩。
