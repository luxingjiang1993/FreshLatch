## §面试讲法(grilling 预案)

**Q:新假绿对照过了吗?**
A:没有。预登记仪器下 must_stale 假绿 0/4(全 unknown),对照不成立,不作废。唯一可引用句是评估文档里那条「仅表明」长句。

**Q:全 unknown 是不是又作废了?**
A:不是。作废只看矛盾 prompt / 红线 / unparseable / 事后改判据。校准后对「现在还成不成立」弃权,是预登记已写明的合法负结果。

**Q:那是不是说明产品没有假绿问题?**
A:不是。弃权基线下产品变红,相对「假绿基线」并不成立。不许写成仪器已证明产品无假绿。

**Q:为什么不再跑一刀?**

**Q:为什么不新开 ADR?**
