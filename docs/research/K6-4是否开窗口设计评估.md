## §拍板 + 逐项子决策

**拍板:D1-(b) + D2-(D′) + D3-(a) + D4-(a) + D5-(b) + D6-(b)。**

1. **本图不执行 K6-4。** 可引用句维持「K6-4（c5/c6 fresh 恢复,各 ≥2/3 且合计 ≥5/6,temp=0,n=3）已锁未执行」。不执行是范围,不是判定层读数,也不是放弃 must_fresh。「判定层冒烟未愈」维持,因为行为线确实还没跑。#27 前置已满足只进本票决议。
2. **通过句模板**(先于任何一次 K6-4 运行锁死;仅当未来测量图按 spec 09 跑完且通过线满足时方可引用):
   「K6-4（n=3，temp=0）仅表明 c5/c6 两条在冒烟层达到各 ≥2/3 且合计 ≥5/6 fresh；三次均为 temp=0，不作为运行间噪声估计，不是统计测量，不是一期评测闭合，也不改写闸层可复现、K3 已锁未执行、或其他 must_fresh / must_unknown 未测部分。」
3. **通过线一字不改。** 事后改 ≥2/3、改合计 ≥5/6、改 temp、把机制层 fresh 算进本线、或缺回归守线 = 该次运行无效。
4. **第三次重试**:K6-4 首次执行不是第三次重试。未达只许 K6-3 登记新背离;不得再改人格/提示词/探针凑绿;不得改 `gold.json`。
5. **词表**:不新增「开窗口」「通过句模板」「已锁未执行」。生产里判不出来。
6. **本工单不跑** LLM、不改 spec 09、不改 `gold.json`、不改 `CONTEXT.md`、不新开 ADR。
7. **本图终点**:「判定层冒烟未愈」不改成已愈;补上 K6-4 已锁未执行,与 K3 平行。在本图内跑 K6-4 划出 Out of scope。

## §面试讲法(grilling 预案)

**Q:K6-4 跑了吗?判定层愈了吗?一期评测闭合了吗?**
A:没跑。本图可引用的只有「K6-4（c5/c6 fresh 恢复,各 ≥2/3 且合计 ≥5/6,temp=0,n=3）已锁未执行」。判定层冒烟未愈。一期评测没有闭合。闸层可复现、K3 已锁未执行、2026-09-21 假绿对照不可引用,这几句也不变。

**Q:#27 都实装了,为什么还不跑?**
A:那只解开「线不启动」这道门,没有把这张改口图改成行为层实验。本图终点已经写了「判定层冒烟未愈」,又禁止升级成「判定层已愈」——在这张图里跑过且过线,改口违规,不改口撒谎。要数字就另开测量图,通过线一字不改,引用句用已经锁死的「仅表明」那句。

**Q:不跑是不是说明 must_fresh 已经放弃了?**
A:不是。不跑是范围,不是读数。未愈 = 行为线未跑。K6-4 仍是 spec 09 已锁实验。

**Q:如果以后 K6-4 过了,能不能说判定层已愈?**
A:不能那么说。K6-4 是 temp=0、n=3 的冒烟,三次不是运行间噪声估计。通过后唯一能摘的是「仅表明 c5/c6 两条在冒烟层达到各 ≥2/3 且合计 ≥5/6 fresh;三次均为 temp=0,不作为运行间噪声估计,不是统计测量,不是一期评测闭合,也不改写闸层可复现、K3 已锁未执行、或其他 must_fresh / must_unknown 未测部分。」c4/c8 等其他 must_fresh、must_unknown、K3 统计层都不被这条退休。

**Q:这不就是同一仪器第三次重试吗?**
A:不是。第三次重试禁的是人格/提示词/同端点语义探针(#21 0/6、#26 同错)。K6-4 是 #27 之后 Lead 被打回、真回 T1 同维度复验、再走双判一致。未达不许再改提示词凑绿,只许按 K6-3 登记新背离。

**Q:为什么不新开 ADR?**
A:事后改判据毁实验已经在 ADR-0007。同仪器三次重试已经在 ADR-0011。K6-4 通过线已经锁在 spec 09。本图不跑随时可以另开测量图,不满足难反转。我们禁止的是「K6-4 通过 = 判定层已愈」,那条如果当成产品行为才要新 ADR;本票把它锁成引用模板,不进词表、不改闸。
