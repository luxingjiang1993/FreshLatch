## 4. 拍板 + 逐项子决策

**拍板：2.1-(A) + 2.2-(A) + 2.3-(A)。**（#519 人令：按推荐）

### 4.1 `score` 公式族

| 状态 | `score` | 禁令 |
|---|---|---|
| **released**（`decision=release`） | 有限非空支撑置信；推荐 `s = P(entailment) ∈ [0,1]` | 禁止 `None`；禁止金标/评委/用户裁决进 score |
| **rejected**（hard reject / `decision=reject`） | **`−∞`**（浮点） | 禁止 `None` 混池；不得靠字典序进固定 `k` |
| **C 臂** | 无核验分 | 固定 `k` 仍 `coverage_c` |

- **默认针**：维持现行 `compare_primary` 对 T/B1/B2 的全体候选 `_top_positions` + reject=`−∞`。  
- **允许等价形**：先取自然放行集，再按分取前 k（reject 不进池）。预注册须写死采用默认针或等价形之一；**推荐默认针 (a)**。  
- **纪律**：高分只用于固定 k **排序**，不单独定义放行；放行 = 绑定闸 + 核验 `ok` + 臂策略。废止「score 继续为空」。

### 4.2 主核验 = 本地 mDeBERTa-v3 XNLI

- **型号**：`MoritzLaurer/mDeBERTa-v3-base-xnli-multilingual-nli-2mil7`（本地 transformers）。  
- **形**：`premise = evidence_text`（绑定 chunk），`hypothesis = after_text`。  
- **`ok`**：`argmax = entailment` **且** `P(entailment) ≥ τ`。  
- **`τ`**：跑前小标定锁死（构造正确/坏改对）；敏感性闸细则与通过线归 **#520**；禁事后放宽 τ 凑绿。  
- **released `score`**：`P(entailment)`；rejected → `−∞`。  
- **Limitations 必写**：MT 训练降低 NLI 质量；通用 NLI ≠ 法条支撑；不装法律域已校准（#521 事实句 1）。  
- **留位**：MiniCheck / AttrScore / SummaC / TRUE / ALCE AutoAIS / FActScore——本期不为主核验。  
- **标定/陷阱原料（非打分器）**：`verified-chinese-law-kb`、`legal-hallucination-bench` 供小标定与 #520 敏感性闸；不得装 FreshLatch 已过线。  
- **换卡**：未激活可 Amendment；激活后换卡 = 本预注册作废另开页。

### 4.3 B1/B2 记账与拒识口径（写入 Y，不为乙差异化）

- 乙成立 **只判 T−C**；B1/B2 报告-only。  
- **预注册抄死**（四臂共用同一 `verify_edit` 公式；差异只在闸）：  
  1. **T**：绑定失败 → reject；`ok=False` → **hard reject**；release → 非空有限 score。  
  2. **B1**：事后核验；`ok=False` → **hard reject**；**不要求**阈值/策略 ≠ T。  
  3. **B2**：核验不过 **不**因此 hard reject；`reverify_ok` 记账；可仍 release；release → 有限 score，reject → `−∞`。  
- 拉开 B1/B2 拒识 = **甲图**；本票 Out。

### 4.4 `/to-spec` 边界

- **可**：`verify_edit` 换 NLI；score 赋值；夹具证明 reject 不进固定 k；τ 配置缝；PREREG-Y 仪器 Amendment。  
- **不可**：激活主跑；回写旧 PREREG/B/C；金标进 score；把 #521 Acc 写入成立格；保证乙。

### 4.5 与 #520 的接口

本票锁：**公式族 · 主核验型号 · ok/score 映射 · 臂拒识口径**。  
#520 锁：敏感性闸坏改集合与通过线、n=30 冒烟看什么、激活门闩与 `GATE-Y` 关系；可**收紧** τ，不得与本票公式矛盾。

## 6. 面试讲法

**Q: 为什么不用 MiniCheck？它不是更贴 doc-claim 吗？**

> 形近，但一手材料 en only，无中文法律数字。当主核验 = 装过线。#521 已写清；本期留位，主闸用带 zh Acc 的本地 mDeBERTa。

**Q: rejected 用 −∞ 会不会和「高分≠放行」矛盾？**

> 不矛盾。放行仍由绑定+`ok`+臂策略决定；score 只服务固定 k **排序**。−∞ 的作用是：已被 hard reject 的样本不得靠 `None`→claim_id 运气挤进固定覆盖。

**Q: 为什么乙还要在预注册写 B1/B2 拒识？又不判甲。**

> 四臂仍跑通记账、仍抄同一次 `compare_primary`。不写死则实现易发明「乙也要拉开 B1」或误把 B2 改成硬拒。写的是**现状继承**，显式「不为乙强行差异化」。

**Q: mDeBERTa XNLI 0.803 是不是已经说明核验器够用？**

> 不是。那是通用 XNLI-zh，且卡内警告 MT 降质。法律但书/废止陷阱要靠小标定 + #520 敏感性闸。演示/仓外 Acc ≠ 乙成立。

**Q: 这能保证乙吗？**

> 不能。只保证仪器可测、reject 不进固定 k 的纪律。乙仍是求验目标。
