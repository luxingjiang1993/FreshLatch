| 前置 | 来源 | 锁死作用 |
|------|------|----------|
| 生产默认 BM25；改臂须增益门 + Hard-Gold | ADR-0003 / 0026 / roadmap Hard rules | 本波可建成 Hard-Gold **骨架**，**不**授权改臂 |

## 3. 逐路线评估

| 维度 | 拍板 | 被否理由 |
|------|------|----------|
| 形态 | **(a) 一阶段三轨** | (c) 层不同验收互替风险；(b) 缺清晰 Exit/地图位 |
| 生死线 | **① 冲 mid** | ③ 过重且与「骨架不改臂」冲突；④ 与无 Trigger 矛盾；② 可挂副产品但不作生死 |
| B′ | **A + 薄观测** | D 丢掉假绿口述；C 单独不够「不静默绿」；B 可加分非必须 |
| Hard-Gold | **A 不改臂** | B 把评测结果绑死产品变更；C 无面试可跑物 |
| #8 | **A 出处禁区** | C 缠 must_stale；D 违 Out；B 可二刀另票 |
| 命名 | **B I3** | A 易听成已换臂；C 地图弱 |
| 票序 | **B #8→B′→Gold** | 先最快 demo；Gold 最重后置 |
| 难金标 | **A 分文件** | B 糊层；C 空转 |
| 文档 | **A** | B 违四件套；C 过重 |

**Anthropic 清单命中（主动修正）：**
1. **演示可过 ≠ 测量可信**：I3 全档冒烟；Hard-Gold 骨架报告禁止升格「已证明该换臂」。  
2. **随机系统**：B′/ #8 硬门以确定性夹具为主；不绑单次 LLM 判 I3 生死。  
3. **默认不是规格**：增益门公式沿用 I0 预登记；解码参数若出现 e2e 须显式记录。  
4. **词表**：Hard-Gold / Policy-as-code / 政策拒进 CONTEXT；Phase 名与通过线数字不进 glossary。  
5. **预登记**：难金标 n≥20、traps/对抗≥30%、不改臂、Out 表 — **先于造数写死**。  
6. **复现两层**：确定性（政策拒、超时结构化错误、重入不双写、默认臂断言）逐位；随机层本波尽量不设。  
7. **ADR 三条件**：旁路 vs 塞 rule_gate、叫 Hard-Gold 却不改臂、三层一阶段 — 齐备 → ADR-0032。

**被否原推荐（写透）：**
- 「真融合一条产品主缝」——否：验收会用金标顶替 #8。  
- 「本波过线即改 `PRODUCTION_RETRIEVAL_MODE`」——否：违 ADR-0026；骨架 n 小装统计。  
- 「#8 塞进 `rule_gate` 同文件改不变量」——否：与既有闸语义缠死、难回滚。  
- 「无 Trigger 大开 B′ Memory/多 Agent」——否：roadmap Out。

## 4. 拍板 + 逐项子决策

1. **Phase I3**：一阶段 · 三轨 · 冲 mid；验收互不顶替。  
2. **主缝句**：「I3 交付可答辩的加固包：政策旁路能拒绿灯、Agent 假绿/重入不静默、难金标骨架可跑且默认臂仍为 bm25——三轨证据分列，互不顶替。」  
3. **#8**：声明式规则文件；首条 = **出处禁区**；Verify+ 旁路；≥1 可复现政策拒；不改 `rule_gate` 不变量语义。  
4. **B′**：timeout / 结构化错误 / 人审串行幂等各一刀 + 闸分布一页（CLI 或 MD）；合成夹具；不声称修真事故。  
5. **Hard-Gold**：完整规格落盘；`data/eval/retrieve_hard_gold.json`（名可微调）**n≥20**，traps/对抗类 ≥30%；分列臂 + 增益门复跑；**断言 `PRODUCTION_RETRIEVAL_MODE == "bm25"`**。  
6. **票序**：#8 → B′ → Hard-Gold → 联合 DoD。  
7. **层标签模板**（evidence 文首强制）：冒烟/面试加固；不报方差；非改臂授权；非政策平台；非已修真事故；Hard-Gold 页加「骨架·未授权改臂」。

### Exit 预锁（冒烟）

| 轨 | 硬条 |
|----|------|
| #8 | 旁路加载 ≥1 出处禁区；命中不得绿灯；可复现；未改 rule_gate 不变量语义 |
| B′ | 超时/假绿→结构化错误可见；人审重放不双写坏账；闸分布一页可生成 |
| Hard-Gold | 规格+难金标可跑+增益报告+默认臂仍 bm25 |
| 联合 | `docs/evidence/i3/ACCEPTANCE.md`；三轨分节；Out 未偷渡 |

### Out（偷渡一票否决）

改生产默认臂；宣称 Hard-Gold 已授权换臂；OPA/Cedar/政策平台；改写 rule_gate 不变量；Memory/多 Agent/跨 Provider 硬关门；Studio；C′/图谱/CMS；High-Recall 改默认；用 I3 替代 I1/I2；报方差/显著；导出前整包再验挂回发前钩子。

## 6. 面试讲法（grilling 预案）

**Q: 为什么三个不相关的东西塞一个阶段？**  
A: 冲 mid 要「政策能拒、演示不假绿、检索数字诚实」三句；一阶段省切换成本，但 Exit **分列**，金标过了不算 #8 Done。

**Q: 为什么叫 Hard-Gold 却不换 BM25？**  
A: Hard-Gold 是**讨论改臂的前置轨道**，不是改臂开关。骨架波先有难金标与增益判决；改臂另决议+过线。冒烟 n=36 更不够。

**Q: 政策拒和 stale 有什么区别？**  
A: stale/unknown 是新鲜度与证据充分性；政策拒是声明式禁区（如出处）即使证据「新」也不得绿。旁路装载，不改 rule_gate 不变量正文。

**Q: 没有真事故为什么做 B′？**  
A: 合成夹具预装最小 hardening + 观测页，标的是「面试不翻车」，诚实声明不是生产事故复盘。Memory/多 Agent 仍不做。

**Q: 这算安全认证或检索 SOTA 吗？**  
A: 不算。层身份冒烟/面试加固；不报方差；不授权换臂；不是政策平台。
