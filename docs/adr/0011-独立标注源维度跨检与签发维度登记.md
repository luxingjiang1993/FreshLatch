# ADR-0011: 独立标注源维度跨检与签发维度登记

- **状态**: Accepted(2026-09-21,工单 #28 拍板;#25 前置约束 5 / #19 §4.4
  pre-registered 条款的当场执行,owner 指令闭环)
- **修订关系**: **增补 ADR-0010**(维度核对条款分账:机械跨检为主、不变量 7
  兜底未登记主张);ADR-0010 其余条款、ADR-0009 全部条款一律不动,继续有效。
- **相关**: 工单 #28 评估见 `docs/research/stale路径维度混淆独立标注源设计评估.md`;
  #26 行为验收(e3b3132,通过线① 1/6,双层语义同错成立);
  #25 `docs/research/stale路径双人防线重开设计评估.md`(本候选的预登记出处);
  ADR-0010(不变量 7 与 stale 路径双人防线);ADR-0009(双判一致);
  ADR-0008(不变量 6,机械预检同构先例)。

## 背景

#25 拍板的丙′机制(Auditor 进驻 stale 路径 + 不变量 7 维度异议打回)经 #26 行为验收:
Auditor 在场 5/5,但对 c5 维度混淆反证 `dimension_match=true` 与 Lead **同错**,
不变量 7 零触发、dissent 全程 null——第二判与第一判共享盲区(同端点同源),
通过线① 1/6 未达成。#25 §4.6-6 预登记锁死判别触发:停止同仪器第三次重试,
重开 grilling 评估预登记候选「独立标注源机器跨检」。本 ADR 是该候选的落地拍板。

与 #25 否掉的机器闸③(乙)的本质区别(评估文档 §3 四差异,缺一即是乙重演):
①比对锚外部化——登记维度是**签发时人工标注**的结构字段,不经复验模型之手;
②问法换锚——反证维度字段问的是「反证自身攻击的维度」(可独立验证的证据属性),
不是「与主张是否同维度」(不可验证的关系声明);③**登记维度对复验模型不可见**——
Critic 填字段时无锚可照,「照锚填字段」的对策不成立;④归因预验——行为验收判别
写明「机械层零触发不算赢」,bundle 绿不等于独立标注源这一层生效。

## 决议

### 1. 签发维度登记(独立标注源的实体形态)

`t0_docket.json` 每条主张增 `dimension` 字段,封闭枚举同 `FOCUS_DIMENSIONS`
六值;`Claim` dataclass 与 `load_docket()` 同步增字段,`load_docket` 对非法值
硬拒绝(签发即校验,坏卷宗不进系统)。人工编辑卷宗 = 人工标注:标注者是签发人,
维度标签是签发动作的结构延伸,不经任何复验模型之手。schema 版本化照仓内惯例
(直接改 + 幂等,不造迁移框架),变更登记于评估文档。存量主张人工一次性回填
(依据规格 §2.6 + gold `why_fresh`),回填完成是行为验收的硬前置。

### 2. 反证强制携带维度字段

`mark_stale` 两侧镜像(Critic / Lead)同步增必填参数 `dimension`,六枚举硬校验
整段复刻 focus 形态(非法值整 call 拒绝、回列词表、重试计步——强制性住边界,
不住模型服从)。字段语义 = 「本反证自身攻击的维度」;**登记维度不注入 Lead/Critic
上下文**(闸层独享比对锚)。

### 3. 规则闸不变量 8:维度机械跨检

stale 分支内,位置 = 不变量 6(元陈述闸)之后、Auditor 依赖项之前(同属「反证包
质量」机械预检层)。`claim.dimension ≠ stale_dimension` → 纯字符串比对打回,
error_code = `DIMENSION_CROSSCHECK_MISMATCH`,路由 **unknown + 异议记录**——
异议内容 = 机械比对事实(登记维度 X vs 反证自标维度 Y),纯结构、零模型意见,
随黄卡进 HumanLatch。**两维任一缺失 → 跳过不变量 8,回落不变量 7**(fail-soft
回到丙′,不是裸奔;真 stale 不得被未标注主张憋死)。打回路由整段复用
`arbitrate_stale_mark` 形态;fresh×stale 平行路径走同一闸自动覆盖;
GateDecision 增两字段(登记维度、反证维度)。

### 4. 与 ADR-0010 的并轨关系

不变量 7(Auditor 语义维度异议)全条款保留,职责收窄为「**未登记主张**的维度
防线」。#26 证「Auditor 与 Lead 同错」——同源性论据支持「不当唯一防线」,
不支持「拆除」;回填窗口内机械跨检无锚可比对,不变量 7 是该窗口的唯一维度防线。
Auditor EvidencePacket 不动(fallback 走语义核对,不需要机械字段)。

### 5. 行为验收 pre-registration(判定人触发,事后改 = 作废)

锁定于评估文档 §4 子决策 6,继承 #25 §4.6-6 口径:通过线① c5/c6 ≥4/6 非 stale
落档;② c1/c2/c3/c7 各 3/3 落 stale;③ 无双判一致的 fresh(违例级一票否决);
n=3、temp=0、qwen-flash 显式锁定,冒烟读数框定(1/3 翻转基率,不报方差)。
**归因登记**:每次拦截落 error_code 区分机械(`DIMENSION_CROSSCHECK_MISMATCH`)
与语义(`DIMENSION_MISMATCH`);**①达成但机械层零触发 → 判「候选机制未生效」,
不宣告胜利**。**锁死判别(终点预登记)**:①未达成 → 停止机器防线第四次重试,
维度防线终点移交 HumanLatch(黄卡强制维度对照),评测侧按 c9 形状登记为
「该端点维度混淆不可机器修复」已知边界。本修复**不背负** c5/c6 ≥2/3 fresh
金标线(fresh 是 Lead 复验行为层 #27 的账)。

## 后果

- 词表:新增 **登记维度**(CONTEXT.md);**规则闸** 词条不变量清单 touch-up 增
  第 8 条指针。error_code 词表 +1(`DIMENSION_CROSSCHECK_MISMATCH`)。
- 实装:新实装单(bundle:签发字段 + 反证字段 + 闸不变量 8 + 存量回填);
  行为验收独立触发、独立判读(同 #25 不攒批纪律)。
- **事后修改本 ADR 的不变量(撤销跨检、放宽打回、让登记维度对模型可见)等于在
  保留「独立标注源已验」叙事的前提下拆机械防线,W5–W8 及后续窗口的实验意义
  随之作废——修改必须走新评审工单并明示受影响窗口**(与 ADR-0009/0010 后果
  条款同构)。
- 残余盲区如实登记:Critic 故意填错维度值时机械层仍穿透;归因读数(子决策 5)
  是这一盲区的验证仪器,若验收显示字段被对策化,按锁死判别终点处置,不再第
  四次机器重试。
