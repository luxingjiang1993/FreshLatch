# ADR-0015: 客户向复验备忘字段集

- **状态**: Accepted
- **日期**: 2026-09-22
- **相关**: grill-with-docs Batch 0+1、docs/research/C1-Batch0-1预登记卡.md、CONTEXT「客户向复验备忘」

## 背景

Batch 1 要把复验产出做成可转发附件。若字段集事后随演示加戏（塞入 Agent 轨迹或「建议进入/不进入」），会同时毁掉 Export rubric 预登记与品类边界。满足 ADR 三条件：难反转（绑 DEM-3）、反直觉（轨迹看起来「更专业」）、真取舍（可读交付 vs 审计完整度）。

## 决策

客户向复验备忘（Client Memo）**必填**：课题问题句、生成时间、免责声明、三分栏（仍成立 / 已作废 / 缺口）、每条 claim_id + 一句话理由、可点回的 evidence_id（可含 #anchor span；首版不做字符偏移）。

**明确排除：** Lead/Critic 轨迹摘要；任何「建议进入/不进入」类商业裁决。轨迹属内部审计导出 / 审计视图，不进 Client Memo。

## 后果

- 预登记卡 DEM-3 / INV-2/3 以本字段集为单一真相。
- 事后增字段须新预登记或新 ADR；不得静默加分项通过 DEM-3。

## 替代方案（被否决）

- **备忘含轨迹**：客户附件噪声，且默认泄漏角色名。
- **备忘含商业建议**：品类自杀（禁止自动商业裁决）。
