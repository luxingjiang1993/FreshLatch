# ADR-0034: 生产补丁/放行 SLO 与实验—生产防火墙

- **状态**: Accepted
- **日期**: 2026-10-09
- **相关**: `docs/research/生产补丁放行SLO设计评估.md`、`docs/ops/生产补丁放行SLO.md`、ADR-0027、ADR-0029、ADR-0031、ADR-0023、ADR-0006；路线 Y 结果丙（PREREG-Y / RESULT-Y 只读冻结）

## 背景

发前闭环已有 Evidence-bound 补丁、HumanLatch、发前钩子与评测北星，但生产侧缺少可执行的数字 SLO / 观测分层。实验侧路线 Y 主跑已判**丙**（过闸≠改对）。若不钉「运营页真源 + 与实验乙尺防火墙」，易把生产看板变绿误读为 RESULT-Y 改判、同页二跑凑乙，或把金标塞进在线放行/生产 score。

三条件齐备：难反转（后续运营票与双管另页将引用本分层与防火墙）；反直觉（实验有尺却**禁止**当生产 KPI；生产变绿**不得**改判丙）；真取舍（硬防火墙 vs 同页兼写；观测起步 vs 立刻全表硬 %；金标离线 vs 在线刷分）。

## 决策

1. **运营真源**：生产补丁/放行/人审/复验纪律落 `docs/ops/生产补丁放行SLO.md`。评估见 `docs/research/生产补丁放行SLO设计评估.md`。规格见 `docs/spec/24-生产补丁放行SLO.md`。
2. **实验—生产防火墙**：  
   - 不得修改或回写 `PREREG-Y` / `RESULT-Y` / `formal-generations-y` 成立格或正文以「跟生产」。  
   - 禁止同页二跑凑乙；禁止称甲 / 软甲 / 接近乙 / 主实验成功（相对 Y）。  
   - 生产 SLO 改善 ≠ 自动改判乙。机制大改 → **新预注册另页**。  
   - 固定 k 误放 / T−C 等乙尺 **实验-only**，不进生产 KPI。
3. **指标分层**：  
   - **硬闸不变量（目标=0 或 100%）**：无证拒拦；未确认不出门；Agent 自红转绿=0；无 T1 绿灯=0；续命必须带新 T1。  
   - **观测 / Watch**：改对率、错改率、再验失败率、误放/误拒成对、作废率、override rate、包结论分布、补丁后仍勿发/需补丁占比等。  
   - **离线评测轨**：must_stale / must_fresh multi-run；**金标不得进生产 score 或在线放行器**。
4. **起步阈值（预注册）**：不变量如上；确认后严重错改抽检本波 **观测-only**，Watch 讨论线 &lt;5%（样本协议未齐前不作 Gate 生死）；must_stale multi-run 不得低于当前金标/Hard-Gold 门。事后改门槛凑绿 = 作废重签。
5. **叙事**：本页是运营与产品纪律，不是 `patch_events` 冲乙。北极星仍是 must_stale 与作废率。
6. **实现授权**：本 ADR **不**授权本会话写业务代码；实现须经 to-spec → tickets → before-implement。

## 后果

- to-spec / 运营票须引用本 ADR 与运营页。  
- 任何将生产数字填入 RESULT-Y 成立格、或把金标当生产放行器的提案，视为违例。  
- 升「严重错改 &lt;5%」为 Gate 须另决议（人标协议齐备后）。

## 替代方案（被否决）

- 生产 SLO 挂在 `docs/evidence/patch-events/` 并兼写乙尺。  
- 生产变绿则回写 RESULT-Y 为乙 / 软乙。  
- 以放行率单独升高为成功。  
- 金标进在线 score。  
- 本波对全部观测指标立刻下硬 % Gate。  
- 并入修订 ADR-0029（补丁 API 与运营纪律糊缝）。
