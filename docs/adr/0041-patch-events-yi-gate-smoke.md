# ADR-0041: patch_events 冲乙门闩与冒烟功率（敏感性前置 · n30 · GATE-Y 继承）

- **状态**: Accepted
- **日期**: 2026-10-10
- **相关**: `docs/research/冲乙门闩与冒烟功率条款设计评估.md`；[#520](https://github.com/luxingjiang1993/FreshLatch/issues/520)；父图 [#517](https://github.com/luxingjiang1993/FreshLatch/issues/517)；载体 ADR-0039 / #518；仪器 ADR-0040 / #519；先验 `GATE-Y-PROBE` / ADR-0037
- **说明**: 编号顺延开 PR 上的 0034–0040 之后。本文件只钉激活前序与通过线；不改正式 n、不改乙成立尺（点>0.05）、不授权本图内正式主跑。

## 背景

升格未激活 `PREREG-Y` 已锁 n=400 与成立尺；仪器最小集已锁 NLI 与非空分。激活前仍缺：核验敏感性可执行通过线、n=30 冒烟看什么、以及相对既有 GATE-Y 在仪器修复后的继承/差异。B/C 有「过门仍丙」先例——门闩过 ≠ 乙成立。

三条件齐备：

- **难反转**：后续敏感性夹具、SMOKE、GATE-Y 人令与 `/to-spec` 将引用本前序；事后放宽 ρ 或夹具升格过门会使激活纪律作废。
- **反直觉**：过门仍用点>0，不用正式乙的 0.05；冲乙不判 B1/B2 却在冒烟检测三臂坍缩。
- **真实取舍**：敏感性硬前置 vs 直接探针；冒烟独立层 vs 升格过门；方向门 vs 成立尺门。

## 决策

1. **敏感性闸（硬前置）**  
   - 报告：`GATE-Y-SENSITIVITY.md`（可扔）。  
   - 集合 S：构造坏槽（四层×mod4）+ 有限废止/版本陷阱 + 正确对照；名单/规则跑前写死。  
   - 通过须同时：无 `score=None`；reject=`−∞`；坏→`ok=False` ≥0.90；正确→`ok=True` ≥0.70；型号/τ=ADR-0040。  
   - 未激活失败：可收紧 τ **一次**并整闸重测；禁止放宽 τ 凑绿。  
   - 未通过 → 不得真数据探针、不得激活、不得正式跑。

2. **n=30 冒烟（可扔 · 不作过门）**  
   - 报告：`SMOKE-Y-N30.md`。  
   - 必看：T 自然 k；T−C 固定 k 差点估计方向；T/B1/B2 fixed-k `claim_id` 集是否完全相同（`collapse=true` → 停）；score 卫生；B1/B2 差必报不过条件。  
   - 防火墙：不进 RESULT-Y；不构成 `gate_passed`；区间不写总体；不保证乙。

3. **激活门闩（继承 GATE-Y + 增量）**  
   - **继承**：`gate_passed` ⇔ k≥10 ∧ T−C 点估计>0；B1/B2 不过门；真数据 `GATE-Y-PROBE`；禁升格 `#479`/GATE-K/C/夹具/冒烟/RESULT-B/C。  
   - **增量**：机制针须齐 ADR-0040；敏感性通过为探针硬前置。  
   - **人令序**：① 缝齐 → ② 敏感性通过 → ③ 可选夹具 → ④ n30 冒烟 → ⑤ 探针人令 → GATE-Y → ⑥ 人审过门 → ⑦ 激活批注 → ⑧ 正式主跑人令 → ⑨ 一次 formal-y（n=400）。  
   - 探针人令默认：「授权路线 Y 仓外探针发模型；不得激活。」  
   - 过门用点>0（方向），**不用**正式乙点>0.05。

4. **词表**  
   - `CONTEXT.md` 可收「GATE-Y 敏感性前置」；ρ/冒烟细则不进词表。

## 后果

- 地图 #517 三决议票齐 → 可开 `/to-spec`（仍不激活、不保证乙）。  
- 违例：夹具/冒烟升格过门；放宽 ρ/τ 凑绿；过门改 0.05；Agent 自行激活；同页二跑。

## 替代方案（被否决）

- **无固定敏感性通过线**：不可执行。  
- **#521 Acc 当过线**：装过线。  
- **冒烟升格过门/乙**：门闩倒置。  
- **过门 Cond 改点>0.05**：层混淆。  
- **夹具绿 / 旧 GATE-K/C 升格**：禁令。
