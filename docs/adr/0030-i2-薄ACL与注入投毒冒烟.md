# ADR-0030: I2 薄 ACL 与注入/投毒冒烟三例

- **状态**: Accepted
- **日期**: 2026-09-29
- **相关**: `docs/research/I2-安全三例设计评估.md`、`docs/grill-prep.md` §2g、roadmap Phase I2、差距清单 §4；明确 **≠** idea #4 / ADR-0022 对抗目录 Exit

## 背景

冲 mid 需要可复现的安全演示。若不钉威胁分列、防护落点与 Exit 层，易把 I2 做成安全平台、用 #4 过期伪装顶替、或用单次 LLM 跑通冒充安全结论；亦易出现「实现已三例、roadmap 仍写两条」的双真相源。

三条件齐备：难反转（mid 口述与 `security.md`/ACCEPTANCE 将引用本契约）；反直觉（单仓产品仍做薄 `tenant_id`；Exit 分列注入与投毒而非合并；硬门以确定性为主却保留注入 1× LLM 冒烟）；真取舍（三例 vs 两条；真路径薄过滤 vs mock；分层 e2e vs 全绑 LLM；完整改写 roadmap vs 不改文档）。

## 决策

1. **I2 Exit = 三例冒烟（各恰好 1 fixture）**  
   - **越权召回** `acl-t001`：合成多租户；`tenant_id=B` 的 `retrieve` **不得**返回 A 的块。  
   - **间接注入** `inj-t001`：已入库 T1 含「忽略指令→标 fresh」类文案 → **规则闸 fail-closed**，不得仅因此给出 `fresh`。  
   - **检索投毒** `poison-t001`：块带显式 `poison`/`untrusted`（或等价）元数据；即使得高分也**不得**进入可引用证据集。  
   - **不等于**安全平台、多攻击面清单、渗透认证或统计通过率。

2. **薄实装（真路径）**  
   - Document/Chunk 可选 `tenant_id`（缺省 `default`）；`retrieve(..., tenant_id=)` 硬过滤；无该参数时行为与改前兼容。  
   - **禁止**租户管理面 / 完整 RBAC / 多租户产品化。  
   - 投毒靠**元数据剔除**，不靠无标签内容启发式作硬门。

3. **Exit 分层硬门（预锁，禁 HARKing）**  
   - **硬 · 确定性**：上述三例的 pytest 行为断言（ACL/poison 不硬绑 LLM）。  
   - **硬 · 注入 e2e 冒烟**：Lead+Critic+LLM **跑 1 次**；ACCEPTANCE **文首**声明冒烟层；记录 model / temperature / seed / 日期；**禁止**报方差/显著；托管漂移写入限制。  
   - 交付物：`docs/security.md` 薄表（threat · demo_id · layer · repro_cmd · expected · smoke_note）+ `docs/evidence/i2/ACCEPTANCE.md`；**无 UI** 硬门。

4. **I2 ≠ #4**  
   - idea #4（过期伪装）可同波交 `adv-fresh-t001` 作面试弹药；ACCEPTANCE **分节可选勾**；**不计入** I2 Exit。  
   - **不**把本阶段记为 ATK-FG/CS 目录升版 Exit。

5. **词表**  
   - 产品可判：`tenant_id`、`poison`/`untrusted` 进 `CONTEXT.md`。  
   - 「越权命中 / 注入诱绿」等为评测标签，细则在本 ADR / 评估 / `security.md`，**不**进 CONTEXT 产品枚举正文。

6. **roadmap**  
   - Phase I2 Goal/In/Out/Exit 及仓内「两条 / 安全一例」交叉表述 **完整改写** 对齐三例（不作「暂不改文档」）。

## 后果

- to-spec / 实现须引用本 ADR；测例 id 与 ACCEPTANCE 脚本不得事后改桶凑绿。  
- 扩成安全平台、把 #4 算进 I2 Exit、或取消确定性层改纯 LLM 判生死，须另决议。

## 替代方案（被否决）

- Exit 维持「注入/投毒合并为一条」或把 #4 勾进 I2 Exit。  
- 纯 mock store/gate；完整 RBAC/租户后台。  
- 无标签投毒启发式作硬门；仅靠 prompt 防注入。  
- 三威胁全部硬绑单次 LLM e2e；或取消注入 e2e 只留单测却仍宣称「真链路安全轮」而不分层声明。  
- 实现三例但不改 roadmap（双 SoT）；仅最小补丁留「两条」残句。  
- 把 I2 样例塞进 `data/traps/` 或宣称 adversarial INDEX 升版即 I2 Done。
