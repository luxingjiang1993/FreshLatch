# ADR-0042: 生产补丁/放行 SLO 与实验—生产防火墙

- **状态**: Accepted（防火墙与分层继承 #508 草案；编号顺延）
- **日期**: 2026-10-09 草案 · 2026-10-12 按 tip `2a3fadd` 改编落盘（#557）
- **相关**: `docs/ops/生产补丁放行SLO.md`、`docs/ops/生产观测最小6-索引.md`、`docs/spec/24-生产补丁放行SLO.md`、ADR-0027、ADR-0029、ADR-0031、ADR-0023、ADR-0006、ADR-0028；路线 Y 结果丙（`PREREG-Y` / `RESULT-Y` 只读）
- **编号**: [#508](https://github.com/luxingjiang1993/FreshLatch/pull/508) 草案文件名是 `docs/adr/0034-生产补丁放行SLO与实验防火墙.md`。tip 上 `docs/adr/0034-patch-events-route-b-identifiable-fixed-k.md` 已存在。本文件用 **0042**（继 ADR-0041 之后），不覆盖 0034，不改已接受的 patch-events ADR。

> **生产观测 ≠ 乙尺。** 本 ADR 落盘未编辑 `RESULT-Y` / `PREREG-Y` / SESOI。

## 背景

发前闭环已有 Evidence-bound 补丁、HumanLatch、发前钩子与评测北星，但生产侧缺少可执行的数字 SLO / 观测分层。实验侧路线 Y 主跑已判丙（过闸不等于改对）。若不钉「运营页真源 + 与实验尺防火墙」，易把生产看板变绿误读为结果页改判、同页二跑凑绿，或把金标塞进在线放行/生产 score。

2026-10-12 的 min-6 grill 把本波观测收口为 6 个 SLI。宽表仍是 #508 的 program draft。本 ADR 记录防火墙与分层；成员表以索引为准，避免两套主名单。

三条件齐备：难反转（后续运营票与双管另页将引用本分层与防火墙；事后把生产数字填进结果页会使防火墙作废）；反直觉（实验有尺却禁止当生产 KPI；生产变绿不得改判丙）；真取舍（硬防火墙 vs 同页兼写；观测起步 vs 立刻全表硬百分数；金标离线 vs 在线刷分）。

## 决策

1. **运营真源**：宽表纪律落 `docs/ops/生产补丁放行SLO.md`。本波收口索引落 `docs/ops/生产观测最小6-索引.md`。规格见 `docs/spec/24-生产补丁放行SLO.md`。评估全文留在未合并 #508 @ `b24b6f5`，本 ADR 不复制该评估，以免双真源。交付真源是 #556/#557 与索引。
2. **实验—生产防火墙**：  
   - 不得修改或回写 `PREREG-Y` / `RESULT-Y` / `formal-generations-y` 的成立格，也不得改 SESOI / \(k_{\min}\) / Cond / 选取 R。  
   - 禁止同页二跑凑绿。禁止把本生产观测称作乙、软乙、接近乙或主实验成功。  
   - 生产观测改善不得自动改判丙。机制大改走新预注册另页。  
   - 固定 k 误放 / T−C 等实验尺保持实验-only，不进生产 KPI。
3. **指标分层**：  
   - **硬闸不变量（目标=0 或 100%）**：无证拒拦；未确认不出门；Agent 自红转绿=0；无 T1 绿灯=0；续命必须带新 T1。  
   - **观测 / Watch**：改对率、错改率、再验失败率、误放/误拒成对、作废率、override rate、包结论分布等。本波主 SLI 1–5 坐在这一层。  
   - **离线评测 / canary**：must_stale / must_fresh multi-run 与冻结金标 canary。金标不得进生产 score 或在线放行器。本波主 SLI 6 坐在这一层。
4. **本波收口**：主 SLI 只有索引中的最小 6。phase-2 六项（claim-level faithfulness、failure attribution 3-way、judge-human calibration、version tags、cost、implicit feedback）只挂附录。宽表其余 ID 不升为第 7+ 主 SLI。
5. **起步阈值（预注册）**：不变量如上；确认后严重错改抽检本波观测-only，Watch 讨论线小于 5%（样本协议未齐前不作 Gate 生死）；must_stale multi-run 不得低于当前金标/Hard-Gold 门。事后改门槛凑绿 = 作废重签。min-6 数值门槛本波只给起步姿态。
6. **叙事**：本页是运营与产品纪律。`#508` 保持 draft，Matt 审完之前不合并。本 ADR 不授权改 `src/` 放行谓词，不授权实现 T2–T6。
7. **实现授权**：T1 只落文档。协议字段摘取与周报脚本属于后续票，且须另过 before-implement。

## 后果

- 索引、运营页、规格、地图须引用本 ADR。  
- 任何将生产数字填入 `RESULT-Y` 成立格、或把金标当生产放行器的提案，视为违例。  
- 升「严重错改小于 5%」为 Gate 须另决议。  
- 已占用的 ADR-0034 至 ADR-0041 保持原决，不因本文件改号。

## 替代方案（被否决）

- 生产 SLO 挂在 `docs/evidence/patch-events/` 并兼写实验尺。  
- 生产变绿则回写 `RESULT-Y`。  
- 以放行率单独升高为成功。  
- 金标进在线 score。  
- 本波对全部观测指标立刻下硬百分数 Gate。  
- 并入修订 ADR-0029（补丁 API 与运营纪律糊缝）。  
- 在 tip 上仍使用文件名 ADR-0034，从而覆盖 patch-events 路线 B 的 ADR。  
- 把 phase-2 六项升成本波主 SLI，或另起一套与 B2/B3/C2 平行的 KPI 名。
