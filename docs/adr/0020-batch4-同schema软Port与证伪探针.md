# ADR-0020: Batch 4（δ）同 schema 迁移 = 软 Port + 证伪探针

- **状态**: Accepted
- **日期**: 2026-09-23
- **相关**: `docs/research/δ-同schema零改代码迁移假设设计评估.md`、ADR-0019、地图 #96 / 工单 #104；下游 #105

## 背景

Batch 4 要以 P1 QuoteTTL 薄课题包证明 Second-thesis Port。若把「同 schema 零改代码」解成 `src/` 字面零 diff，则假设过脆且易造假合规；若为隔离或报价叙事加列、加第七维、改闸，则不再是迁移。需要可操作的假设语句与实现后可打的证伪探针。

三条件齐备：

- **难反转**: 假设与 FP 一旦绑验收，事后放宽探针或偷偷加列会使「迁移成功」话术作废。
- **反直觉**: 「零改」常被听成零 diff；「加 pack_id 列更清晰」看起来无害。
- **真实取舍**: 可落地的软 Port vs 字面硬零改；命名/分库隔离 vs schema 加列。

## 决策

1. **迁移假设取软 Port**（非硬零改）：冻结面零改；允许平行数据包 + 配置切换 + 只读装载器（职责：解析 `active_pack`、拼路径、开对应 DB）。
2. **冻结面** = 闸与 error_code 语义；主张字段集（不加列）；gold 键形状（不加键）；SQLite 表结构（不加列）；HumanLatch 作废/续命语义；职人旅程步骤；focus/登记维六枚举。
3. **隔离**: claim_id 命名隔离为必须；每包独立 SQLite 文件为允许；**禁止**为包隔离加 `pack_id`（或同意图）列。
4. **证伪探针 FP1–FP7**（详见评估文档）：任一响 → 不得宣称本批迁移成功，须重预登记。装载器不钉行数硬顶，越界由 FP7 判定。
5. **平行课题包必须标明 synthetic**；对外释放协议正文不在本 ADR（#105）。
6. **本 ADR 不授权** wayfinder 会话内 `/implement`，不授权为 P1 改第一课题 gold/语料凑绿。

## 后果

- Batch 4 `/to-spec` 与实现验收必须挂载 FP1–FP7。
- #105 可依赖「平行包 + synthetic 标明」前提，但不得把释放写成「多垂类已 Port」。

## 替代方案（被否决）

- **硬零改（src diff 为空）**: 不可操作，诱致假合规。
- **假设不成立、只锁宽改动面**: 与 ADR-0019「不改闸才叫迁移」冲突。
- **表加 pack_id 列 / gold 加键 / 第七维**: 不同 schema 或改词表。
- **钉装载器行数硬顶**: 可刷，不表征职责边界。
