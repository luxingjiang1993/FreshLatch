# ADR-0008: 规则闸不变量 6——stale 反证不得为纯元陈述(c9 缺口句法闸)

- **状态**: Accepted(2026-09-20,工单 #17 拍板)
- **相关**: 工单 #17 评估见 `docs/research/c9元陈述句法闸设计评估.md`;W4 验收纪律 ADR-0007、背离一登记 `docs/evidence/w4/repro-check.md`、HumanLatch ADR-0006

## 背景

c9(must_unknown)的 T1 只有元陈述(「本轮未复测……该指标不再列入跟踪项」)。W4 三次运行中两次被 Lead 以元陈述为唯一依据判 stale,违反人格显式规则(「未复测=证据缺口,走 mark_gap+unknown」)——**提示词层防线被端点漂移实证击穿**(人格规则在案仍 2 次违反,记背离一,签认不升级)。must_unknown 桶的既有机械防线「无 t1_evidence_ids 不得 fresh」只管 fresh 方向,stale 方向无闸。

## 决议

### 1. 规则闸新增第 6 条不变量

stale 反证不得为纯元陈述:stale 理由以元陈述(未复测/不再列入跟踪/无新数据/待发布/未入账等封闭枚举标记)为唯一依据的,闸层打回 `META_ONLY_DISPROOF`,经 runner 既有「stale 打回落 unknown」路径路由 unknown。绿灯方向不开口(不变量 1 兜底),误伤单向且不对称安全:最坏结果 = 该主张本轮挂 unknown 进人审。

### 2. 判定机制 = 确定性句法启发式,非 LLM judge

元陈述标记子句剥除后,存在含数值的实质子句即放行(c3/c7 实录形状),否则打回。理由:(a) 评测可复现性要求闸层零非确定性,judge 引入第二次漂移且与被判者同源,属循环论证;(b) 闸的零 I/O 纯函数定位(ADR-0001)使其拿不到证据正文,语义比对结构性不可行。算法先于任何测试写死于评估文档,事后修改 = 评估作废重签。

### 3. 工具层提前反馈与闸层兜底是同一判定函数

Lead/Critic 的 `mark_stale` 用同一纯函数(`gates/meta_gate.py`)在环内打回;引导措辞按角色白名单出口适配(Critic 无 mark_gap,引导至 report_finding)。判定逻辑单一真相,不复制。

### 4. 本变更为工程修复,非判据修订

金标 gold.json、must_unknown 口径、W4 通过线不动一字;harness 行为对齐既有判据,而非判据对齐 harness 的错误(工单 #17 评审结论,沿用 repro-check 签认口径)。W4 已签验收不重开。

## 后果

- 词表:规则闸不变量清单 + `元陈述` 术语 + `有效反证` 定义补充(CONTEXT.md 已落)。
- `GateDecision` 增加 `stale_reason` 字段;runner `_finalize` 注入判定理由。空理由跳过元陈述校验(理由存在性归工具层 ≥20 字校验),向后兼容。
- 已知边界预登记(评估文档 B1–B3):无数值的实体性反证与元陈述共存时可能误伤(方向单向可接受);标记词表封闭,增补走 #17 同款评审纪律。
- 行为层收敛验证(端到端 12 主张多跑)归 W12 前工程冒烟,n 小报方向不报方差;机制级验证 = c9 两次实录 reason 注入闸层逐位判 unknown(单测在案)。
