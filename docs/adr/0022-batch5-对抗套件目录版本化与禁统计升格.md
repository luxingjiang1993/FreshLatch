# ADR-0022: Batch 5（ε）对抗套件目录版本化与禁统计升格

- **状态**: Accepted
- **日期**: 2026-09-23
- **相关**: `docs/research/ε-对抗套件目录与版本化设计评估.md`、`docs/research/adversarial/`、地图 #96 / 工单 #107、#98 ATK-CS、#102 假绿分条

## 背景

Batch 5 需要假绿/对抗用例的可引用索引，但「建了目录」极易被读成「对抗仪器已过」或诱使写入通过率充当证书。与金标/预登记若复制正文，会形成第二真相。

三条件齐备：难反转（版本与禁列一旦被外部引用）；反直觉（有目录常被当成已测过）；真取舍（先骨架 vs 本批出统计/夹具）。

## 决策

1. 对抗索引落在 `docs/research/adversarial/`，以 `catalog_version`（semver）版本化；**0.1.0** 为本批骨架。
2. 条目 ID 形如 `ATK-<FAMILY>-NN`；改语义必须 bump 目录版本；退休用 `status=retired`，不改写历史条目含义。
3. INDEX **禁止** `pass_rate`（及同类统计结论列）。本批条目 `status=skeleton`。
4. 与金标/预登记/已有 ATK-CS **只指针**，不复制通过线正文。
5. **目录存在 ≠ 仪器已过 / 对抗成立**。本 ADR 不授权本批报统计通过率，不授权 wayfinder 内 `/implement` 夹具。

## 后果

- Batch 5 `/to-spec` 可引用骨架作 RESEARCH 交付；验收不得把「INDEX 有行」写成对抗通过。
- 真跑次与统计另开批次/工单，且不得回写本目录冒充已过。

## 替代方案（被否决）

- 本批报通过率或加 pass_rate 列。
- 目录内嵌 gold/通过线副本。
- 仅评估文档列表、无版本化目录。
