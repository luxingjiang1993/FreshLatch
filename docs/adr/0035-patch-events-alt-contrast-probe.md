# ADR-0035: patch_events 平行轨 · 可识别更干净对照探针

- **状态**: Accepted
- **日期**: 2026-10-08
- **相关**: `docs/research/patch_events-平行轨可识别对照设计评估.md`、[#434](https://github.com/luxingjiang1993/FreshLatch/issues/434)、[#435](https://github.com/luxingjiang1993/FreshLatch/issues/435)；旁路锁页 `docs/evidence/patch-events-alt/PROBE-LOCK.md`；冲甲主链 #431/#432 / ADR-0034（平行、零 diff）
- **说明**: 本 ADR 不占用、不修订 ADR-0034。编号 0035 专指平行轨探针设计闸。

## 背景

旧 n=30 在空分固定 k 下 T-B1/T-B2 差锁 0，冲甲主链（路线 B）已另拍可识别选取 R 与仓外门闩。若把「换指标 / 同文四闸 / 收紧 B1」直接写进主 `compare_primary` 或冲甲预注册，等于见主链结果后改主仪器追甲。需要一条与冲甲完全平行的设计探针轨，预先锁死指标、结构、B1 信息集、假绿边界与升级闸。

三条件齐备：

- **难反转**：后续 `/to-spec`、`compare_alt_*`、夹具探针与升级/放弃票将引用本闸；事后放宽升级闸或反写主缝会使探针实验作废。
- **反直觉**：本轨成功 ≠ 甲成立；更干净对照却禁止改主 `compare_primary`；推荐同文四闸而非分头生成；收紧 B1 是为真对照而非削弱稻草人。
- **真实取舍**：自然率 vs 固定 k；同文 vs 分头；B1′ vs 现 B1；升级三档 vs 见结果再定闸；旁路 vs 改主缝。

## 决策

1. **平行轨层身份**  
   实验/设计探针。内部档：可分开 / 分不开 / 不值得升级。禁止称结果甲/乙/丙。小 n 或夹具 = 冒烟，不报方差充总体。

2. **与冲甲防火墙**  
   对冲甲预注册正文（含 `PREREG-B` 草稿）与主 `compare_primary` 语义**零 diff**。禁止回写旧 `PREREG.md`；禁止本轨数字填主 RESULT 成立格；禁止金标进排序；禁止削弱对照冒充差；禁止对外宣称主假设成立。

3. **主指标**  
   自然误放率 + 自然放行率成对报。固定 k 误放仅附录。Pareto 不本期主指标。

4. **结构**  
   探针主结构 = 同一 `after_text` 四闸分判（C / T / B1′ / B2）。分头生成仅附录。

5. **B1′**  
   禁止看 evidence id / 绑定；同文锁定后才延迟获得 evidence 正文核验。拒绝不得记成 T。

6. **假绿**  
   「不能假绿」另测，绝不进本轨主表或升级闸（#428 精神）。

7. **升级闸（预锁）**  
   - **可分开** → 允许另开主论文级新预注册文件（不取代冲甲页，不自动激活）。  
   - **分不开** → 不升级；技术报告；禁放宽本闸。  
   - **不值得升级** → 放弃旁路主论文预注册。  
   见结果后改闸 = 作废。可分开 ≠ 甲。

8. **实现边界**  
   只许旁路：`compare_alt_*`、`docs/evidence/patch-events-alt/`，或只读复用旧 jsonl/夹具。未授权不发模型。五处冻表面不动。检索指标不得冒充本轨结论。

9. **词表**  
   `CONTEXT.md`：patch_events 平行轨、同文四闸、B1′、平行轨升级闸（细节见评估）。

## 后果

- **可以立即 `/to-spec`**：旁路规格、夹具探针票、防火墙路径、升级/放弃票序。  
- **不可以**：未授权正式/探针生成；改主缝追甲；本轨取代冲甲页；称探针为甲。  
- **违例级**：回写旧 PREREG；本轨填主 RESULT；见结果后改升级闸；假绿塞主表；复活 #419–#430。

## 替代方案（被否决）

- **直接改主 compare_primary 追甲**：HARKing 主链；毁门闩/止损意义。  
- **固定 k 作本轨主指标**：与冲甲重叠或再现同集病。  
- **分头生成作探针主结构**：噪声大，难答「更干净」。  
- **维持现 B1**：与 T 过近，假对照。  
- **假绿塞主表 / 混一句**：构念污染。  
- **见结果再定升级闸**：验收作废。
