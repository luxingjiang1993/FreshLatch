# ADR-0029: V1.5 Evidence-bound 补丁与独立确认 API

- **状态**: Accepted
- **日期**: 2026-09-29
- **相关**: `docs/research/V1.5-Evidence-bound补丁设计评估.md`、`docs/grill-prep.md` §2f、roadmap Phase V1.5、ADR-0027、ADR-0028、ADR-0006

## 背景

V1 已交付包结论「需补丁」与 `patch_events` 起记，但主张正文仍无法以 ⊆ 已入库 T1 的方式改稿并强制再验。若不钉 API 边界与 Exit 条，易把补丁塞进 HumanLatch 第三动词、用薄对话/单次「可发」冒充 attested，或把论文 n 绑死产品 Exit。

三条件齐备：难反转（对客楔子与论文路线 A 将引用本契约）；反直觉（有「需补丁」却**不**扩 latch 动词；Exit **不**硬要包结论可发）；真取舍（独立 patch API vs renew/第三动词；表单 Exit vs 薄对话绑 Exit；fail-closed vs 软警告）。

## 决策

1. **Evidence-bound / attested patch（对外少用 proof-carrying）**：整条主张 `statement` **原地替换**；确认时必填 `t1_ids`，且每个 id 必须 ∈ 本 Run **已入库** T1；否则 **拒绝确认**（fail-closed）。产品路径恒 `patch_events.arm=T`；C 仅脚本/后台。
2. **独立 Verify+ API**：`propose_patch` / `confirm_patch`。**不**扩展 HumanLatch `discard`|`renew`；**不**用 renew 顺带改正文。confirm 成功后：**强制单条再验**该主张，再聚合包结论。
3. **资格**：仅未 discard 的 `unknown` 或 `stale` 可提案；`void` / `fresh` 本期不可。入口为**主张级**（与包结论「需补丁」解耦，不独依赖包级横幅）。
4. **UX**：挂在复验单 / Run 详情**增量**条带；`t1_ids` 从本 Run 已入库 `evidence_id` **多选**。propose 草案仅会话/Run **暂存**；未 confirm 不改正文、不写正式 `patch_events`。
5. **账本**：正式事件在 confirm 时追加；在既有字段上增 `before_text` / `after_text`；保留 `patch_span`（可自动默认）；`minutes` 由确认人手填。
6. **导出**：单次补丁包 = **JSON + 短 Markdown**（before/after、t1 指针/checksum、确认者、再验前后 disposition）。
7. **薄对话**：本期 **Out**（不实装、不 stub）；不得对话改正式 disposition。roadmap Phase V1.5 **In** 以表单闭环为准。
8. **Exit（冒烟层）**：证据落 `docs/evidence/v15/ACCEPTANCE.md`。预锁脚本：对人审范围 discard **mck-1** 与 **mck-4** → 包结论至「需补丁」→ 对 **mck-3** 表单补丁并 confirm → 单条再验 → 导出。硬条 = 无证拒确认 + 有证 confirm + `reverify=true` + 导出存在；包结论升「可发」为**加分**，非硬 Exit。禁止单次运行报 C vs T 显著；禁止事后改脚本凑绿。
9. **范围**：#8 Policy-as-code **不**与本期并行；论文 n≥30 **不挡**本 Exit。

## 后果

- to-spec / 实现须引用本 ADR；UI/API 不得出现 C|T 臂开关。
- ADR-0027「Evidence-bound 属 V1.5、本 ADR 不授权实装」由本 ADR 授权实装边界。
- 扩资格集、做薄对话、Exit 改绑「可发」、或把 patch 并入 HumanLatch 动词，须另决议。

## 替代方案（被否决）

- span 级 diff 编辑器 / 独立补丁台（编辑器秀）。
- 扩 HumanLatch `apply_patch` 或 renew 改正文。
- 产品允许无证确认或软警告放行。
- Exit 必须薄对话或硬绑包结论「可发」/ mck-3 `fresh`。
- propose 即写 `patch_events(human_confirm=false)` 污染账本。
- 并入修订 ADR-0027；#8 与本期并行。
