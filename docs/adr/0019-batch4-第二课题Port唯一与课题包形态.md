# ADR-0019: Batch 4（δ）第二课题 = 同构课题包 + 本批唯一 Port

- **状态**: Accepted
- **日期**: 2026-09-23
- **相关**: `docs/research/δ-第二课题选题设计评估.md`、地图 #96 / 工单 #103；下游 #104 / #105

## 背景

Batch 4 要证明 Second-thesis Port：同一套 FreshLatch 旅程与闸能否换到第二份合成课题。若把「第二课题」做成独立 QuoteTTL 产品表面、或本批并行多个垂类包、或只改 `question` 换皮，则要么改品类，要么无法测量「迁移」，要么踩地图 OUT（十个垂类 / 改闸语义）。

三条件齐备：

- **难反转**: 平行 gold/语料按唯一选题投入后，改唯一选题或事后宣称多垂类已 Port，会使本批迁移预锁与测量作废。
- **反直觉**: 「垂直好卖就该整包产品化」与「候选池大就该本批全做」看起来合理，实则破坏 Port 探针。
- **真实取舍**: 一次诚实 Port vs 表面多垂类；课题包 vs 第二产品线。

## 决策

1. **第二课题形态** = FreshLatch 内同构合成**课题包**（平行 question / T0·T1 / gold 子集；同一 UI 旅程），**不是**独立产品表面，**不是**仅改问题句的假换皮。
2. **本批（Batch 4）唯一进平行 gold 的课题** = **P1 QuoteTTL 薄切片**（claim 级报价保质期故事；禁止本批上字段引擎/含税守恒/ERP/真连接器/自动对外通知）。最小故事骨架以评估文档 §4 为准。
3. **δ backlog**（Port 通过后才开动；**不得**升格为「已多垂类验证」）序：P3 → P5 → P2 → P8 → P4 → P9。登记单一真相在评估文档，不在 CONTEXT 复制整表。
4. **P10**（SkillRot / BronzeCheck / ProvenanceWatch / IncidentReplay）与 **P11**（MemoryForensics 当第二课题）= **本图出池、未来另图备选**；不进 Batch 4 交付，不进「已 Port」话术。
5. **本 ADR 不授权** wayfinder 会话内 `/implement`，不授权为迁就第二课题改主课题闸/词表语义（若改闸则须重预登记，不得再称本批迁移）。

## 后果

- #104 须在 P1 课题包前提下定义「同 schema 零改代码」操作定义与证伪探针。
- #105 释放范围可随 P1 合成包收敛；不得因 backlog 存在而宣称数据集覆盖多垂类。
- Batch 4 `/to-spec` 必须引用本 ADR 与评估文档；验收层保持「迁移预锁」。

## 替代方案（被否决）

- **本批并行实现入池多包**: 踩 OUT，Port 不可测。
- **完整 QuoteTTL 产品表面作为 δ**: 第二产品立项，与卖作废主叙事及 W12 纪律冲突。
- **变现优先（可改工具面）作为选题判据**: 把垂类课题包与产品线混为一谈。
- **监管口径或成本/渠道近邻作为第一次 Port**: 区分度弱，易被攻击为第一课题换皮。
- **P10/P11 塞进本图 δ 交付**: 抢主叙事或 Mem0/观测台误读。
