# ADR-0039: patch_events 冲乙预注册载体相对 PREREG-Y（修订升格 · n=400 · T−C 点>0.05）

- **状态**: Accepted
- **日期**: 2026-10-10
- **相关**: `docs/research/冲乙预注册载体相对PREREG-Y设计评估.md`；[#518](https://github.com/luxingjiang1993/FreshLatch/issues/518)；父图 [#517](https://github.com/luxingjiang1993/FreshLatch/issues/517)；上游 ADR-0037（路线 Y · 只冲乙）/ ADR-0038（缺额解锁）；整合参考 `docs/research/冲甲冲乙行动方案整合.md`（PR #516）；姊妹票 #519（仪器）/#520（门闩）
- **说明**: 编号顺延开 PR 上的 0034–0038 之后。本文件**不**改写 ADR-0037 正文；只钉「相对 Y 的载体/n/成立线」三题拍板，供合入后与 0037/0038 并列引用。

## 背景

地图 #517 要钉「下一轮冲乙」在 `/to-spec` 前的决议。整合方案写：改核验/score/拒识进池须**新开预注册**、乙正式 n=100、成立为点>0∧下界>0。既有未激活 `PREREG-Y`（ADR-0037）则已锁：只冲乙、n=400、点>0.05∧下界>0、机制继承 B 软对齐+R。三者冲突须明文拍板，否则仪器票与门闩票无法挂载体。

三条件齐备：

- **难反转**：后续 #519/#520、`/to-spec`、formal-y/GATE-Y 将引用本闸的载体与尺；事后改开 Z 或改 n/放松成立线会使实验针漂移。
- **反直觉**：整合「改核验=新开页」下仍**修订升格**未激活 Y，而不是另开字母页；维持 n=400 与 0.05 线，而不是跟整合摘要回落到 100 / 点>0。
- **真实取舍**：修订升格 vs 新页作废 Y；n=100 vs 400；经典成立线 vs Y 加严线。

## 决策

1. **载体 = 修订升格 `PREREG-Y`**  
   冲乙正式预注册载体仍为 `docs/evidence/patch-events/PREREG-Y.md`。在**未激活**前提下以 Amendment / 修订记录写入整合升格声明；仪器（#519）与门闩/冒烟（#520）槽位写入**同一页**（或页内指向的门闩路径）。**不**新开 `PREREG-Z`，**不**将 Y 标成主证据作废归档。

2. **作废边界（保持）**  
   相对旧 `PREREG.md`（含 Amendment）与现 `RESULT.md` 链，以及 `PREREG-B/C`·`RESULT-B/C`，主证据作废关系**保持**（见 Y 原文作废声明）。禁止回写上述旧页凑乙；禁止同页二次主跑 B/C/Y；禁止复活路线 A。

3. **机制基线（引用，不重开）**  
   选取 R；软对齐（非 C 强制抄句主路径）；只判 T−C；放弃甲；bootstrap 10000、种子与解码锁定沿用 ADR-0037。本 ADR 不改比较器、不新造 `compare_*`。

4. **正式 n=400**  
   维持 ADR-0037 正式针。本窗**不**改选整合摘要中的 n=100，也**不**以 n=250 作正式针。缺额纪律继承 ADR-0038：凑不满则不可激活；禁止表写 400、实际喂不足；禁止静默改小配额。可加载 ≠ 激活 ≠ 过门 ≠ 乙成立。

5. **T−C 成立线（维持 Y 加严）**  
   参与成立的唯有 T−C：点估计 **>0.05** 且 95% bootstrap 下界 **>0**（且有定义）。否决回滚到「点>0∧下界>0」作为本页成立尺。B1/B2 报告-only；分层只可能乙或丙，不得称甲。止损：点≤0.05 或下界≤0（含无定义）→ 丙；禁加 n、改 R、改成立尺、同页二跑。

6. **与整合方案的优先级**  
   整合方案 §3 的 n=100、点>0 视为相对旧满样本门槛与 `DECISION-LOG` 的摘要。冲乙正式页以 **ADR-0037 + 本 ADR** 为准。仪器修复仍遵守「不回写已跑旧页」；未激活 Y 上 Amendment ≠ 同页翻盘。

7. **词表**  
   `CONTEXT.md` 收产品级「路线 Y / PREREG-Y」及「冲乙整合升格（相对 #517）」指针；成立加严细则与止损频率不进词表；过程词冲甲/冲乙/仪器坍缩不进词表。

## 后果

- #519 / #520 与 `/to-spec` 挂 **升格后的 PREREG-Y**，不另起字母载体。  
- `PREREG-Y` 协议页合入后须追加评估 §4.6 修订行；页状态保持**未激活**直至门闩+人令。  
- 违例：未过门激活；新开 Z 冒充本拍板；静默改 n；未跑数放松 0.05；回写 B/C；保证乙；称甲。

## 替代方案（被否决）

- **新页作废 Y（PREREG-Z）**：可审计，但本窗无 Y 跑数可污；重挂 PE-Y 工程轨成本高；否。  
- **正式 n=100**：放弃 Y 功效叙事；与已扩 pe_v2/n400 针错位；否。  
- **n=250 作正式针**：ADR-0037 已否。  
- **成立线回滚点>0**：未跑数放松止损；Anthropic #5 否。  
- **回写旧 PREREG / 翻 B/C / 复活 A**：基线禁令。  
- **新造 compare_***：双真相源；违 #416。
