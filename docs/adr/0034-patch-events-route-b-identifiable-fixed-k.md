# ADR-0034: patch_events 路线 B · 可识别固定 k（R）与仓外门闩

- **状态**: Accepted
- **日期**: 2026-10-08
- **相关**: `docs/research/patch_events-路线B冲甲可识别选取设计评估.md`、[#431](https://github.com/luxingjiang1993/FreshLatch/issues/431)、[#432](https://github.com/luxingjiang1993/FreshLatch/issues/432)；协议页 `docs/evidence/patch-events/PREREG-B.md`；废止主证据资格：`docs/evidence/patch-events/PREREG.md` + 现 n=30 `RESULT.md` 链（动机附录可留）
- **说明**: 已废除的路线 A 关单曾口称「ADR-0034」但从未落盘；本文件为首次占用该编号，内容为路线 B，不继承 #420 拍板。

## 背景

n=30 主比较在旧选取下 T-B1/T-B2 差为 0：`score` 全空时 T/B1/B2 按同一 `claim_id` 取固定 k，三臂同集，结果甲结构上不可识别。路线 A（继续旧 PREREG→n=100）已整链废除。冲甲要求新预注册与可识别选取，并防止「见差为 0 后改判据」或「未分离就锁正式页」。

三条件齐备：

- **难反转**：后续 `/to-spec`、compare 缝、正式主跑与抄表将引用本闸；事后改选取或放宽成立定义会使新预注册实验作废。
- **反直觉**：冲甲却先废旧主证据；门闩未过不得激活正式页；见 B1/B2 为 0 仍不改成立定义。
- **真实取舍**：R vs S/S+R；门闩前可 /to-spec 缝 vs 不可正式生成；k 下限 10 vs 更小/不设。

## 决策

1. **路线 B**  
   新预注册文件。旧 `PREREG.md` 与现 n=30 主证据链不得作为冲甲主证据（可作动机附录）。禁止回写旧页凑甲。禁止复活 #419–#430。

2. **选取 = R**  
   固定 k 从各臂自然放行集取样。k := T 自然放行数。m≥k：放行集内 `claim_id` 升序取前 k。m<k：该臂固定 k 误放率无定义，相关主比较不得成立。弃用旧空分 `claim_id` top-k 作为主选取。本期弃 S / S+R。

3. **功率与止损**  
   k 下限 = 10。n 瞄准 100（更小须改预注册）。bootstrap：10000 次、种子 20261007、流名 `bootstrap`。成立定义不放宽：点估计>0 且 95% 区间下界>0。正式主跑后 T-B1 或 T-B2 点估计≤0 → 不得称甲，按乙或丙收口。同一预注册只许一次正式主跑；禁止看结果后改 R/S 再跑冒充原计划。

4. **仓外试分离门闩**  
   未过门：不得激活冲甲正式主跑、不得开正式生成。过门：仓外（不进主表）显示 T 相对 B1 与相对 B2 的固定 k 误放差方向均为正，且 T 的 k≥10。T-B1 分不开：改机制或改冲乙，禁止金标/评委打分硬拆。

5. **反 HARKing**  
   旧差为 0 的数字只证明结构锁零。改的是可识别性（选取），不是成立定义。正式主张只来自激活后的新跑数。

6. **层身份**  
   仓外试分离 = 可扔冒烟层，不得升格为甲。结果只抄 `compare_primary`。检索层与放行闸分说。甲未成立前五处冻表面不动。

7. **词表**  
   `CONTEXT.md`：路线 B、固定 k 自然放行选取（R）、仓外试分离门闩（见评估链接）。甲/乙/丙成立细则不进词表。

## 后果

- `/to-spec` 可开：协议骨架完善 + `compare_primary` R 缝（Acceptance 须含臂间固定 k 可不同，且旧空分同集病被拒或不再适用）。  
- 门闩未过：`PREREG-B.md` 保持未激活；禁止正式生成进主表。  
- 违例：回写旧 PREREG；复活 A；金标进 score；削弱对照；夹具填甲；未过门激活正式页；甲未成立称 T 更好。

## 替代方案（被否决）

- **路线 A / 只加 n**：同集差锁 0，甲不可识别。  
- **本期 S / S+R**：无仓外可辩护臂分；增量未证。  
- **先锁正式页再试分离**：门闩倒置。  
- **见 0 后放宽成立定义或回写旧页**：HARKing。  
- **k 下限 5 或不设**：功率不足，假冲甲。
