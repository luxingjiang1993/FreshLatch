# ADR-0038: patch_events 路线 Y · 正式 n 缺额解锁（扩语料 · 停泊 · 禁静默改小）

- **状态**: Accepted
- **日期**: 2026-10-09
- **相关**: `docs/research/patch_events-路线Y正式n与语料缺额设计评估.md`；上游 ADR-0037（n=400 · 只冲乙）；协议页 `docs/evidence/patch-events/PREREG-Y.md`（未激活）；实现针 PE-Y-03 / PR #497（`SPLIT-pe-v2-route-y.json` · 不可激活）；语料先例 #371 · 规格讨论 #368
- **说明**: 本文件只钉「如何解锁正式 n 可执行」；不改成立尺、选取 R、门闩过门条件、甲防火墙；不激活正式主跑。

## 背景

ADR-0037 与 `PREREG-Y` 已锁正式 **n=400**。PE-Y-01…04 工程已齐，但现网 `pe_v2` claims≈**178**，四层库存天花板远低于每层 100。PE-Y-03 已 fail-closed：**缺额不可激活**，且禁止返回不足 400 条冒充正式集。

监督窗须在「扩语料 / 另决议改正式 n / 暂缓」之间拍板，避免实现会话静默改小配额或未齐闸派 PE-Y-05。

三条件齐备：

- **难反转**：后续 corpus 票、SPLIT 重针与 PE-Y-05 人令闸将引用本解锁路径；若改走「改 n」却无新决议，会使 n=400 预注册作废。
- **反直觉**：协议尚未激活、尚未跑结果，却仍**拒绝**把正式 n 改成现有 178——因为开 Y 的功效动机不允许「库存拟合规格」当缺省。
- **真实取舍**：扩 `pe_v2` 工时 vs 透明改 n（放弃功效）vs 停泊推迟冲乙。

## 决策

1. **主解锁路径 = 扩语料（A1）**  
   在 `PREREG-Y` 样本框内扩充 `data/pe_v2_docket.json` 与 `data/corpus/pe_v2/`（公开法规同源路径，#371 级 provenance），使构造后可满正式 n=400（四层各 100，层内 50/50），并尽量满足共形每层 5 的 leftover；不够共形则写「未做」，**不得**挖主配额。刷新 `SPLIT-pe-v2-route-y.json`（或等价针）离开「不可激活」。

2. **操作态 = 停泊（C）直至 A 完成（或人另选 B）**  
   PE-Y-05 **不派**；`PREREG-Y` 保持未激活；不得发正式模型。工程 PR #494–#497 合入与文档可继续，不构成可激活。

3. **禁止静默改小配额（B1 永否）**  
   不得把 `PREREG-Y` 配额表 400 改小充数；不得「表写 400、实际喂 <400」。PE-Y-03 loader 缺额失败语义保持。

4. **改正式 n 不是本窗出口（B 本窗否）**  
   若真人将来放弃「更稳 400」功效叙事，须**另开** grill：新评估 + 新 ADR + `PREREG-Y` 修订记录，明示新正式 n 与放弃理由。本 ADR **不**批准任何小于 400 的正式针。

5. **样本框边界**  
   禁止以第二领域、KPR benchmark、医疗指南、或退回 `thesis-1` 合成主路径冒充解锁。

6. **词表**  
   `CONTEXT.md` 可收产品级「缺额停泊 / 扩容解锁」；成立加严与止损频率仍不进词表。

## 后果

- 下一窗优先派 `PE-Y-CORPUS-*`（扩 pe_v2 + 重针 SPLIT + 单测）；**禁止**派 PE-Y-05。  
- 扩容验收绿 ≠ 过门 ≠ 乙成立；真数据 `GATE-Y-PROBE` 与正式人令仍是激活前置。  
- 违例：静默改配额；未扩满激活；第二领域凑数；用探针令冒充正式令；回写 B/C。

## 替代方案（被否决）

- **静默改小 n / 表 400 喂不足**：纪律违例；双真相。  
- **本窗直接修订正式 n≤178**：放弃 ADR-0037 功效动机；须另决议，不得借本 ADR。  
- **n=250 作正式针**：ADR-0037 已否。  
- **永久关停路线 Y**：过度；停泊即可，四件套与 ADR-0037 保留。  
- **第二领域 / 合成回退主路径**：违 `PREREG-Y` 样本框。
