# ADR-0031: V2 发前钩子闸与主张台账只读投影

- **状态**: Accepted
- **日期**: 2026-09-30
- **相关**: `docs/research/V2-发前钩子与主张台账设计评估.md`、`docs/grill-prep.md` §2h、roadmap Phase V2；上游 ADR-0015（Client Memo）、ADR-0006（HumanLatch / 作废名单）、ADR-0027（包结论）、ADR-0029（补丁导出分轨）

## 背景

I2 冒烟 Exit 已齐后进入 V2（ADOPTION）。若不钉「嵌入钩子」的产品语义与台账写路径，易把检索 `embed` 与 Adoption 钩子混称、把导出做成强制整包再验或无闸假导出、用新表双写作废名单、或把 Word/Notion 平台与图谱塞进冒烟 Exit。

三条件齐备：难反转（采用出口与 ACCEPTANCE 将引用本闸）；反直觉（路线图写 Embed 却**不是**向量化；有台账却**不**新建写表；做「外部钩子」却只做入站 check 而非插件平台）；真取舍（只读 disposition+checksum vs 整包再验；Memo 主出口 vs 多平台并行；Backlog C′ vs 本期平台化）。

## 决策

1. **产品词**  
   - **发前钩子（publish hook）**：导出/打包前的确定性采用闸；**不是**检索向量 embed。  
   - **主张台账（claim ledger）**：作废名单 ∪ 续命人审日志的**只读投影**；**不是** `patch_events`，**不是**新 SQLite 写表。

2. **闸语义（确定性）**  
   - 输入绑定发前 `run_id`（或等价 Run 键）；读该 Run **包结论（disposition）** + T1 **checksum / `run_id` 机械新鲜度**。  
   - **不**在钩子路径强制整包 Lead/Gate 再验。  
   - **勿发**：拒绝导出 / 钩子 `allow:false`；**不**落 Client Memo 文件。  
   - **需补丁**：默认拒绝「干净」导出；仅当显式 `ack_needs_patch=true`（或 UI 等价确认）才允许，并**强制**页眉/载荷标明「需补丁」。  
   - **可发**：放行（仍受 checksum 新鲜度约束）。

3. **本期硬出口**  
   - Client Memo：**UI「导出客户备忘」+ CLI**（`python -m freshlatch.export client-memo`）共用同一闸函数。  
   - **入站** HTTP check（逻辑路径如 `POST /api/publish-hook/check`）：必填 `run_id`；返回 `{allow, disposition, code, message}`；deny 用 403/409 类。  
   - 默认绑定 **`127.0.0.1`**；可选共享密钥头 `X-FreshLatch-Hook-Token`（环境变量）；**不**宣称公网 webhook 平台。  
   - 内部 sheet / Evidence-bound 补丁包同闸 = **加分另票**，不挡 V2 Exit。

4. **主张台账**  
   - 真相仍为 `invalidation_list` + `latch_log`（`discard`/`renew`）；投影挂 Run 详情旁路（默认可折叠）+ 可导出 Markdown。  
   - **禁止**新建双写作废写路径；**禁止**扩 HumanLatch 动词；**禁止**用 renew 改正文。

5. **Exit（冒烟 · 采用层 · 预锁）**  
   - 证据：`docs/evidence/v2/ACCEPTANCE.md`；文首冒烟声明；**不报**采用率/方差。  
   - 硬条：(1) 样例 Run 人审后 disposition 可知；(2) UI 或 CLI Memo 闸动作正确；(3) `curl`（或测试客户端）入站 hook **allow 与 deny 各 ≥1**；(4) 台账可见本次 discard/renew 的 `claim_id`；(5) ACCEPTANCE 落盘。  
   - **不**硬绑包结论「可发」。`curl` 触发 ≠ 生产插件/webhook 平台已交付。

6. **Backlog / 弃**  
   - **Backlog 备选**：C′ 外部嵌入平台化（Word/PPT/Notion 插件、开放 webhook）；大图谱 / 全量采编 CMS（非近端）。  
   - **弃（本期且不进「以后做」冒充 Adoption）**：Memo 商业裁决；未过 Hard-Gold 改默认检索臂；解冻 Studio；双写作废表。

7. **roadmap**  
   - Phase V2 In/Out/Exit 与 cheat-sheet **对齐本 ADR**（发前钩子 + 台账；Exit 含外部 check 事件）；Out 仍钉大图谱/全量采编平台。

## 后果

- to-spec / 实现须引用本 ADR；UI/CLI/HTTP 不得各写一套放行语义。  
- 把钩子升级为整包再验、插件平台、或新表双写，须另决议。  
- Client Memo 字段集仍受 ADR-0015 约束（禁商业裁决、禁轨迹）。

## 替代方案（被否决）

- 用检索 Embed / 称 Verify+ 已完备 / Studio 已解冻。  
- 导出路径强制整包再验；无闸或静默放行；水印导出冒充可发。  
- 新建 `claim_ledger` 写表双写作废名单；台账与 `patch_events` 糊成一条历史。  
- 本期 Word/Notion/开放 webhook 平台或目录 drop 作唯一外部形态。  
- 出站「通知 webhook」顶替打包前 check。  
- Exit 硬绑真客户仓外点击、采用率 n、或包结论必须「可发」。  
- Memo 写入「建议进入/不进入」类商业裁决。
