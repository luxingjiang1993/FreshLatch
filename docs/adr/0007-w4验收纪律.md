# ADR-0007: W4 验收纪律(判据预先锁定/一次性修复窗口/止损优先)

- **状态**: Accepted(2026-09-20,工单 #12 拍板)
- **相关**: 工单 #12 评估见 `docs/research/W4验收标准操作化评估.md`;金标设计 ADR(工单 #8)、评测 harness(工单 #9)、UI 形态 ADR-0002

## 背景

切片 §13 的 W4 停止条件(「仍不能点回 T1 原文」「Critic 零有效已死反证」、主界面红线)是**整个 12 周计划的止损触发器**,但原文是口号级表述,本工单将其操作化。操作化过程中暴露三个真实风险:

1. **HARKing**:验收判据若在看到结果后还能随手编辑,止损机制形同虚设——可编辑 ≠ 可逆,事后改判据技术上容易、实验意义上毁灭性;
2. **修复窗口滑坡**:「先停」一旦允许续杯,停止条件退化为「迭代到达标为止」;
3. **演示层与测量层混淆**:W4 判据是 demo 层(可演示、可记录),统计测量(`--runs N≥5`)已被 #9 明确推迟到 W5–W8,两层必须显式分开,demo 层不得假装成统计结论。

## 决议

### 1. 判据预先锁定(pre-registration)

W4 验收检查表(`docs/evidence/w4/checklist.md`)**先于验收运行写死**,头部注明:「判据于 W4 验收前锁定,事后修改视为本次验收无效」。判据具体数值归评估文档,本 ADR 只记纪律。

### 2. 一次性修复窗口

W4 未过且属**工程类失败**(点回不达标、Critic 反证不达标)时,给**一次性 2 周修复窗口**后复验一次:同一份检查表、同一批判据,只换新证据;**窗口不得续杯**。复验再不过 = 立项失败。属**定位红线失败**(界面已是聊天框、复述测试成立、主按钮违禁)= 不可修,直接停。

### 3. 止损优先于演示打磨

任何「为了过验收」而修改产品定位、主按钮、主界面的动作,优先级判定为**止损条款(切片 §13/§14)高于验收通过**;宁可验收不过,不得把主界面改成聊天框/生成答案/开始调查。

### 4. 判据两层标注

每条 W4 判据在检查表中标注层级:**demo 层**(确定性检查:点回全量、红线单测、复述测试)与**冒烟层**(随机系统采样:must_stale 3 遍 × 3 seed,显式非零温度)。统计测量层(W5–W8 `--runs N`)不在 W4 判据内。

### 5. 留档可重跑

每次验收运行显式记录 decoding 参数(temperature、seed、模型版本、日期);托管端点漂移使跨会话复现只能是近似的,此限制写入留档。AFK 冷启动复现抽查分两层:闸层(must_* 零违例)逐位复现,判定层(混淆矩阵条数)按文档化容差。
