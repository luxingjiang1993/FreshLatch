# ADR-0014: 记忆卫生评测预注册与检测器操作定义锁死

- **状态**: Accepted
- **日期**: 2026-09-21
- **作者**: Cursor Grok 4.6
- **相关**: 立项切片 §11、ADR-0013、`docs/research/MemoryForensics操作定义对齐与论文路径设计评估.md`

## 背景

ADR-0013 拍板了 Forensic 角色、五工具、隔离而非删除、三表 schema。它没有锁死 **dead/contradictory/unverified 的可执行判据**,也没有锁死 **何时填写 `must_quarantine`**。随后出现的启发式分析文把时效词匹配写成 dead、把字段空值检查写成 100% 准确率,并把 demo 写成可投 AAAI/NeurIPS 的实验结果。

这满足 ADR 三条件:

- **难反转**:金标一旦按检测器输出回填,再改判据就是 HARKing,评测作废。
- **反直觉**:「检测器刚跑通、顺手把 id 写进 gold」看起来便宜。
- **真实取舍**:先锁规则会让 W12 记忆金标再等一次提交;不锁则永远没有可引用的测量。

## 决策

1. **操作定义执行体优先于启发式包装。** dead 必须对照 T1 原文(含「从 X 降至 Y」这类旧值仍出现在 T1 的覆盖句);无 T1 不得标 dead。互斥必须过具体对象门闩。unverified = 无 source_ref 或文档在 T0/T1 皆不存在。时效词单独标 dead 废弃。
2. **`must_quarantine` 填写必须晚于构造规则落档。** 规则的单一真相在评估文档 §7。本 ADR 接受日不得把 demo 输出写进 `gold.json`。改 §7 而不声明评测作废,视为违例。
3. **主张评测与记忆评测隔离。** Lead 默认白名单仍为 W3;`spawn_forensic` 处理器可在盘,但 W9 挂载不得进入 12 条 `must_stale` 矩阵。
4. **论文方法身份。** 可发表的是 T1 锚定的 fail-closed 记忆闩及其测量,不是词表算法。启发式分析文中的会议清单不构成本期计划。

## 后果

- 检测器与 schema 对齐后,demo 可以点回 T1;这仍是 demo 层。
- 记忆金标空数组维持到另一次提交,`test_gold_gate` 的空断言暂时保留。
- 文档侧必须勘误「W12 已全部通过 / 侧栏已有 / 无缝集成 / 100% 准确率」。
- checksum-dead、作废连带记忆 void、Forensic LLM 循环仍按评估文档留位,不在本 ADR 提前启用。

## 替代方案(被否决)

- **按本次 demo 结果回填 gold**:事后贴金标,评测无意义。
- **立即 Lead 挂 W9**:污染主张复验步数与 must_stale 可复现性。
- **以 embedding/LLM-as-judge 替换第一版判据**:默认模型不是规格;无对照、不可复现。
- **维持时效词 dead 只改宣传口径**:与切片 §11.1 冲突,面试被追问即穿。
