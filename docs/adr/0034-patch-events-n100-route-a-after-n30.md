# ADR-0034: n=30 主比较不成立后仍走路线 A（禁止见丙改预注册）

- **状态**: Accepted（2026-10-08，工单 #420 拍板）
- **日期**: 2026-10-08
- **相关**: `docs/evidence/patch-events/PREREG.md`、`DECISION-LOG.md`、ADR-0007、评估见 `docs/research/patch_events-n100路线与阶段成功收口设计评估.md`、地图 #419

## 背景

n=30 正式比较已抄入 `RESULT.md`：固定放行数 k=3；T-C / T-B1 / T-B2 的 false-accept 配对差按预注册均不成立。下一会话面对诱惑是：回写 `PREREG.md`、放宽成立定义、或在「继续路线 A」名义下更换 T 的提示词/阈值后再跑 n=100。

这满足 ADR 三条件：

- **难反转**:一旦见丙后改判据或偷换处理再挂同一预注册，旧 n=30 与新 n=100 不再是同一次预注册实验；证据链不可诚实拼接。
- **反直觉**:「小样本挂了就改口径」看起来便宜，且 k=3 使区间无信息，改起来心理成本低。
- **真实取舍**:坚持路线 A 可能仍得丙；改口径可能更容易「过线」，但毁掉预注册意义。

## 决策

1. **路线 A 锁定**:继续现有 `PREREG.md` 做满 n=100（n=30 超集）。现 n=30 链保留，不作废。禁止回写该页的判据、种子、配额、构造算子、评委 id、评分细则。
2. **见丙 ≠ 授权改判据**:n=30 不成立或 k 过小，不得作为修改成立定义、削弱 B1/B2、或把 `claim_text` 当 `after_text` 的理由。
3. **T 定义变更必须走路线 B**:若仓外试改表明必须改 T 的可执行定义（提示词、核验阈值、放行规则）才有希望成立，则另写新预注册，明文作废旧 `PREREG.md` 与现 n=30 链，再重跑。禁止在路线 A 下静默换正式生成配置。
4. **阶段成功与主假设分离**:结果乙（仅 T-C 成立）算阶段成功，与 `DECISION-LOG.md` 场地映射一致；结果丙可关闭测量但不得宣称「T 更好」。数字只抄同一次 `compare_primary`。
5. **对外表面**:五处冻表面仍受规格 23 / #401 约束；未按甲/乙/丙收口前不得改。

## 后果

- 实现与跑数票按路线 A 开；「三条成立」不是 implement 验收项。
- 仓外试改至多一轮，不进主表；触发定义变更则停 A、开 B。
- 词表不收录结果甲/乙/丙或「仓外试改」（过程/评测收口词）。
- 继承 ADR-0007 的预先锁定纪律；本 ADR 只补「见丙后的路线分叉」。

## 替代方案（被否决）

- **回写 PREREG 后重跑**:HARKing。
- **新预注册但不明文作废旧链**:双口径并存，面试不可答。
- **试改后仍挂 A 却换 T 配置**:未声明的新实验。
- **只认结果甲为阶段成功**:与已锁场地乙路径冲突，无必要收紧。
