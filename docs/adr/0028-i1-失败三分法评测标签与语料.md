# ADR-0028: I1 失败三分法为评测标签与 HumanLatch 语料双形态

- **状态**: Accepted
- **日期**: 2026-09-29
- **相关**: `docs/research/I1-失败三分法与HumanLatch语料设计评估.md`、`docs/grill-prep.md` §2e、roadmap Phase I1、ADR-0006、ADR-0026、ADR-0027

## 背景

Phase I1 要把「能跑」变成「能答辩错在哪层」。若不钉三分法边界与挂载面，易把口语桶写进生产 Gate/disposition，或编造无轨迹样本凑 mid；若把远程 V1 关单当作 Exit，I1 corpus 会建在未本地证明的发前闭环上。

三条件齐备：难反转（论文/mid 口述会引用桶名与样本）；反直觉（有失败标签却**不**改生产枚举）；真取舍（全链三桶 vs 仅检索；页+JSONL vs 单形态；本地 V1 ACCEPTANCE 硬挡 vs 远程 CLOSED 即开）。

## 决策

1. **失败三分法（全链三桶）** 为 **评测/答辩标签**，不是生产 status：
   - **找不到**：retrieve / T1 覆盖不足（召回空、must_unknown、无 T1 仍敢判）
   - **找错**：命中错段，或 Lead/Critic 点错证（含假 stale/假 fresh 用错原文）
   - **没用上**：证据在场但未进裁决依据，或 Gate/HumanLatch 未收口（含搁置、续命失败未解释）
2. **挂载面**：允许挂在 eval/轨迹与 I1 corpus；**禁止**改生产 `rule_gate` / 包结论 disposition / HumanLatch `discard`|`renew` 封闭集来表达这三桶。
3. **漏拦 / 误拦**：相对金标或人终审——该拦未拦 / 不该拦却拦；**每条样本必须**同时标注三分法一桶（复盘主键 = `err_kind × fail_bucket`）。
4. **corpus 双形态**：`docs/evidence/i1/` 每条一页 md + `docs/evidence/i1/events.jsonl`（字段至少含 `sample_id, claim_id, gold_or_human, machine_status, package_disp?, fail_bucket, err_kind, layer, trajectory_ptr, evidence_md, runnable, ts, actor`）+ 短索引 md。文首声明答辩/冒烟层；不报方差。
5. **样本量**：重标既有 W4/假绿对照与轨迹 ≥3；另从 V1 顾问垂直（McK SoAI）新跑 **≥1** 条 `runnable=true` 金样。`runnable=replay_trace_only` **不得**作为唯一 Exit 金样；可复跑须显式记录模型/temperature/seed/日期。
6. **开工硬挡**：I1 落样本 / 宣称 Exit 之前须 (i) 本期① bare-pytest 卫生 Exit，且 (ii) 本地 V1 Exit 证明齐——以新建 `docs/evidence/v1/ACCEPTANCE.md` 为准（含 disposition 映射抽检、patch_events 一行、默认臂仍 bm25、人审走通）。**远程 issue CLOSED ≠ 自动 V1 Exit**。
7. **词表**：三分法与漏拦/误拦细则留本 ADR 与评估文档；`CONTEXT.md` 仅在评测区留指针，**不**把桶名写成产品裁决词。

## 后果

- to-spec / 实现须引用本 ADR；轨迹挂标字段名与 JSONL 对齐。
- 贡献清单 I1 行可声明「失败三分法 + 可复盘误判样本」，须带冒烟层口径。
- 扩大生产枚举或取消本地 V1 ACCEPTANCE 硬挡须另决议。

## 替代方案（被否决）

- 远程 V1 CLOSED 即开 I1 落盘。
- 三分法只映射检索，或第四桶「角色用证」。
- 改生产 Gate/disposition 枚举承载三分法。
- 编造无轨迹样本；仅 JSONL 或仅 md。
- 用 replay_only 冒充唯一可复跑 Exit。
- 把三分法写进 CONTEXT 产品词表正文。
