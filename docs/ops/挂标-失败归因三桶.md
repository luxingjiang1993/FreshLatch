## 0. 目的

失败样本按 ADR-0028 的三桶挂标。每一条进入分母的样本恰好一桶，并可与 `err_kind` 交叉。复盘主键是 `err_kind × fail_bucket`。

| 要看见的 | 不在本页交付 |
|----------|----------------|
| 封闭三桶：找不到、找错、没用上；每条恰一 | 第四桶，含被否的「角色用证」，或任何「其他 / 未分类」列 |
| 与 `err_kind`（漏拦 / 误拦）的 2×3 交叉 | 把桶名写进 `rule_gate`、包结论 disposition、HumanLatch 动词 |
| 与 SLI 3 分列的附录行 | 与 `fresh` / `stale` / `unknown` 互改标或合流 |
| 样例字段空表 | 把金标写入生产 score 或在线放行器；把 I1 冒烟条数当成当周观测 |

SLI 3 的协议仍是 [`判定-unknown三分协议.md`](判定-unknown三分协议.md)。那一页的三分是生产判定出口。本页不改那一页的 fresh/stale/unknown 定义，也不在那一页填 `fail_bucket`。

## 1. 三桶（封闭集 · 严格复用 ADR-0028）

`fail_bucket` 只取下表三值。操作定义与 ADR-0028 决策 1 相同，不改写桶界。

| `fail_bucket` | 操作定义 | 本页怎么用 |
|---------------|----------|------------|
| **找不到** | retrieve / T1 覆盖不足（召回空、`must_unknown`、无 T1 仍敢判） | 离线评测标签。描述覆盖不足。不改生产 `status` |
| **找错** | 命中错段，或 Lead/Critic 点错证（含假 stale / 假 fresh 用错原文） | 离线评测标签。描述点错证。不改生产 `status` |
| **没用上** | 证据在场但未进裁决依据，或 Gate / HumanLatch 未收口（含搁置、续命失败未解释） | 离线评测标签。描述未收口。不新增人审动词 |

每条进入 `n_fail` 的样本，`fail_bucket` 恰为上表之一。空值、两桶并列、「都有一点」、自造桶名，该条不进分母。

### 1.1 不另起第四桶

ADR-0028 已否决第四桶「角色用证」，也否决「三分法只映射检索」。本页继承这两条否决。

下列写法都不是新桶，周报不给它们单列：

- 「角色用证」
- 「其他」「未分类」「混合」「说不清」
- 把 `fresh` / `stale` / `unknown` 当作第四个 `fail_bucket`
- 把 `err_kind` 的漏拦或误拦当作桶名

写不进三桶的样本留在表外。备注可以写「未归桶」。这四个字是排除句，不是第四个 `fail_bucket`，附录不设这一列。

## 2. 与 err_kind 交叉

`err_kind` 沿用 ADR-0028 决策 3，相对金标或人终审，封闭二值：

| `err_kind` | 操作定义 |
|------------|----------|
| **漏拦** | 该拦未拦 |
| **误拦** | 不该拦却拦 |

复盘主键 = `err_kind × fail_bucket`。进入分母的每一条同时具备恰一个 `err_kind` 与恰一个 `fail_bucket`。缺 `err_kind` 的行不进 `n_fail`。不新增第三种 `err_kind`。

交叉是 2×3 六格。六格是计数格子，不是六套新失败类型，也不是第四桶。

|  | 找不到 | 找错 | 没用上 |
|--|--------|------|--------|
| 漏拦 | 计数 | 计数 | 计数 |
| 误拦 | 计数 | 计数 | 计数 |

六格之和等于 `n_fail`。和不等于 `n_fail` 时，当周不报占比，不靠新列把差额收进去。

## 3. 与 SLI 3 分界

**ADR-0028 ≠ fresh/stale/unknown。** 两套词不互相改标，不合流。

| 词 | 属于 | 本页处置 |
|----|------|----------|
| `fresh` / `stale` / `unknown` | SLI 3。生产判定出口。协议在 [`判定-unknown三分协议.md`](判定-unknown三分协议.md) | 不改定义。`unknown` 不是失败。拒识留在 SLI 3 |
| 找不到 / 找错 / 没用上 | 本页离线评测标签 | 不升成 SLI 3 的第四态，不替换 `unknown`，不写入 `unknown_n` |
| `must_unknown` / `must_fresh` / `must_stale` | 金标档名 | 只可出现在离线 `gold_or_human` 旁注。不进生产 score，不充当生产入样键，不改 `status` |
| `void` | 人的终态（ADR-0006） | 不进本页分母，也不进 SLI 3 分母 |

同一条离线复盘可以同时抄录只读的 `machine_status` 与评测标签 `fail_bucket`。抄录不是改标。不得把 `unknown` 改写成「找不到」，也不得把「找不到」写回 `status`。`machine_status=unknown` 且 `fail_bucket=找不到` 可以出现在同一行，两列仍是两套词。

把三桶并进 SLI 3 的三格，或拿 `unknown_n` 充当 `n_fail`，视为合流，本协议违例。

## 4. 不写进生产枚举

三桶只挂在本页、周报附录和样例字段上。

| 生产面 | 既有封闭集 | 本页 |
|--------|------------|------|
| `rule_gate` | 既有校验项。本票不编辑 `src/freshlatch/gates/rule_gate.py` | 不新增以三桶命名的校验项，不把桶名写入 `GateResult` |
| 包结论 disposition | 可发 / 需补丁 / 勿发（ADR-0027） | 不把三桶写进 disposition。`package_disp` 若出现，只读抄录当时的这三词之一 |
| HumanLatch 动词 | `discard` \| `renew`（ADR-0006） | 不新增动词。「没用上」可以描述未收口，描述不扩展封闭集 |
| `Claim.status` | `fresh` \| `stale` \| `unknown` \| `void` | 不改枚举，不按桶回写 |

「没用上」句里出现 Gate 或 HumanLatch，指的是评测观察（证据在场但未进裁决依据，或未收口）。观察句不授权改闸语义，也不授权加动词。

## 5. 分母与样本不足

分母 `n_fail` = 本窗口内、相对金标或人终审已经能判为漏拦或误拦、且 `fail_bucket` 恰为一桶的离线复盘行数。

- 分母不是生产出口全体，不是 `N_exit`，不是 `unknown_n`，不是 B2/B3 的出口条数，不是金标集大小，不是实验固定 k。  
- `n_fail` 为 0，或窗口划不出来，或没有任何一行同时具备恰一 `fail_bucket` 与恰一 `err_kind` 时，三格都写「样本不足」。禁止记成 0、0.0 或 0%。  
- `n_fail` 大于 0 时，三格写 `该桶条数 / n_fail`。某一桶条数为 0 时写 `0 / n_fail`，notes 写明：这是该桶计数，不是失败率为 0，也不是本波 Gate 通过。三格之和必须等于 `n_fail`。  
- 未归入三桶的行不进分母，不单列成第四格。

本页不锁条数通过线。I1 答辩/冒烟 Exit 的「漏拦/误拦 ≥3」写在 ADR-0028 与 `docs/evidence/i1/`，不是本页周报门槛，也不是本波 Gate。

窗口：过去 7 个自然日，或本发布列车窗口。时区 Asia/Shanghai。与 phase-2 附录同一窗口。本页不新写聚合脚本，不改 `src/`。

样本不足时，附录使用下面的句式：

```text
本周样本不足：已挂标失败样本 n_fail=0（或窗口不可划定，或没有同时具备恰一 fail_bucket 与恰一 err_kind 的行），不报找不到/找错/没用上占比；三格写「样本不足」。ADR-0028 三桶 ≠ fresh/stale/unknown。不进 SLI 3，不进 rule_gate / disposition / HumanLatch 动词。禁止写成 0% 或 0。不另起第四桶。
```

同时禁止：

- 用 `unknown_n`、B2/B3、金标条数或实验固定 k 补 `n_fail`  
- 样本不足时宣称某一桶已清零，或宣称本波 Gate 通过  
- 只报其中一桶、删掉另外两列  
- 把 I1 冒烟索引上的历史条数抄进当周三格

## 6. 样例字段

字段名对齐 ADR-0028 的 JSONL 最小集。附录另加 `window` 与 `notes`，用来标明周报窗和「不改标」句。不新增第四套标签名。

空表在 [`docs/evidence/slo-phase2/P2-样例字段.md`](../evidence/slo-phase2/P2-样例字段.md)。本协议不预填比率，不预填样例计数。`docs/evidence/i1/events.jsonl` 只说明这些列长什么样，不把那些行导入本周分母。

| 列 | 说明 |
|----|------|
| `sample_id` | 本窗口离线复盘行身份。空则不进 `n_fail` |
| `claim_id` | 仓内主张身份。只作定位 |
| `window` | 附录列。起止，Asia/Shanghai |
| `fail_bucket` | `找不到` / `找错` / `没用上` 之一。恰一 |
| `err_kind` | `漏拦` / `误拦` 之一。恰一 |
| `gold_or_human` | `gold` 或 `human`。离线对照来源。不进生产 score |
| `machine_status` | 只读抄录当时的生产 `status`。不按桶改写 |
| `package_disp` | 可选。只读抄录可发 / 需补丁 / 勿发。不把桶名写进此列 |
| `layer` | 本协议新挂的行写 `观测/Watch · 离线评测标签`。不回写 I1 已落盘的 `答辩/冒烟` |
| `trajectory_ptr` | 轨迹或对照锚。没有锚的行可以留空，并在 `notes` 写「无轨迹」；无轨迹不自动升桶，也不编造轨迹 |
| `evidence_md` | 人读复盘页指针。可空 |
| `runnable` | 若填，只说明能否按轨迹重放。不充当放行特征，不充当本页通过线 |
| `ts` | 挂标时间 |
| `actor` | 标注者 |
| `notes` | 固定可写「ADR-0028 ≠ fresh/stale/unknown；不进 rule_gate」。未归桶的行写「未归桶」并不进分母 |

空行（复制后填写；尖括号是占位，不是测量值）：

```text
| sample_id | claim_id | window | fail_bucket | err_kind | gold_or_human | machine_status | package_disp | layer | trajectory_ptr | evidence_md | runnable | ts | actor | notes |
| <id> | <id> | <起止 · Asia/Shanghai> | <找不到|找错|没用上> | <漏拦|误拦> | <gold|human> | <只读 status> | <可发|需补丁|勿发|空> | 观测/Watch · 离线评测标签 | <路径或空> | <路径或空> | <true|replay_trace_only|空> | <时间> | <人> | ADR-0028 ≠ fresh/stale/unknown；不进 rule_gate |
```

`gold_or_human=gold` 的旁注留在这张离线表。在线放行器不读这列。生产 score 不读这列。

## 8. 叙事

可接受的观测叙事：

- 「同一窗口附录：找不到、找错、没用上三格同在；每条恰一桶；主键是 err_kind × fail_bucket」  
- 「n_fail=0，三格写样本不足，不报点估计」  
- 「某一桶是 0 / n_fail；这是该桶计数，SLI 3 的 unknown 另计」

不可接受的叙事：

- 「找不到变少了，所以 unknown 变少了」或反过来用 unknown 解释三桶  
- 「三桶已经写进 rule_gate / disposition / 人审动词」  
- 「加了第四桶之后，样本都能归类」  
- 「P2 已过线，本波 Gate 通过」  
- 「接近乙」或任何把本页数字写成路线 Y 改判的句子  
- 把 I1 冒烟条数说成当周生产观测已达标

本波 P2 为观测/Watch · 离线评测标签，不作本波 Gate 生死。升 Gate 须另决议，并事先锁定判据。
