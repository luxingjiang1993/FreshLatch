## 1. 周表模板（可复制）

```text
# FreshLatch · 人审 B2/B3 周表 · <window 起止 · Asia/Shanghai>

- window: <起止 · Asia/Shanghai>
- 取数口: latch_log（列清单见 人审-override周报.md §6；只读，不改写路径）
- 声明: ≠模型变好 / ≠验收绿灯（ADR-0023）· 生产观测 ≠ 乙尺 · North Star=B2；guardrails 不并分

| 行 | 分子 | 分母 | 本周值 | 样本不足时 |
|----|------|------|--------|------------|
| B2 人审有效动作率（North Star） | 窗口内 latch_log 真实 discard∪renew 行（renew 必须带可点回 T1 evidence_id） | 窗口内可人审主张（reviewable claims） | <n/m 或比率> | 写「样本不足」，禁止 0% / 0.0 |
| B3 override rate（SLI 4 / C2） | override=1 的人审行数 | override 已标注（0 或 1）的人审行数 | <n/m 或比率> | 写「样本不足」，禁止 0% / 0.0 |
| B1 设计伙伴按次会话数 | 完整信封会话数（计数，无分母） | — | <n> | 写「样本不足」；禁本地空跑顶 B1（实数属 §E，Owner 外联） |

notes: <人审动词仍只有 discard|renew（ADR-0023 · ADR-0006）；未新增动词；未回写 Y；无健康分列>
```

填数规则：有数则填分子分母两笔再算比率；无数写「样本不足」，**禁把缺样本写成 0% / 0 ms / 0.0**。B3 的分子分母细则以 [`人审-override周报.md`](人审-override周报.md) §1 为准（本表不复写）。

## 4. 否写

- 表绿 ≠ RESULT-Y 乙 / ≠ 注册通过 / ≠ PMF；本表不是验收面。模板入库 ≠ 有数；实数等 §E / 真实人审流量。
- 禁综合健康分：B2、B3、B1 任两行不得合成一个分；不与 RESULT-Y（丙）并图并句。
- 空样本 ≠ 0%：分母为 0 只能写「样本不足」。
- 禁本地空跑 / 合成会话顶 B1；伙伴日志唯一真源是 [`设计伙伴按次日志.md`](设计伙伴按次日志.md)，B1 实数属 §E。
- B3 就是 SLI 4 / C2，不另起平行 KPI 名。
- renew 无 T1 evidence_id 不算有效动作（同 `RENEW_NO_EVIDENCE` 拒径，见 [`拒答行为夹具.md`](拒答行为夹具.md) G2-RN-01）。
- 不新增 HumanLatch 动词；不改 `src/freshlatch/gates/human_latch.py`。
