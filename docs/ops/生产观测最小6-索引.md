## 1. 层身份

本波主 SLI 的层身份是 **观测/Watch + 离线 canary**。

| 层 | 本波用法 |
|----|----------|
| 观测/Watch | SLI 1–5。周报或抽检。本波不作 Gate 生死。 |
| 离线 canary | SLI 6。冻结金标 / Hard-Gold 多跑。不进生产 score。掉线只触发停发讨论，不回写 Y。 |
| 硬闸 | 继承 ADR-0042 的不变量（无证拒拦、未确认不出门、自红转绿=0、无 T1 绿灯=0）。支撑计数在 defer 的 #512，**不是**本波第 7 个主 SLI。 |
| 实验-only | 路线 Y 另页。只读。不进本索引的成功判据。 |

数值门槛本波只给起步姿态。硬百分数 Gate 须后续决议。事后改门槛凑绿 = 本页作废。

## 2. 最小 6 成员（本波不增删）

| # | SLI | 操作定义 | 分母 | 层 | 复用锚 | 起步姿态 |
|---|-----|----------|------|----|--------|----------|
| 1 | false-accept（误放） | 生产放行 / confirm 出口里，事后抽检判定为坏改的占比 | 抽检放行样本；与 #2 成对 | 观测/Watch | #514 SLO-05 · B2 | 先建基线；样本不足写诚实句；禁止只报放行率 |
| 2 | false-reject（误拒） | 该放被拦的占比 | 与 #1 同窗 | 观测/Watch | #514 SLO-05 · B3 | 必须与 false-accept 同表 |
| 3 | unknown / abstention | 显式 `unknown` / abstain（含 must_unknown）占比。拒识算能力 | 判定出口总数；与 fresh/stale 并存 | 观测/Watch | 仓内三档 + ADR-0028；对照 HALT-RAG | 报率，并保留「装绿=0」硬闸指针；不把 unknown 压成 false-reject |
| 4 | HumanLatch override | 人推翻机器判定的 override rate（派生标签） | `latch_log` 可计事件 | 观测/Watch | #511 SLO-06 · C2；ADR-0023；ADR-0006 | 周报。文首声明不作绿灯。不新增 HumanLatch 动词。C1 作废率可旁注 |
| 5 | e2e P95 latency + retrieval fallback rate | 同一行两个字段：（a）端到端 P95（ms）；（b）检索路径 `bm25_fallback` / `lexical_fallback` / rerank 缺失回退的比率 | （a）成功完成请求；（b）检索调用次数 | 观测/Watch | 仓内 fallback 记录语义；对照 NVIDIA RAG observability / Arize Phoenix 的字段习惯 | 同周报一行。cost 不进本波。P95 单独好看不算放行成功 |
| 6 | frozen gold canary pass rate | 冻结金标 / Hard-Gold 子集上 canary 或 multi-run 通过率 | 冻结 canary 集大小；版本针用 code pin / dataset pin 占位 | 离线 canary | arXiv 2608.26385；#515 D1/D5 口径可摘（票 defer） | 发布前或周跑。金标只读。掉线不回写 Y |

字段名映射到仓内 B2/B3/C2/unknown/canary/P95/fallback。不新建 Confident-* 或 Phoenix-* 主名。

### 成员之间

- #1 与 #2 同窗。缺一侧写「样本不足」，不写假 0%。  
- #3 与 fresh/stale 共存。禁止把 abstention 重标成 false-accept 或 false-reject。  
- #4 高低只表示分权，不等于模型变好或变差，不作验收绿灯。  
- #5 的两个字段同一行。  
- #6 掉线是发布风险，不是改判丙的信号。  
- 禁止只报放行率（B1）当成功。
