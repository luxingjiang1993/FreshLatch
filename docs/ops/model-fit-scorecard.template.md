结论格只填一个词，三选一：

| 词 | 含义 |
| --- | --- |
| `keep` | 维持当前登记。不把这一槽改到本地 LMS。 |
| `prefer_local` | 日常草稿建议走本地 LMS。registry 里的生产默认模型 id 仍然不动，换默认另票。 |
| `must_cloud` | 必须留在云端（或正式读点禁止 `local-lms`）。本地 LMS 不替代。 |

`nli` 若维持 transformers 本地权重、不进 LM Studio，结论用 `keep`，不用 `prefer_local`。`prefer_local` 在本计划里专指 LM Studio 草稿覆盖。
