> **层身份**：观测 / **Watch**。生产侧误放与误拒的成对观测（或抽检折算）；**不是**硬闸；**不是**实验乙尺；**不是** demo 冒充总体。  
> **权威互指**：运营真源 `docs/ops/生产补丁放行SLO.md` §3.2（B1/B2/B3）· §5（双管验收包）· §6（周报字段）；评估 `docs/research/生产补丁放行SLO设计评估.md` §4；ADR-0034。  
> **改侧抽检**：字段与抽样框可复用 `docs/ops/抽检-补丁改对率.md`（A2/A3/A4）；本页不重写该正文。  
> **冻结**：不回写 `RESULT-Y`；不实现 / 不调用实验 `compare_primary`；金标与人标结果 **禁止** 写入生产 score / 在线放行路径。

## 1. 字段定义（B2 / B3）与分母

单位分两类样本（同一窗口、同一周报必须成对出现）：

1. **放行样本**：窗口内已放行 / 已 `allow` 出门的候选（含 confirm 后 release、发前钩子 allow；周报须写明采用的出口定义）。  
2. **拒拦样本**：窗口内被闸或钩子拒绝、未出门的候选（无证拒、核验不过、人拒、钩子 deny 等；周报须写明桶）。

人标在可核对语境下判定「该不该放」（相对勾选 T1 / 任务真相；与改侧 A3/A4 可对齐，但本页分母是**放行决策**，不是「确认后改对」 alone）。

| ID | 名称 | 操作定义（人标 / 折算） | 分子 / 分母 | 层 |
|----|------|-------------------------|---------------|-----|
| **B2** | 误放率 | 已放行样本中，人标认为 **不该放**（坏改、证据不支撑、或会害客户的严重错改出门） | 误放条数 / 本周放行侧可判定抽检条数 | 观测 |
| **B3** | 误拒率 | 拒拦样本中，人标认为 **该放**（事实与证据足以出门，却被拦） | 误拒条数 / 本周「人标该放」可判定条数（见 §1.1） | 观测 |

### 1.1 分母细则（硬句）

- **B2 分母** = 放行侧抽检中可判定条数（`insufficient_context` 不进分母）。放行侧抽检量为 0 时，B2 **无定义**，禁止记成 0。  
- **B3 分母** = 本周抽检中人标为「该放」的可判定条数（可来自拒拦侧为主、必要时含对照用的放行侧「该放」条，须在周报注明构成）。分母为 0 时，B3 **无定义**，禁止记成 0。  
- **禁止**用「候选总数」或「仅放行率」替代 B2/B3 分母。  
- **禁止**用实验臂固定放行集 k 充当生产 B2/B3 分母（见 §3）。

### 1.2 单条标注枚举（最小集）

每条样本填出口状态 + 一档人标（可另附备注）：

| 出口状态 | 标签 | 含义 | 计入 |
|----------|------|------|------|
| 已放行 | `release_ok` | 该放且已放 | 放行侧可判定；非 B2 |
| 已放行 | `false_accept` | **误放**：不该放却放了 | B2+ |
| 已拒拦 | `reject_ok` | 不该放且已拦 | 拒拦侧可判定；非 B3 分子 |
| 已拒拦 | `false_reject` | **误拒**：该放却拦了 | B3+（且计入 B3 分母「该放」） |
| 任一 | `insufficient_context` | 无法判定该/不该放 | **不进** B2/B3 比率分母 |

约定：周报必须同时给出 B2 与 B3（或双侧诚实句）；只报其一 = 本协议违例。

### 1.3 与 B1 / 硬闸的关系

- **B1 放行率**（release / 候选）可旁注，但见 §5：**禁止**单独升高当成功。  
- 本协议数字 **不** 替代 B6/B7/C5/D3 硬闸。  
- 与改侧 A3/A4：放行侧误放样本常与错改重叠，可同批标注、分列报；不得用 A3 升高替代 B2/B3 成对。

## 2. 抽样规则

### 2.1 总体与频率

- **窗口**：过去 7 个自然日（或本发布列车窗口，周报须写明）。  
- **频率**：**每周**（或每发布列车）至少一轮；**B2 与 B3 同一轮成对出报**。  
- **目标完成量**（起步）：放行侧可判定 **n_rel≥10**；拒拦侧可判定 **n_rej≥10**（或「该放」分母 ≥10）。达不到则走 §4，**禁止编造比率**。

### 2.2 抽法（可复现、无金标）

1. 分别列出窗口内放行事件与拒拦事件（账本 / 钩子日志只读）。  
2. 各自按时间戳升序；用固定周种子（建议 `YYYYWW`）确定性洗牌。  
3. 两侧顺序取满目标；总量不足则全取并触发 §4。  
4. **禁止**按实验金标、实验臂、Hard-Gold id 分层抽。  
5. 高风险优先（可选，须注明）：数字/日期/专名/价格等槽位可加权入样。

### 2.3 盲标纪律

- 标注时 **不看** 离线金标、实验组别、`compare_primary` 输出、生产 score、在线放行模型分。  
- 可看：出口状态、`claim_id`、正文前后、`t1_ids` 与 T1 原文、拒拦 reason 码（若有）。  
- 单人须在周报写 `annotator=`。

抽样框细节与改侧协议对齐处，直接遵循 `docs/ops/抽检-补丁改对率.md` §2，不必在本页复制扩写。

## 3. 与实验尺分轨（固定 k · T−C · RESULT-Y）

以下词在本页出现时，身份一律如下（搜索验收用）：

| 词 | 身份 | 生产处置 |
|----|------|----------|
| **固定 k** | **实验-only** | 各臂同 k 的误放尺（运营真源 B4/B8）；**不进生产 KPI**；不得充当本页 B2/B3 分母 |
| **T−C** | **实验-only** | 乙尺配对差（运营真源 B5/E1）；**只读**引用实验页；**不进生产 KPI**；不得与生产 B2 点估计混写或相减冒充乙 |
| **RESULT-Y** | **只读**冻结（路线 Y 结果丙） | **禁止**回写成立格；生产 B2/B3 变绿 ≠ 改判乙；**不进生产 KPI** 叙事 |

补充硬句：

1. 生产协议 **不实现**、不调用、不复述实验 `compare_primary` 的计算语义；该函数与固定放行集误放差属实验门闩另页。  
2. 不得把本页 B2「看起来像」T−C 点估计，或把 B1 放行率当作实验固定放行率。  
3. `PREREG-Y` / `RESULT-Y` / `formal-generations-y` 本票 **零编辑**。

## 4. 样本不足诚实句

当放行侧或拒拦侧（或 B3「该放」分母）未达目标时，周报 **必须** 使用下列句式之一：

```text
本周样本不足：放行侧可判定 n_rel、拒拦侧可判定 n_rej（目标各≥10），不报 B2/B3 点估计；仅列原始标注表。B2 与 B3 仍成对留格为「不足」。
```

或：

```text
本周样本不足，B2/B3 不报比率；误放计数 = fa，误拒计数 = fr（仅计数，不升 Gate，不成单独成功叙事）。
```

禁止：

- 只报 B2 不报 B3（或反向）  
- 用实验固定 k 集或金标条「补」生产分母  
- 在不足时宣称「误放已达标」或本波 Gate 通过  
- 放行数为 0 时把 B2 记成 0；「该放」分母为 0 时把 B3 记成 0

## 5. 成功标准（禁止单独放行率）

本协议下的「成功 / 变好」**必须**同时满足叙事纪律：

1. **禁止**将「仅放行率（B1）升高」写成成功、绿灯或 Gate 通过。  
2. 讨论放行变松/变紧时，**必须**同时给出 B2 与 B3（或双侧样本不足诚实句）。  
3. 可接受的观测叙事示例：  
   - 「B2 下降且 B3 未明显恶化（同窗口成对）」  
   - 「硬闸 B6/B7 保持；B2/B3 本周样本不足，不报点估计」  
4. **不可接受**：  
   - 「放行率升了所以更好」  
   - 「少放了所以更安全」（无 B2）  
   - 「误放降了」（无 B3，可能靠误拒堆出来）

本波 B2/B3 为 **观测-only**，**不作本波 Gate 生死**；升 Gate 须另决议。

## 6. 周报表格（最小列 · 成对必填）

| 列 | 说明 |
|----|------|
| `week` / 窗口 | 如 2026-W41 |
| `N_rel` / `N_rej` | 窗口放行 / 拒拦事件总数 |
| `n_rel_judged` / `n_rej_judged` | 两侧可判定抽检条数 |
| `b2_rate` | 误放 / 放行侧可判定；不足则诚实句 |
| `b3_rate` | 误拒 / 「该放」可判定；不足则诚实句 |
| `b1_rate`（可选旁注） | 放行率；**不得**单独作为成功格 |
| `fa_n` / `fr_n` | 误放 / 误拒计数 |
| `annotator` | 标注者 |
| `notes` | 必须含「成对」确认，或「本周样本不足」；高风险加权说明 |

填入运营真源 `docs/ops/生产补丁放行SLO.md` §6「B2/B3 成对」行时，只抄上表摘要；**禁止**填写 `RESULT-Y` 成立格或「接近乙」句。
