## 0. 目的

同一周报窗口里同时看见误放与误拒。少放本身不构成安全，放行率升高本身不构成成功。

| B2 与 B3 出现在同一 `window` 的周报 | 用单独放行率（B1）升高当成功 |

## 1. 字段定义（B2 / B3）与分母

同一窗口、同一周报必须成对出现两类样本：

1. **放行样本**：窗口内已放行 / 已 `allow` 出门的候选（含 confirm 后 release、发前钩子 allow）。周报写明采用的出口定义。  
2. **拒拦样本**：窗口内被闸或钩子拒绝、未出门的候选（无证拒、核验不过、人拒、钩子 deny）。周报写明桶。

人标在可核对语境下判定「该不该放」（相对勾选 T1 / 任务真相）。本页分母是放行决策。确认后改对率（宽表 A3/A4）可以同批标注、分列填报；A3 升高不能代替 B2/B3 成对。改侧抽检正文在未合并的 #510，本页不依赖那一页，抽样以 §2 为准。

| ID | SLI | 名称 | 操作定义（人标 / 折算） | 分子 / 分母 | 层 |
|----|-----|------|-------------------------|---------------|-----|
| **B2** | 1 false-accept | 误放率 | 已放行样本中，人标认为 **不该放**（坏改、证据不支撑、或会害客户的严重错改出门） | 误放条数 / 本周放行侧可判定抽检条数 | 观测/Watch |
| **B3** | 2 false-reject | 误拒率 | 拒拦样本中，人标认为 **该放**（事实与证据足以出门，却被拦） | 误拒条数 / 本周「人标该放」可判定条数（见 §1.1） | 观测/Watch |

### 1.1 分母细则

- **B2 分母** = 放行侧抽检中可判定条数（`insufficient_context` 不进分母）。放行侧抽检量为 0，或本周未抽放行侧时，B2 写「样本不足」。禁止记成 0 或 0%。  
- **B3 分母** = 本周抽检中人标为「该放」的可判定条数（以拒拦侧为主；若含放行侧「该放」对照条，周报注明构成）。分母为 0 时，B3 写「样本不足」。禁止记成 0 或 0%。  
- 分母使用放行侧可判定条数，以及人标「该放」可判定条数。候选总数和放行率不能充当 B2/B3 分母。  
- 实验臂固定放行集 k 不能充当生产 B2/B3 分母（见 §3）。

### 1.2 单条标注枚举（最小集）

每条样本填出口状态 + 一档人标（可另附备注）：

| 出口状态 | 标签 | 含义 | 计入 |
|----------|------|------|------|
| 已放行 | `release_ok` | 该放且已放 | 放行侧可判定；非 B2 分子 |
| 已放行 | `false_accept` | 误放：不该放却放了 | B2 分子，并计入 B2 分母 |
| 已拒拦 | `reject_ok` | 不该放且已拦 | 拒拦侧可判定；非 B3 分子 |
| 已拒拦 | `false_reject` | 误拒：该放却拦了 | B3 分子，并计入 B3 分母「该放」 |
| 任一 | `insufficient_context` | 无法判定该放或不该放 | 不进 B2/B3 比率分母 |

周报同时给出 B2 与 B3 两格。缺的那一格写「样本不足」，两格都留在同一窗口的表上。只留一格 = 本协议违例。

### 1.3 与 B1 / 硬闸的关系

- **B1 放行率**（release / 候选）可以出现，身份是旁注。见 §5：禁止单独升高当成功。  
- 本协议数字不替代 B6/B7/C5/D3 硬闸。硬闸计数仍以宽表与 ADR-0042 为准，不是本页新造的第 7 个主 SLI。  
- 放行侧误放常与错改重叠，可以同批标注、分列报。不得用 A3 升高替代 B2/B3 成对。

## 2. 抽样规则

### 2.1 总体与频率

- **窗口**：过去 7 个自然日，或本发布列车窗口。周报写明起止，时区 Asia/Shanghai。B2 与 B3 使用这一同一个窗口。  
- **频率**：每周（或每发布列车）至少一轮。两格同一轮出报。  
- **目标完成量**（起步姿态，不是本波 Gate）：放行侧可判定 `n_rel≥10`；B3「该放」分母 ≥10。达不到则走 §4。禁止编造比率。

### 2.2 抽法（可复现、无金标）

1. 分别列出窗口内放行事件与拒拦事件（账本 / 钩子日志只读）。  
2. 各自按时间戳升序，用固定周种子（建议 `YYYYWW`）确定性洗牌。  
3. 两侧按洗牌顺序取到目标量。总量不足则全取，并触发 §4。  
4. 抽样不按实验金标、实验臂、Hard-Gold id 分层。金标不进入生产 score，也不进入本抽检的入样键。  
5. 高风险优先（可选，须注明）：数字、日期、专名、价格等槽位可以加权入样。

### 2.3 盲标纪律

- 标注时不看离线金标、实验组别、`compare_primary` 输出、生产 score、在线放行模型分。  
- 可看：出口状态、`claim_id`、正文前后、`t1_ids` 与 T1 原文、拒拦 reason 码（若日志里已有）。  
- 单人标注时，周报写 `annotator=`。

## 4. 样本不足

放行侧可判定条数未达目标，或 B3「该放」分母未达目标，或任一侧本周没有可判定样本时，周报使用下列句式之一。未达到的那一侧格子写「样本不足」。禁止把该侧写成 0%、0.0 或 0。

```text
本周样本不足：放行侧可判定 n_rel、B3「该放」分母 n_should（目标各≥10），不报未达侧的 B2/B3 点估计；仅列原始标注表。未达侧的格子写「样本不足」。B2 与 B3 仍留在同一窗口。
```

或：

```text
本周样本不足，未达侧的 B2/B3 不报比率，格子写「样本不足」；误放计数 = fa，误拒计数 = fr（仅计数，不升 Gate，不成单独成功叙事）。
```

同时禁止：

- 周报表只留 B2 或只留 B3  
- 用实验固定 k 集或金标条补生产分母  
- 在样本不足时宣称误放已达标，或宣称本波 Gate 通过  
- 放行侧可判定为 0 时把 B2 记成 0；「该放」分母为 0 时把 B3 记成 0

## 5. 成功标准（B1 旁注 · 禁止单独优化拒拦率）

「变好」必须同时满足下面三条：

1. **B1 只作旁注。** 禁止把「仅放行率（B1）升高」写成成功、绿灯或 Gate 通过。  
2. 讨论放行变松或变紧时，同一窗口同时给出 B2 与 B3。缺的一侧写「样本不足」，不删格。  
3. **禁止单独优化拒拦率。** 禁止只把拒拦变多、或只把误拒堆高，写成安全或成功。误放下降的句子必须带上同一窗口的 B3（或该侧「样本不足」）。

可接受的观测叙事：

- 「同一窗口内 B2 下降，且 B3 未明显恶化」  
- 「硬闸 B6/B7 保持；B2/B3 本周样本不足，不报点估计」

不可接受的叙事：

- 「放行率升了，所以更好」  
- 「少放了，所以更安全」（没有 B2）  
- 「误放降了」（没有同一窗口的 B3；下降可能来自误拒变多）  
- 「拒拦率优化了」（单独把多拦当成功）

本波 B2/B3 为观测/Watch，不作本波 Gate 生死。升 Gate 须另决议，并事先锁定判据。
