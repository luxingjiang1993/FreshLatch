## 0. 目的

同一周报窗口里，机器判定与人终审（或人标）能够配成对时，看见一致率，并看见分歧落在哪一格。override 的方向只作为分歧谱的分解，不单独顶替这张谱。

| 要看见的 | 不在本页交付 |
|----------|----------------|
| 同窗可配对样本上的一致率，分子与分母同时出现 | 把一致率写成验收绿灯或模型变好 |
| 分歧谱：机器状态 × 人审动作，六格同在 | 只报一个折叠后的 override rate，并把它叫做校准 |
| override 方向三格：fresh→discard、stale→renew、unknown→renew | 新增 HumanLatch 动词，或把 `override` / `calibrate` 做成 action |
| 与 SLI 4 分列，并可旁注两个分母的差 | 把本页数字写入 C2 的 `c2_rate` 等主列 |
| 分母为 0 时写「样本不足」 | 用 `1 - c2_rate` 填一致率，或把缺样本写成 0% |

SLI 4 的协议仍是 [`人审-override周报.md`](人审-override周报.md)。那一页的主行是 C2 override rate。本页不改那一页 §5 的列，也不在那一页填写一致率。

## 1. 与 SLI 4（C2）分列

C2 回答：已带 override 标签的人审行里，人推翻机器判定的行占多少。  
本页回答：同窗里机器标签和人标签都能读到的样本，有多少对是一致的，不一致的那些对落在哪一格。

| | SLI 4 · C2 | 本页 · P3 |
|--|------------|-----------|
| 身份 | min-6 主行 | phase-2 周报附录旁表 |
| 主数字 | 一个比率 `c2_rate` | 一致率，加上六格分歧谱，加上三格方向 |
| 分母 | `override_labeled_n`：`action` 为 `discard` 或 `renew`，且 `override` 为 0 或 1 的人审行 | `n_paired`：同窗内机器侧与人侧都能配对的行 |
| override | 分子是 `override=1` 的行数 | 方向三格是分歧的分解，不替换 `override_true_n` |
| 所在表 | [`docs/evidence/slo-min6/周报骨架.md`](../evidence/slo-min6/周报骨架.md) 的 SLI 4 格 | [`docs/evidence/slo-phase2/周报附录骨架.md`](../evidence/slo-phase2/周报附录骨架.md) 的 P3 行 |

两页使用同一个窗口，以便旁注分母差。窗口对不齐时，本页不报比率，写「窗口不一致」。禁止另开一窗把样本凑齐。

### 1.1 与 C2 的差（旁注 · 必写）

旁注写在附录 P3 的「与 C2 旁注」格，不写进 SLI 4 的主列。

1. **谱，不是折叠。** C2 把所有 `override=1` 收成一个分子。本页把可配对行铺成六格。六格不齐，当周不算报了 P3。只抄 `c2_rate` 或只抄 `1 - c2_rate`，都不是本页。  
2. **分母可以不同。** C2 的分母不要求 `machine_status_before` 落在 `fresh` / `stale` / `unknown`。本页要求机器侧可读且落在这三词里。`override` 已标注、但机器状态缺失、为空或越出三词的行，留在 C2，不进 `n_paired`。因此 `n_paired` 可以小于 `override_labeled_n`。禁止用 C2 分母填本页，也禁止用 `n_paired` 回填 C2。  
3. **一致率不是 C2 的补数格。** 某一周两个分母碰巧相等时，可配对行上的分歧条数会等于该子集上的 `override=1` 条数。即便如此，一致率仍只写在本旁表。不得把 `1 - c2_rate` 抄进一致率充数，不得把一致率抄进 `c2_rate`。分母不同时，这两个数本来就不是补数。  
4. **方向不是新的主名。** `dir_fresh_discard`、`dir_stale_renew`、`dir_unknown_renew` 是分歧谱的三格明细。它们不是第二个 Override Rate，不新编最小 6 编号，不升成主字段。三格之和等于本页的分歧条数；这个和数不写入 `override_true_n`。  
5. **C1 仍留在 override 周报。** 作废率是 SLI 4 那一页的旁注。本页不接管 C1，不把作废率写成校准。

## 2. 配对

一行人审就是一条候选样本。窗内同一 `claim_id` 可以有多条人审，每条单独配对。不去重成主张数，以免把 C2 的行分母悄悄换成 C1 的主张分母。

`pair_kind` 只有两种，且分母分开。没有第二种记录时，第二种写「未计」，不并进第一种。

| `pair_kind` | 机器侧 | 人侧 | 分母 | 本波周报 |
|-------------|--------|------|------|----------|
| `latch_action` | `machine_status_before` | 成功人审 `action` | `n_paired` | 主旁表。六格必填或整表「样本不足」 |
| `status_label` | 同一行上的机器状态词 | 人写下的 `fresh` / `stale` / `unknown` | `n_paired_label` | 仅当这种人标真实存在。否则「未计」 |

### 2.1 `latch_action`（本波可计数的一对）

同时满足下面五条，才进入 `n_paired`：

- `action` 为 `discard` 或 `renew`  
- `machine_status_before` 为 `fresh`、`stale` 或 `unknown`  
- `override` 已写成 0 或 1（用来核对格子，不单独定义分母）  
- `claim_id` 非空  
- `ts` 落在本窗口  

缺任何一条，该行不进 `n_paired`。`action` 为 `rerun` 或 `basis_rot` 的行不进人侧。失败落档与幂等跳过不新增人审行，也不进分母。

机器侧来源写 `machine_status_before`。tip 上没有另一列自动 judge。本票不新增那一列，不把 `machine_status_before` 改称 judge 来充数。若将来另有只读的自动 judge 记录，它使用单独的 `machine_label_source` 和单独的分母，不混进 `n_paired`。没有该记录时，这一来源写「未计」。

人侧是动作，不是另一套状态词。ADR-0006：`stale` 是机器判定，`void` 是人作废后的终态，二者并存、不互斥。`discard` 不翻译成 `stale`，`renew` 不翻译成 `fresh`。禁止用翻译后的字符串相等来制造一致。

### 2.2 六格（机器状态 × 人审动作）

格子边界与 ADR-0023 的派生谓词相同。本页只把谓词摊开，不改谓词。

| `machine_status_before` \ `action` | `discard` | `renew` |
|--------------------------------------|-----------|---------|
| `fresh` | 分歧 · `dir_fresh_discard` | 一致 |
| `stale` | 一致 | 分歧 · `dir_stale_renew` |
| `unknown` | 一致 | 分歧 · `dir_unknown_renew` |

- **一致** = 上表三只「一致」格的行数之和，记 `agree_n`。这些行的派生标签是 `override=0`。  
- **分歧** = 三只方向格的行数之和，记 `disagree_n`。这些行的派生标签是 `override=1`。  
- `n_paired` = `agree_n` + `disagree_n`。六格之和必须等于 `n_paired`。和不等于时，当周不报占比，不靠新列把差额收进去。  
- 一致率 = `agree_n / n_paired`。只在 `n_paired` 大于 0 且六格已齐时填写。

方向三格只分解分歧，不分解一致：

| 方向 | 行条件 | 含义 |
|------|--------|------|
| `dir_fresh_discard` | `discard` 且 `machine_status_before=fresh` | 机器判 fresh，人作废 |
| `dir_stale_renew` | `renew` 且 `machine_status_before=stale` | 机器判 stale，人续命 |
| `dir_unknown_renew` | `renew` 且 `machine_status_before=unknown` | 机器判 unknown，人续命 |

三格之和等于 `disagree_n`。某一方向为 0 时，在 `n_paired` 大于 0 的前提下写 `0 / n_paired`，notes 写明：这是该方向的计数，不是 override 已清零，也不是本波 Gate 通过。

`discard` 且机器为 `stale` 或 `unknown`，以及 `renew` 且机器为 `fresh`，留在一致格。它们不是第四个方向，也不单列成新的 override 类型。

### 2.3 `status_label`（人标 · 默认未计）

人标指人在本窗口写下的状态词，词表与机器相同：`fresh` / `stale` / `unknown`。它不是 `action`，也不是冻结金标。

仅当这种人标真实记在与机器状态同一 `claim_id`、同一窗口的只读记录上时，才另开 `n_paired_label`：

- 一致 = 两个状态词相同的行数  
- 分歧谱 = 3×3 里不相同的格子，格子名用「机器词 → 人标词」  
- 这一谱与 §2.2 的六格分表。不得把 `discard` 译成 `stale` 之后填进这张表  

没有这种人标时，`status_label` 写「未计」。未计不是 0，不是 0%，也不是样本不足。样本不足只用于 §2.1 已经开了计数、但 `n_paired` 为 0。

冻结金标、Hard-Gold id、实验臂、`gold.json` 不得充当人标，不得充当入样键，不得进入生产 score。

## 4. 样本不足

`n_paired` 为 0，或本窗口划不出来，或没有任何一行同时具备 §2.1 的五条时，一致率、六格、方向三格都写「样本不足」。禁止记成 0、0.0 或 0%。

```text
本周样本不足：同窗可配对样本 n_paired=0（或窗口不可划定，或没有同时具备人审动作、机器三态与 override 标签的行），不报一致率，不报分歧谱点估计；格子写「样本不足」。声明仍为：≠模型变好 / ≠验收绿灯（ADR-0023）。本旁表不改 SLI 4 的 C2 格。禁止写成 0% 或 0。禁止用 1 - c2_rate 填一致率。
```

C2 自己的格子按 [`人审-override周报.md`](人审-override周报.md) 填写。缺 C2 不删 P3；缺 P3 不拿 C2 顶上。C2 为「样本不足」时，旁注写明此事，P3 仍只看 `n_paired`。

同时禁止：

- 用金标条、实验固定 k、生产 score 或 C2 分母补 `n_paired`  
- 样本不足时宣称校准已达标，或宣称本波 Gate 通过  
- 只报一致率、删掉六格或方向三格  
- 把「未计」的 `status_label` 改写成 0%  

`n_paired` 大于 0 时，一致率写 `agree_n / n_paired`。六格各自写 `该格行数 / n_paired`。方向三格写 `该方向行数 / n_paired`。

## 7. 不新增动词，不作 Gate

HumanLatch 动词封闭集仍是 `discard` | `renew`（ADR-0006 · ADR-0023）。`override` 是写入时派生的 bool 标签，不是动词。

本页不新增、也不把下列词收进 `VALID_ACTIONS`：`override`、`calibrate`、`agree`、`judge`。不编辑 `src/freshlatch/gates/human_latch.py`。不把方向三格做成三个 action。

本波不锁一致率通过线，不锁分歧条数通过线，不把 P3 升为 Gate。一致率升高或降低都不构成放行句。升 Gate 或锁定通过线须另决议，并事先锁定判据。ADR-0023 已写明本批不锁 Override Rate 通过线；该禁令覆盖本旁表，本页不另开一条通过线。

## 8. 叙事

可接受的观测叙事：

- 「同一窗口旁表：六格同在；一致率 = agree_n / n_paired；方向三格只分解分歧」  
- 「n_paired=0，格子写样本不足，不报点估计；SLI 4 的 C2 按自己的分母另填」  
- 「n_paired 小于 override_labeled_n；差在机器状态不可读的人审行，那些行留在 C2」  
- 「两个分母同数。一致率仍只写在旁表，不写入 c2_rate」  
- 「某一方向是 0 / n_paired；这是该方向计数，不是验收通过」

不可接受的叙事：

- 「一致率高了，所以模型变好」  
- 「分歧少了，所以验收通过」或「override 少了，所以校准通过」  
- 「本页就是 1 减 C2」并把该数写入 SLI 4  
- 「作废率下来了，所以校准过了」（C1 不是本页）  
- 「人标未计，所以人机已经一致」  
- 任何把本页数字写成实验成立、或拿来改判路线 Y 的句子
