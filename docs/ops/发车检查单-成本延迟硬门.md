# 发车检查单：成本与延迟硬门（A-P5）

层：发车检查。代码在 `src/freshlatch/sli/release_gate.py`，入口是 `check_release_gate`。

本页不改 floors、gold、x1、`PRODUCTION_RETRIEVAL_MODE`、SESOI、C-04、RESULT-Y。基线与 SLA 由调用方传入，本模块不预设这两个数。`cost_is_quality` 恒为 false。`counted_as_pass` 恒为 false。过门也不写成注册通过。

## 检查项

- [ ] 热路径：成本低于调用方基线的 1.5 倍，且 e2e P95 不超过调用方 SLA

达到或超过基线的 1.5 倍，或 e2e P95 超过调用方 SLA，检查单记 **发车红**（`verdict=fail`，`blocked=true`）。两格都在线内记 **发车绿**（`verdict=pass`，`blocked=false`）。发车绿仍保持 `counted_as_pass=false`。

同一条里成本与延迟可以同时破线。`reasons` 先写 `cost_over_baseline`。延迟有毫秒数且超过 SLA 时接着写 `e2e_p95_over_sla`；P95 未测时接着写 `e2e_p95_unmeasured`。超 SLA 与未测不会同时出现。

## 判定

| 条件 | 结果 |
|------|------|
| `observed_cost / baseline_cost >= 1.5` | 发车红，`cost_over_baseline` |
| `e2e_p95_ms > sla_e2e_p95_ms` | 发车红，`e2e_p95_over_sla` |
| `e2e_p95_ms` 为「样本不足」或「未计」 | 发车红，`e2e_p95_unmeasured` |
| 成本低于 1.5 倍，且 P95 是不超过 SLA 的毫秒数 | 发车绿 |

1.5 是检查单倍数，写死在 `COST_FACTOR`。它不是效应量，调用方不能另传一个倍数。等于 1.5 倍记红。P95 等于 SLA 记为未超过。

`baseline_cost` 与 `sla_e2e_p95_ms` 必须大于 0。`observed_cost` 必须是非负有限数。缺了就拒绝，不用 0 或某个库内常数顶上。

成本的单位由调用方自己对齐。`token_total`、`api_cny`、`gpu_s` 任选一种，基线与本次观测用同一种。本门不换算。字段说明在 [`成本周报.md`](成本周报.md)。

未测的 P95 保持「样本不足」或「未计」，禁止写成 0 ms，也禁止当成未超 SLA。

## 主 SLI

延迟来源只能是下面三者之一：

| 参数 | 读法 |
|------|------|
| `window` | 调用 A-P3 `measure_primary_sli`（[`主SLI与burn-rate-page.md`](主SLI与burn-rate-page.md)） |
| `sli` | 已落下的主 SLI 映射，至少含 `e2e_p95_ms` |
| `e2e_p95_ms` | 调用方直接给的毫秒数或占位 |

夹具目录会拒绝。`abstain_rate`、`retrieval_fallback_rate`、`abstain_fallback_rate` 在来源里有就抄上。两率不参与红绿，本页不给它们发明阈值。

## 成本不伪装质量

成本倍数与延迟 SLA 是发车约束。它们不是质量分，不是 groundedness，不是注册 G1/A1/T1/R1，也不是 RESULT-Y。`format_release_gate` 的记录里 `cost_is_quality=false`。

口径来自两处，都不在本页填目标百分数：Databricks 把延迟预算当作发布约束，端到端 P95 超过调用方 SLA 则不发。SRE Workbook 的错误预算政策是预算烧穿则停止发布。本门只用这个「破线则发车红」的口径。可用性目标百分数仍不在本页填写；鉴权后 5xx 的分母说明见 [`serving-failure-budget.md`](serving-failure-budget.md)。

## 回滚关闸

环境变量 `FRESHLATCH_RELEASE_GATE`。

| 值 | 行为 |
|----|------|
| 未设置、空、`on` | 硬门生效 |
| `off` | 关闸 |

`FRESHLATCH_RELEASE_GATE=off` 时仍计算是否破线：`verdict` 与 `raw_fail` 保持原判定，`blocked=false`，`checklist=关闸`，`suppressed=true`。关闸不是发车绿，也不是质量通过。其它取值拒绝。

关闸只解除这一次发车拦截。它不改检索臂，不改主 SLI 的计数，也不把未测写成绿灯。
