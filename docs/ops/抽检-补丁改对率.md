# 抽检协议：补丁改对率（A2 · A3 · A4）

> **层身份**：观测 / **Watch**。人标抽检与周报字段；**不是**硬闸；**不是**实验乙尺；**不是** demo 冒充总体。  
> **起步线**：确认后严重错改（会害客户）Watch 讨论线 **&lt;5%**——本波 **观测-only**，**不作本波 Gate 生死**。升 Gate 须另决议（ADR-0034 / 评估 §4）。  
> **权威互指**：运营真源 `docs/ops/生产补丁放行SLO.md` §3.1（A2/A3/A4）· §4（起步阈值）· §6（周报字段）；评估 `docs/research/生产补丁放行SLO设计评估.md` §4；ADR-0034。  
> **冻结**：金标标签、抽检标签、人标对错 **禁止** 写入生产 score / 在线放行路径；不回写 `RESULT-Y`。

## 0. 目的与非目的

| 目的 | 非目的 |
|------|--------|
| 看见「过闸 ≠ 改对」：证据是否对上、确认后是否事实对、是否严重错改 | 用抽检率当本波 Gate 生死 |
| 周报可填 A2/A3/A4（或诚实「本周样本不足」） | 把金标 / 抽检标签喂进生产 score 或在线放行器 |
| 严重错改操作定义可对齐「会害客户」 | 复活 `patch_events` 冲乙 / 同页二跑 |
| 只读既有确认账本抽样 | 本票改 `src/` 或改闸语义 |

## 1. 字段定义（A2 / A3 / A4）

单位：**一条已 `human_confirm=true` 的补丁确认事件**（优先含 `before_text` / `after_text` / `t1_ids` 的正式确认行）。账本指针见 §5。

| ID | 名称 | 操作定义（人标） | 分子 / 分母 | 层 |
|----|------|------------------|---------------|-----|
| **A2** | 证据覆盖 | 改动点能否在勾选的 T1（`t1_ids`）原文上对上：主张变更所依赖的事实片段，是否落在已引用 T1 的可核对范围内 | 证据对上条数 / 本周抽检完成条数 | 观测 |
| **A3** | 改对率 | 确认后的 `after_text`：标注者认为 **与证据一致且事实对**（相对勾选 T1 与任务语境下的可核对真相） | 改对条数 / 本周抽检完成条数 | 观测（主抽检指标） |
| **A4** | 错改率 | 确认（或已放行）后仍与真相不符——与 A3 **成对**：同一批样本上，非「改对」即计错改（含一般错改与严重错改） | 错改条数 / 本周抽检完成条数 | 观测 |

### 1.1 单条标注枚举（最小集）

每条样本填且仅填一档主标签（可另附备注）：

| 标签 | 含义 | 计入 |
|------|------|------|
| `evidence_ok_correct` | 证据对上且 after 事实对 | A2+ · A3+ |
| `evidence_ok_wrong` | 证据对上但 after 仍错（含严重） | A2+ · A4+ |
| `evidence_miss` | 证据对不上（改动点无 T1 支撑或对错位） | A2−；不得记 A3+；通常 A4+ 或流程违例备注 |
| `severe_harm` | **严重错改（会害客户）**——见 §3；可与上列错改叠记，周报单独计严重条数 | A4+（严重子集） |
| `insufficient_context` | 标注者无法从现有 T1/正文判定 | **不进** A2/A3/A4 比率分母；记「无法判定」计数 |

约定：`A3 改对率 + A4 错改率` 在「可判定样本」上应成对可加（允许四舍五入误差）；`insufficient_context` 不进比率。

### 1.2 与流程硬句的关系（非本协议升 Gate）

- 「证据对不上不得 confirm」是运营真源页流程纪律（A2 起步注）；本协议 **事后抽检** 仍要报 A2，用于看见漏网与标注漂移。  
- 本协议数字 **不** 替代 B6/B7/C5/D3 硬闸。

## 2. 抽样规则

### 2.1 总体与频率

- **总体**：过去 7 个自然日（或本发布列车窗口，周报须写明窗口）内、`human_confirm=true` 的补丁确认事件。  
- **频率**：与运营真源一致——**每周**（或每发布列车）至少一轮。  
- **目标完成量**：起步每周 **n≥10** 条可判定样本（`insufficient_context` 另计）。达不到则走 §4 诚实句，**禁止编造比率**。

### 2.2 抽法（可复现、无金标）

1. 从账本列出窗口内确认行，按 `ts` 升序得到有序列表。  
2. 用固定周种子（建议 `YYYYWW` 整数，如 `202641`）对列表做确定性洗牌（同一周同一列表 → 同一顺序）。  
3. 顺序取满目标 n；若总量 &lt; n，则 **全取** 并触发 §4。  
4. **禁止**按金标对错、实验臂、或已知 Hard-Gold id 分层抽（避免把离线金标渗进生产抽检）。  
5. 高风险优先（可选加权，须在周报注明）：涉及数字/日期/专名/价格/份额等槽位的 `patch_span` 可提高入样概率，但仍不得读取金标标签。

### 2.3 盲标纪律

- 标注时 **不看** 离线评测金标、实验组别、生产 score、在线放行模型分。  
- 可看：`claim_id`、`before_text`/`after_text`、`t1_ids` 及对应 T1 原文、`patch_span`、`before_disp`。  
- 双人标注非本波必选；单人须在周报写 `annotator=`。

## 3. 严重错改（会害客户）操作定义

**严重错改** = 确认后的 `after_text`（或已放行正文）相对可核对真相为错，且若客户按该主张行动，**合理预期会造成实质损害**。满足任一即标 `severe_harm`：

1. **数字/钱/比例**：价格、份额、营收、成本、折扣、SLA 数值等写错，且错误方向会对商务或合规决策产生误导。  
2. **日期/时点**：生效日、截止日、财季、版本时点写错，导致「仍有效/已过期」判断反转。  
3. **专名/主体**：公司、产品、合同方、监管主体张冠李戴。  
4. **极性/可否**：把「勿发/禁止/未证实」写成可发或肯定主张，或反向。  
5. **无中生有**：after 引入勾选 T1 **完全不支持** 的关键事实，且该事实属客户决策敏感（报价、合规、出货、承诺）。

**非严重**（仍可记一般错改 / A4）：措辞笨拙但事实骨架对；同义改写；不影响决策的笔误。

周报同时报：

- `severe_n` / `n_judged` → 严重错改率（对照 Watch 讨论线 **&lt;5%**）  
- 该线 **观测-only**：可讨论、可进周报趋势；**不作本波 Gate 生死**

## 4. 样本不足诚实句

当窗口内确认事件总数 &lt; 目标 n，或可判定样本 &lt; 目标 n 时，周报 **必须** 使用下列句式之一（可微调日期/数字，不得改成虚假比率）：

```text
本周样本不足：窗口内确认事件 M 条，可判定抽检 m 条（目标 n=10），不报 A2/A3/A4 点估计；仅列原始标注表。
```

或：

```text
本周样本不足，A3/A4 不报比率（m<n）；严重错改计数 = s（仅计数，不升 Gate）。
```

禁止：

- 用上周转抄凑满 n  
- 用金标条「补」生产抽检分母  
- 在 m&lt;n 时宣称「严重错改 &lt;5% 已达标」或本波 Gate 通过

## 6. 周报表格（最小列）

| 列 | 说明 |
|----|------|
| `week` / 窗口 | 如 2026-W41 |
| `M` | 窗口确认事件总数 |
| `n_drawn` | 抽出条数 |
| `n_judged` | 可判定条数 |
| `a2_rate` | 证据对上 / `n_judged`；不足则诚实句 |
| `a3_rate` | 改对 / `n_judged` |
| `a4_rate` | 错改 / `n_judged` |
| `severe_n` / `severe_rate` | 严重错改计数与比率；对照 &lt;5% **观测线** |
| `annotator` | 标注者 |
| `notes` | 含「本周样本不足」或高风险加权说明 |

填入运营真源 `docs/ops/生产补丁放行SLO.md` §6 对应「A3/A4 抽检」行时，只抄上表摘要。

## 7. 禁止：金标 / 抽检进生产 score 与在线放行

硬纪律（与运营真源 E4、评估 §4、ADR-0034 一致）：

1. **禁止**将金标（Hard-Gold / must_stale 等离线标签）写入生产 score、在线放行器特征、confirm/release 决策输入。  
2. **禁止**将本协议人标结果（A2/A3/A4/`severe_harm`）写入生产 score 或自动放行路径。  
3. 抽检与金标仅服务 **观测周报** 与 **离线评测**；二者物理与叙事隔离。  
4. 搜索本页「生产 score」「在线放行」：凡出现处均为 **禁止** 语境。
