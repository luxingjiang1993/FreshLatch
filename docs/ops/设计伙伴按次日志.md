# 设计伙伴按次日志（E2）

> **按次复验日志 ≠ 客户成功 KPI ≠ 乙尺。**  
> 本页钉顾问垂直设计伙伴做 **一次** Reverify Sheet 复验时，必须留下的会话级字段，以便 90 天 kill 的 (b) 可审计。  
> 人审动词仍是 `discard` | `renew`（ADR-0006）。`override` 是派生 bool（ADR-0023），不是新 action。  
> **禁止**合成冒充客户 outcome；合成 UX / Playtest 见仓外 v1.1，合成分不作本页通过线。  
> **不改** `src/freshlatch/gates/human_latch.py` 动词集；不编辑 RESULT-Y/PREREG-Y。  
> Provenance：**adapt** ADR-0023 · ADR-0006 · [`人审-override周报.md`](人审-override周报.md) · 只读 [`docs/_archive/2026-10/research/ε-override与void事件管道字段设计评估.md`](../_archive/2026-10/research/ε-override与void事件管道字段设计评估.md)。

层身份：产品证据 / 人审审计。本页数字不作 Gate 生死，不作「模型变好」。

## 2. 人审行（每条 discard/renew 一行）

与 `latch_log` 契约对齐；会话文件可摘要抄写，权威仍以运行时 latch_log 为准（若有）。

| 字段 | 必填 | 说明 |
|------|------|------|
| `ts` | 是 | 人审写入时间 |
| `claim_id` | 是 | |
| `action` | 是 | `discard` \| `renew` 仅此二值 |
| `evidence_id` | 否 | 有则填 |
| `actor` | 是 | 人审操作者 |
| `machine_status_before` | 是 | `fresh` \| `stale` \| `unknown` |
| `override` | 是 | 派生 bool：discard∧fresh → true；renew∧(stale\|unknown) → true；否则 false |
| `voided` | 是 | 本行是否导致写入 `invalidation_list` |
| `renew_blocked_reason` | 条件 | renew 失败时必填：如 `no_t1` / `evidence_insufficient` / `humanlatch_blocked` / `other:<text>` |
| `reviewer_note` | 否 | |
| `run_id` | 否 | |

### 2.1 override 硬禁（ADR-0023）

- 禁止：override 变少 ⇒ 模型变好  
- 禁止：本会话 override 率当作验收绿灯  
- 允许：记录人机分权是否被记下

---

## 3. 会话 outcome（恰好一个）

| `outcome` | 含义 |
|-----------|------|
| `voided` | ≥1 主张经 discard 进入作废名单 |
| `renewed` | ≥1 主张经合格证据 renew 成功 |
| `blocked` | 伙伴尝试续命/作废但被 HumanLatch 或无 T1 挡住（失败是证据） |
| `abandoned` | 会话中途退出，无成功 void/renew |

多主张时：若同时有 voided 与 renewed，outcome 取 **主目标** 并在 `notes_session` 写明另一侧计数；不得把 blocked 行藏掉。
