## 0. 目的

在主张粒度上看机器放行或陈述是否与所点回的 T1 证据一致。同一窗口同时给出 claim-level faithfulness 与不忠实率。忠实率单独升高不构成成功。

| 要看见的 | 不在本页交付 |
|----------|----------------|
| 每条抽检主张可挂 `claim_id` | 用 P1 比率替换 min-6 SLI 1/2 的 B2/B3 成对主行 |
| 与 SLI 1/2 同一 `window` 的附录行 | 新编 A/B 号，或新建 Confident-* 主名 |
| 样本不够时的诚实句 | 把缺样本写成 0% 或 0 |
| 离线人标对照所点回的 T1 原文 | 把金标写入生产 score 或在线放行器 |

出口成对协议仍是 [`抽检-放行误放误拒.md`](抽检-放行误放误拒.md)。本页从那一页的抽检框往下拆，不改那一页 §1 的 B2/B3 定义，也不改那一页 §6 的周报列。

## 1. 与 SLI 1/2 的关系（细化 · 折算起点）

SLI 1/2 的一行是一条出口（已放行或已拒拦）。本页的一行是该出口上的一条主张。

1. **抽样框**沿用同一窗口的出口抽检（放行事件与拒拦事件）。主张从这些出口上拆出。本页不另开一套按金标、实验臂或 Hard-Gold id 分层的总体。  
2. **折算**：出口标签（`release_ok` / `false_accept` / `reject_ok` / `false_reject` / `insufficient_context`）只作为父行指针 `parent_exit`。父行的 B2/B3 比率仍按出口协议填写。  
3. **不回写**：某一主张判为不忠实，不自动改写该出口的 B2 或 B3 格子。P1 的两个比率不写入 `b2_rate` / `b3_rate`。  
4. **出口抽检未做**：该窗口还没有 SLI 1/2 抽检框时，本页不单开样本、不报比率，走 §5 的诚实句。不从冻结金标集或全量台账补分母。  
5. **拆不出主张**：出口行在，但挂不上 `claim_id` 时，本页不报比率。出口侧 B2/B3 仍按原协议留在 min-6 周报主行。

`unknown` / abstain 保持 SLI 3 的身份。拒识不改标成 `claim_unsupported`，也不塞进本页分母。

## 2. 字段定义与分母

分母是**可判定主张**，不是出口条数，不是候选总数，不是放行率。

| 项 | 操作定义 | 分子 / 分母 | 层 |
|----|----------|-------------|-----|
| **claim-level faithfulness** | 可判定主张中，人标认为主张与所点回的 T1 证据一致 | `claim_supported` 条数 / `n_claim_judged` | 观测/Watch（可离线抽检） |
| **不忠实率** | 同一批可判定主张中，人标认为主张不被所点回的 T1 证据支撑（多说、改义、或点回的锚不承载该句） | `claim_unsupported` 条数 / `n_claim_judged` | 观测/Watch（可离线抽检） |

两格使用同一个 `n_claim_judged`，必须同时出现。只留一格 = 本协议违例。

### 2.1 分母细则

- `n_claim_judged` = 抽检表中 `claim_id` 非空，且 `verdict` 为 `claim_supported` 或 `claim_unsupported` 的行数。  
- `claim_insufficient` 不进分母。`claim_id` 为空的行不进分母，即使备注里写了判断。  
- `n_claim_judged` 为 0，或未达 §4 的起步量时，两格都写「样本不足」。禁止记成 0、0.0 或 0%。  
- 出口条数、候选总数、B1 放行率、实验固定 k、金标集大小，都不能充当本页分母。

### 2.2 单条判定枚举

每条主张一行。`verdict` 只取下表三值。

| verdict | 含义 | 计入 |
|---------|------|------|
| `claim_supported` | 主张与所点回的 T1 证据一致 | 分母；claim-level faithfulness 分子 |
| `claim_unsupported` | 主张不被所点回的 T1 证据支撑 | 分母；不忠实率分子 |
| `claim_insufficient` | 无法判定（无可用证据指针，或语境不够） | 不进比率分母 |

人标看的是该主张点回的 T1 原文（`t1_evidence_ids`）。判定以 T1 原文为准。离线做完的结论只留在抽检表，不回写生产 score，不改闸。

### 2.3 与人 / 金标对照窗

`contrast_window` 记录这一行拿什么对照，两格比率仍是上面的人标比率。

| 值 | 用法 |
|----|------|
| `human` | 默认可离线抽检。人对照 T1 原文填 `verdict` |
| `gold_readonly` | 离线金标只读旁注。该列不进生产 score，不被在线放行器读取，不回写 `parent_exit`，不改 B2/B3 |

金标旁注可以用来说「这一窗曾与冻结集对过」。它不是本页的成功格，也不是放行特征。

## 3. 抽检表（可挂 claim_id）

一行一条主张。填进当周副本或本页表式。禁止把数字写入 `RESULT-Y` 成立格。禁止写入 min-6 周报的 SLI 1·2 主格。摘要只进 [`docs/evidence/slo-phase2/周报附录骨架.md`](../evidence/slo-phase2/周报附录骨架.md) 的 P1 行。

| 列 | 说明 |
|----|------|
| `claim_id` | 仓内主张身份。空则该行不进 `n_claim_judged` |
| `window` | 起止，Asia/Shanghai。与 SLI 1/2 同一窗 |
| `parent_exit` | 只读：出口状态 + 出口标签。不回写该出口的 B2/B3 |
| `t1_evidence_ids` | 该主张点回的 T1 证据。空则 `verdict` 取 `claim_insufficient`，除非 `notes` 写明标注者离线看过的锚 |
| `verdict` | `claim_supported` / `claim_unsupported` / `claim_insufficient` |
| `contrast_window` | `human` 或 `gold_readonly`。后者不进生产 score |
| `annotator` | 标注者 |
| `notes` | 写「不替换 FA/FR」。无 `claim_id` 时写「无 claim_id」 |

空表（复制后填写；本协议不预填比率）：

```text
| claim_id | window | parent_exit | t1_evidence_ids | verdict | contrast_window | annotator | notes |
| <id> | <起止 · Asia/Shanghai> | <出口状态/出口标签 · 只读> | <id,id 或空> | <claim_supported|claim_unsupported|claim_insufficient> | <human|gold_readonly> | <人> | 不替换 FA/FR |
```

周报附录只抄摘要，不把上表整表塞进 min-6 主行：

| 列 | 说明 |
|----|------|
| `window` | 与抽检表、与 SLI 1/2 同一窗 |
| `n_claim_judged` | 可判定主张数。不足则两格写「样本不足」 |
| `n_supported` / `n_unsupported` | 计数。不足时可以留计数，不升成比率 |
| claim-level faithfulness | `n_supported` / `n_claim_judged`。不足则「样本不足」，禁止 0% |
| 不忠实率 | `n_unsupported` / `n_claim_judged`。同一分母。不足则「样本不足」，禁止 0% |
| `notes` | 「不替换 FA/FR 成对主行」。缺样本时改抄 §5 诚实句 |

## 4. 抽样（起步姿态 · 不是本波 Gate）

### 4.1 总体与频率

- **窗口**：与 [`抽检-放行误放误拒.md`](抽检-放行误放误拒.md) §2.1 同一窗口（过去 7 个自然日，或本发布列车窗口）。时区 Asia/Shanghai。  
- **频率**：每周（或每发布列车）至多跟该窗口的出口抽检一起出附录。没有出口抽检框就不出 P1 比率。  
- **目标完成量**（起步姿态，不是本波 Gate）：`n_claim_judged≥10`。达不到则走 §5。禁止编造比率。

### 4.2 抽法

1. 读取该窗口已经抽出的放行事件与拒拦事件（账本 / 钩子日志只读）。不新造一套入样键。  
2. 每个出口上，列出已经挂着 `claim_id` 的主张。一条主张一行。  
3. 总量不足 10 条可判定主张则全取，并触发 §5。  
4. 抽样不按实验金标、实验臂、Hard-Gold id 分层。金标不进入生产 score，也不进入本抽检的入样键。  
5. 高风险槽（数字、日期、专名、价格）可以在 `notes` 注明优先看过。注明了也不改 B2/B3。

### 4.3 盲标纪律

- 标注时不看离线金标、实验组别、`compare_primary` 输出、生产 score、在线放行模型分。  
- 可看：`claim_id`、主张正文、`t1_evidence_ids` 与 T1 原文、`parent_exit` 的出口状态（只作定位）。  
- `gold_readonly` 旁注若要填，填在 `verdict` 已经落盘之后，并在 `notes` 写「旁注不进 score」。  
- 单人标注时，周报写 `annotator=`。  
- 离线：把上述行导出后对照 T1 原文。结论留在抽检表。不回写放行特征。

## 5. 样本不足（诚实句）

`n_claim_judged` 未达 10，或为 0，或该窗口没有出口抽检框，或出口在但没有可挂 `claim_id` 的主张时，附录两格都写「样本不足」。禁止写成 0%、0.0 或 0。SLI 1/2 成对主行仍按出口协议另填，本页不代填、不覆盖。

有出口抽检框、但可判定主张不足时：

```text
本周样本不足：可判定主张 n_claim_judged（目标≥10），不报 claim-level faithfulness / 不忠实率点估计；抽检表仍可挂 claim_id。格子写「样本不足」。SLI 1/2 的 B2/B3 成对主行按 docs/ops/抽检-放行误放误拒.md 另填，本附录不替换那两格。
```

出口抽检框还没有时：

```text
本周尚未有 SLI 1/2 出口抽检框，P1 不单开样本、不报比率。FA/FR 主行按该协议自行填写。本附录不补写那两格。
```

出口在、但没有可挂 `claim_id` 的主张时：

```text
本周出口抽检未能拆出可挂 claim_id 的主张，不报 P1 比率，不把空表写成 0%。FA/FR 成对主行不动。
```

同时禁止：

- 用 P1 的两格覆盖 min-6 周报里的 false-accept / false-reject  
- 用实验固定 k、金标条或全量台账补本页分母  
- 在样本不足时宣称忠实率已达标，或宣称本波 Gate 通过  
- 只报 claim-level faithfulness、删掉不忠实率  
- 把 `n_claim_judged=0` 记成 0%

## 6. 对照映射（字段习惯 · 不新建主名）

Confident AI 文档里的 faithfulness / groundedness 只说明「主张是否被给定证据支撑」这一习惯。下表是对照，不是第二套主 KPI。

| 公开习惯 | 仓内落点 |
|----------|----------|
| 把输出切成主张再逐条看 | 抽检表一行一个 `claim_id` |
| 检索上下文 / 给定证据 | `t1_evidence_ids` 点回的 T1 原文 |
| faithfulness（主张被证据支撑的占比） | 本页 claim-level faithfulness |
| groundedness（陈述落在所给证据上） | 同一 `verdict`。不另开一列主比率 |
| 无法判断 | `claim_insufficient`，不进分母 |
| 理由 | `notes` |

本页不新建 Confident-* 主名。不把上述习惯写成生产 score 字段。

## 7. 成功标准（附录叙事）

「变好」必须同时满足下面三条：

1. 同一窗口的附录里，claim-level faithfulness 与不忠实率两格都在。缺数则两格都是「样本不足」。  
2. min-6 周报的 B2 与 B3 成对主行仍按出口协议填写。本页数字不进入那两格。  
3. 忠实率升高的句子必须带上同一窗口的不忠实率（或两格「样本不足」），并且不得写成「误放已下降」或「Gate 通过」。

可接受的观测叙事：

- 「同一窗口附录：不忠实计数见抽检表；B2/B3 仍在 min-6 主行，本附录未覆盖」  
- 「可判定主张不足 10，两格写样本不足；出口成对主行另填」

不可接受的叙事：

- 「忠实率升了，所以更好」（没有不忠实率，也没有 B2/B3）  
- 「不忠实率降了，所以误放降了」（用 P1 替换 B2）  
- 「P1 已过线，本波 Gate 通过」  
- 「接近乙」或任何把生产附录读成路线 Y 改判的句子

本波 P1 为观测/Watch，不作本波 Gate 生死。升 Gate 须另决议，并事先锁定判据。
