# §0 架构总览

> **规格地位横幅(DOC-03)**:本卷是 W1–W4(及后续汇编)的**历史规格**。实施与现行叙述冲突时,以 **ADR + `CONTEXT.md`** 为准。下图不重画;图中未标明历史的句子不得当现在时。

## 0.1 一句话架构(现行)

FreshLatch 把已签发主张从「曾经为真」改成「现在仍可复验」。带工具的真 Agent 只有 **Lead** 与 **Critic**;**Auditor = 单轮 structured-output,无工具无循环,不得拥有放行权**(ADR-0009),不得与 Lead/Critic 并列成三个带工具真 Agent。三层确定性强制仍是步数护栏 → 工具白名单 fail-closed → 规则闸;LangGraph 只做人审 checkpoint 管道(**图不是 Agent**);评测是产品一等功能。检索串走**主张查询变换**,Lead 不得自由改写 retrieve 的 `query`;评测臂 dense/hybrid/rerank 可跑,生产默认 BM25;HumanLatch **续命已实装**(不是 disabled 占位)。

## 0.3 分层与强制顺序(三层分离原则)

> **prompt 管任务、白名单管禁止、规则闸管放行。**(#6 拍板,贯穿全部实现)

| 层 | 载体 | 强制什么 | 可测性 |
|---|---|---|---|
| 循环层 | 裸 `while` 循环 + `Guardrails` | 步数预算(Lead 18 / Critic 8 / Auditor 6)、Run 级检索预算 24、软收尾 | pytest 直测纯函数/条件 |
| 工具层 | 角色工具白名单,fail-closed | Critic 无 `reverify_claim`(想强化也没有工具可写)、无 spawn(深度恒 1);Auditor 仅 `verdict` | 白名单矩阵单测 |
| 闸层 | `gates/rule_gate.py` 纯函数 | stale/unknown 不得绿灯、无 T1 不得 fresh、checksum 对不上不得 fresh/续命、作废名单打回 | gold.json 驱动闸单测(tests/eval) |

激励约束(Critic 不得强化原主张、Auditor 不得放行、Agent 不得把红灯改回绿灯)**不靠提示词祈祷,靠工具不存在**(Auditor 现行连工具循环都没有,唯一出口 `verdict` 进规则闸)——机械执行,可测可证(ADR-0001)。表中「Auditor 6 步 / 仅 `verdict`」是 W1–W4 历史挂载叙述,现行无循环无工具。

## 0.4 贯穿纪律(任何工单不得违反)

1. **图不是 Agent**:Agent 循环 = 裸 OpenAI 兼容 chat.completions+tools 自写循环;LangGraph 只用于 checkpoint/interrupt,用法隔离在 `latch/` 模块,Agent 循环不 import langgraph。
2. **评测可复现**:评测期运行时纯本地、代码级禁联网(`web_search` 仅架构插座);eval 模式跳过 HumanLatch;decoding 参数(temperature/seed/模型版本/日期)逐运行显式记录。
3. **单一真相**:禁令枚举真相只在代码(白名单常量+规则闸);skill 文件只写约束的存在+理由+被拦后动作;作废名单 = SQLite `invalidation_list` 表,Lead 上下文与规则闸都查它,不各自维护。
4. **计划不做执行**:本规格是规划产物;实施按 §8 拆单执行。
5. **合成红线**:只用合成材料,界面标注 synthetic;锁定课题「是否在未来 12 个月进入东南亚中小企业 AI 客服市场」,开工后禁止改。

## 0.5 技术栈与依赖(定稿)

- Python 3.11、Windows 本地、不要 Docker / Kubernetes。
- 依赖:`openai`(仅 HTTP 传输)、`pydantic` v2、`fastapi`(+ uvicorn)、`rank_bm25`、`jieba`、`langgraph>=1.0,<2.0`、`langgraph-checkpoint-sqlite`、`python-dotenv`、`pytest`。

- 依赖按参考代码惯例精确 pin 版本(每仓 `requirements.txt`);API key 走 `.env` / `DASHSCOPE_API_KEY`。
- 控制台 UTF-8:`$OutputEncoding = [Console]::OutputEncoding = [Text.UTF8Encoding]::new()`。
