# 工程卫生与可维护性整改规格

> 来源：作品集代码健康审计会话（总评 B-）→ 已落地「根目录清理 + README Snapshot + sqlite close」→ `/to-spec`  
> 词表：`CONTEXT.md`（本波**不**往词表塞工程卫生新词）  
> 权威上游：ADR-0001（目录/src layout）、ADR-0002（UI=FastAPI+HTML）、ADR-0005（CI 零 LLM）、ADR-0006（HumanLatch / evidence_id 续命）、`docs/spec/01-目录与模块.md`、`docs/spec/04-评测纪律.md`、`docs/spec/05-UI与交互.md`  
> 审计依据：会话内审计摘要（`check_x1` 过肥、`gen_x1_drafts` 脚本巨石、三份 `parse_evidence_id` 不一致、`ui/app.py` 巨石、无 `pyproject.toml` / path hack）；根目录清理与连接泄漏归零已另 PR 落地，**本规格不重复**。  
> **测试主缝（预锁 2026-10-06）：工程卫生不变量** —  
> ① 包以 editable 安装为权威导入路径（无依赖 `sys.path.insert` / 裸 `PYTHONPATH=src` 才能跑 CI 与脚本）；  
> ② `parse_evidence_id` 全仓单一语义（切法 + 失败契约一致）；  
> ③ `check_x1` 公开签名与 exit_code 语义不变；  
> ④ `gen_x1_drafts` 核心在 `src/`，scripts 仅薄 CLI，路径红线测仍绿；  
> ⑤ UI 形态红线（主按钮文案等）与既有 API 行为不变，HTML 不再整块嵌在 `app.py` 业务逻辑中间。  
> 子缝（仅当主缝扫不到时）：CI lint 步骤存在；Cloud Agent `install` 含 editable 安装。**优先只暴露主缝。**

## Problem Statement

审计结论是：核心闸与离线测仍干净（约 874 passed / 80% 覆盖、CI 零 LLM），但外围已开始长成难讲的「半屎山」——`check_x1` 单函数过长、草稿生成 2k+ 行挤在 `scripts/`、三份 `parse_evidence_id` 对多 `#` / 非法 `as_of` 行为不一致、`ui/app.py` 近两千行且半为内嵌 HTML + 模块全局态。同时缺少 `pyproject.toml`，约 30 处 `sys.path` hack 掩盖了真实打包边界。作品集面试官会夸闸门，也会在第二眼问「你怎么维护评测脚本和 UI」。根目录与连接泄漏已先清；本波把**可维护边界**钉成可拆单规格，且**禁止**偷渡评测判据、换臂或 UI 产品化并发改造。

## Solution

做一次 **工程卫生整改（Hygiene Phase）**：以 editable 包与 CI lint 收束导入面；合并 `parse_evidence_id` 为单一真相；在签名冻结下拆薄 `check_x1`；把 `gen_x1_drafts` 核心迁入 `src/freshlatch/eval/` 并保留薄 CLI；将 UI 的 HTML/静态资源抽出 `app.py`（本期**不做** `create_app` 去全局 / 多 worker 会话隔离）。Exit 为卫生层冒烟：全量离线测绿 + 主缝可机检；层身份不是新功能阶段，不升格 Hard-Gold / W12。

## User Stories

1. As a 新克隆者, I want `pip install -e ".[dev]"` 后无需手设 `PYTHONPATH` 即可 `pytest` 与跑薄 CLI, so that onboarding 不被 path hack 绑架。
2. As a CI 守护者, I want workflow 用 editable 安装再跑测试, so that CI 与本地权威路径一致。
3. As a CI 守护者, I want CI 有一步 lint（默认 ruff，规则先松）, so that 明显脏导入/未用符号能被拦住，又不一次炸数百条历史债。
4. As a Cloud Agent 维护者, I want 环境 `install` 含 editable 安装, so that 新 agent 不回退到只靠 `sys.path`。
5. As a 脚本作者, I want `scripts/` 下不再各自 `sys.path.insert`, so that 导入面单一。
6. As a 续命操作者, I want `parse_evidence_id` 与点回评测同一套切法, so that `a#b#c@T1` 不会闸里一套、评测里另一套。
7. As a 评测作者, I want 非法 `as_of`（如 `T2`）统一失败为「不可解析」, so that x1 不再静默吞非法时点。
8. As a 评测作者, I want 失败契约统一为 `None`（或等价「不可解析」）, so that 调用方不再同时处理空串三元组与 `None`。
9. As an 架构守护者, I want 单一实现位置 + 他处 re-export 或删除副本, so that 不会再长出第四份解析器。
10. As an 架构守护者, I want 合并前先落差异金标表（多 `#`、非法 as_of、空字段、`None` 入参）, so that 改切法不是 HARKing。
11. As a 评测维护者, I want `check_x1(...)` 公开签名与 `CheckResult` / exit_code 0|1|2 语义不变, so that CLI 与草稿后检查不破。
12. As a 评测维护者, I want `check_x1` 编排拆成可测纯函数段（配置校验 / 语料扫描 / 单题 / 汇总）, so that 复杂度不再集中在单函数。
13. As a 回归守护者, I want `tests/unit/test_x1_checks.py` 在拆分后全绿且不靠改文案凑绿, so that 重构可证明行为不变。
14. As a RET-01 维护者, I want `gen_x1_drafts` 核心逻辑在 `src/freshlatch/` 包内, so that 可被包导入与复用，而不是 2130 行脚本巨石。
15. As a RET-01 维护者, I want `scripts/gen_x1_drafts.py` 只做 argv→调用包入口, so that 脚本层可维护指数不再为零。
16. As a RET-01 维护者, I want 禁止写出路径红线（如不得写 `data/corpus` 等）在迁包后仍由同一测护住, so that ROOT 解析变化不 silent 写错盘。
17. As a RET-01 维护者, I want `test_x1_drafts` 改为包导入而非 `importlib` 按文件路径加载, so that 测与实现同构。
18. As a UI 维护者, I want 复验单 HTML/JS 落在 `ui/static/` 或模板文件, so that `app.py` 不再夹一千行字符串。
19. As a UI 维护者, I want 既有路由与 JSON 契约不变, so that ≥20 个 UI 相关测不必同时改行为断言。
20. As a 形态守护者, I want 主按钮合法文案「开始复验」等红线在抽文件后仍可被测断言, so that ADR-0002 / §5 红线不丢。
21. As a 产品负责人, I want 本期**不**做 `create_app()` / 去掉模块级 `_state` / 多用户会话隔离, so that 不把卫生票偷渡成并发产品化。
22. As a 产品负责人, I want 本期不改评测金标、不换生产检索臂、不改闸谓词, so that 卫生 ≠ 表现。
23. As an 面试讲解者, I want 能指着「包边界 / 单一 evidence_id 解析 / 脚本进 src / UI 静态分离」讲可维护性, so that 回应审计 B- 的脚本与呈现短板。
24. As an AFK agent, I want 本规格拆成带 Acceptance 的工单且一票一会话, so that 符合 Agent Guards。
25. As an AFK agent, I want 每票有 Do-not-touch 与路径清单, so that 不误伤 Hard-Gold / 发前钩子语义。
26. As a 文档维护者, I want README Snapshot 在 pyproject 落地后改权威安装句（若与现行 Quick start 冲突）, so that 对外 onboarding 一致。
27. As a 决议守护者, I want `parse_evidence_id` 切法拍板写进本规格；仅当实施发现库内真实多 `#` doc_id 冲突时停并另开决议/ADR, so that 默认不空转四件套。
28. As a 回归守护者, I want 全量 `python -m pytest tests/ -q` 在每票合入后仍绿（允许既有 skip）, so that 卫生不引入假绿。
29. As a lint 守护者, I want 首版 ruff 规则以「能进 CI」为先、允许后续加严另票, so that 不把历史风格债一次性拦死交付。
30. As a 作品集读者, I want 本波不宣称「已无屎山」或「W12 通过」, so that 层身份诚实。

## Implementation Decisions

### 主缝与策略

- **主缝**：工程卫生不变量（见文首五条）。测的是导入边界、解析一致性、公开 API 稳定、路径红线、UI 静态分离——**不是**新复验能力。
- **权威序（冲突时）**：已接受 ADR + `CONTEXT.md` 产品词 > 本规格卫生契约 > 审计建议清单。本波不得反向改闸/金标/默认臂来「方便重构」。
- **已落地、本规格不重复**：根目录过程文档外移、`test_memory_forensics.db` 出库、README Snapshot、sqlite `close` 归零。若 main 尚未合入，实施票以 main+该 PR 为底，不重做。
- **不新拍产品板**：续命语义、evidence_id 时点只认 T0|T1、UI 红线、CI 零 LLM——沿用 ADR-0005/0006/0002。本规格只钉**工程边界**与一处解析切法对齐。

### 拍板：`parse_evidence_id` 单一语义（预锁）

| 维度 | 拍板 |
|---|---|
| 权威实现 | 一处纯函数（建议模块名实现自洽，如 `freshlatch.evidence_id` 或并入既有无环依赖模块）；`eval/checks.py` 与 `gates/human_latch.py` 改为调用/re-export；`eval/x1_checks.py` 删除本地副本 |
| `#` 切法 | **最后一个** `#` 分隔 `doc_id` 与 `anchor`（对齐现行 `eval/checks.py` 的 `rsplit("#", 1)`；**改正** `human_latch` 的「第一个 `#`」） |
| `@` 切法 | 最后一个 `@` 取 `as_of` |
| `as_of` | 仅 `T0` \| `T1`；其余 → 不可解析 |
| 失败契约 | 统一返回 `None`（x1 调用处改为判空，不再依赖 `("", "", "")`） |
| `None`/非 str 入参 | 视为不可解析 → `None`（保持 latch 对脏入参 fail-closed） |
| 金标表（合并前写入测试，禁事后改口径） | 至少覆盖：`doc-a#p2@T1` 快乐路径；`a#b#c@T1` → `(a#b, c, T1)`；`doc#p2@T2` → `None`；缺 `#`/`@` → `None`；空 doc/anchor → `None` |

**止损：** 若实施中发现已入库 / 金标 evidence_id 依赖「第一个 `#`」切法，**停**，另开决议票（可补薄 ADR），不得在本波悄悄改金标凑绿。

### A — pyproject / path / lint

- 新增 `pyproject.toml`：`src` layout 声明包 `freshlatch`；运行依赖从现行 `requirements.txt` 迁入；`[project.optional-dependencies] dev` 含 pytest、ruff（及实施选定的最少工具）。
- CI：`pip install -e ".[dev]"` → `ruff check`（首版选宽规则集，失败策略在票内写死）→ `python -m pytest tests/ -q`。
- 删除仓内为导入而写的 `sys.path.insert`（scripts / conftest / `__main__` / ui 入口）；允许保留**非导入用途**的路径常量。
- README / AGENTS 权威命令与 editable 对齐；`docs/agents/agent-guards.md` 的 lint 行从「none locked」改为指向 ruff（若本票加锁）。
- **Do-not-touch：** 闸谓词、金标、`PRODUCTION_RETRIEVAL_MODE`、UI 业务路由语义。

### B — parse_evidence_id

- 先提交（或同票最先 commit）差异金标测，再改实现。
- latch 续命路径改切法后，跑 renew / latch / matrix / x1 multi_hop 相关测。
- 注释必须删除「与 checks 同一套」却用反切法的过时句。
- **Do-not-touch：** 续命三层业务（点回库、规则闸、幂等）逻辑，只换解析入口。

### C — 拆 check_x1

- 保持 `check_x1(corpus_dir, traps_dir, questions, config, *, floor_overrides=None) -> CheckResult`。
- 抽段建议：`validate_locked_config` / `scan_licenses_and_meta` / `check_query_item` / `aggregate_exit`（名实现自洽）；`check_x1` 只编排。
- 不改 `LOCKED_CONFIG` 常量语义；不改消息字符串Unless 测试已改为结构化字段（本波默认**不改**消息字符串）。
- **Do-not-touch：** retrieve 主链、drafts 生成算法。

### D — 迁 gen_x1_drafts

- 包内模块可按 validate / prompt / generate / flag / paths 分文件；禁止把 2130 行原样贴成单文件「假迁包」。
- `scripts/gen_x1_drafts.py` ≤ 薄包装（导入 + `main()`）。
- `REPO_ROOT` / 禁止根解析必须以迁包后测为准重钉；`FORBIDDEN_*` 行为不变。
- 测试去掉 `spec_from_file_location("gen_x1_drafts_…")` 类加载。
- **Do-not-touch：** 解码参数预锁字段、预算指纹语义、金标/语料正式目录内容。

### E — UI 静态分离（5a only）

- 将 `HTML_PAGE` / `PREPUBLISH_HTML`（及同类大字符串）移到静态或模板文件；`app.py` 启动或路由内读入。
- 保持 FastAPI 路由注册与响应形状；模块级 `_state` **本票保留**（并发隔离另票 HYG-06+，本规格 Out of Scope）。
- 形态红线测改为读文件或经同一加载函数取 HTML，禁止删红线断言。
- **Do-not-touch：** publish-hook 闸函数、HumanLatch 写路径、主按钮文案白名单常量语义。

### 词表与 ADR

- **不**往 `CONTEXT.md` 增加「卫生」「巨石」「path hack」等工程词。
- **默认不新开 ADR**：切法对齐 checks 是纠错 + 单一真相，写进本规格即可。若止损触发（真实多 `#` 数据依赖旧 latch 切法），再开决议四件套。

## Testing Decisions

- **好测试**：行为/契约可观察（安装后导入、解析表、exit_code、路径红线、HTML 红线、路由 JSON）。不测「文件是否好看」。
- **权威命令（每票 Evidence）：**  
  - `python -m compileall -q src`  
  - `python -m pytest tests/ -q`  
  - A 票另加：无 `PYTHONPATH` 的干净 venv 冒烟（票内写命令）+ CI 含 lint  
  - B 票另加：差异金标表全过  
  - D 票另加：`test_x1_drafts` 全过且无按路径 importlib 加载实现  
  - E 票另加：既有 UI 红线/相关测全过  
- **层身份文首（预锁，禁事后改）：**

```text
层身份：工程卫生 / 可维护性整改（Hygiene）。
不是新功能阶段 Exit；不是 Hard-Gold；不是 W12 通过；
不是 UI 多租户/多 worker 产品化；不改评测金标与生产检索臂。
```

- **Prior art：** `test_x1_checks`（22）· `test_x1_drafts`（85）· `test_matrix.parse_evidence_id` · UI 族测 · ADR-0005 CI。
- 本仓用户纪律：卫生票**需要**更新/补充自动化测（与「未要求则不写测」的产品票不同）；以 Acceptance 写明的命令为准。

## Out of Scope

- 根目录再清理、README Snapshot 重写、sqlite `close`（已另做）  
- `create_app()`、去掉 `_state` 全局、多进程/多用户会话隔离、为并发加锁（另票）  
- 合并无关重复代码、删除「早期未覆盖代码」大扫除（可另开调研票）  
- 改 `PRODUCTION_RETRIEVAL_MODE`；重跑 L3 / Hard-Gold；改 gold 凑解析切法  
- 收紧 ruff 到「零 warning 全仓」作为本波硬 Exit  
- 引入 mypy 严格全仓、poetry/pdm 锁文件战争（除非 A 票显式选一种且不扩大 Exit）  
- 重做 UI 视觉（Refero/Figma）、薄对话、C′ 插件平台  
- 代关改臂 Gate 票；宣称审计已从 B- 升到 A
