# c10 缺口 paraphrase 元陈述标记增补（相对 ADR-0008 / #241）

> 工单：[GitHub #246](https://github.com/luxingjiang1993/FreshLatch/issues/246)  
> 规格：`docs/spec/19-must-unknown-c10-缺口误stale.md`  
> 性质：ADR-0008 封闭标记词表**评审增补**；非算法族更换；非改 gold。

## 问题

#241 堵住「元标记已命中后的主张数字回声」。本跑 c10（`report-20261001-010433`）用 **`无新测量` / `无更新记录` / `数据缺口声明`** 等 paraphrase，现行 `_META_MARKERS` 未命中 ⇒ `has_meta=False` ⇒ 整段放行。

## 增补终表（本票写入 `meta_gate._META_MARKERS`）

| 标记 | 覆盖意图 |
|------|----------|
| `无新测量` | 本跑 c10 实录 |
| `无任何更新` | 「无任何更新记录」子串 |
| `无更新记录` | 本跑 c10 实录 |
| `数据缺口声明` | 语料标题句 |
| `数据缺口` | 短形 |
| `尚未发生` | 未来例行调整未发生=缺口叙事 |
| `放弃追踪` / `主动放弃追踪` / `不再被追踪` / `无新数据替代` | 活模 c9 逃逸：把历史 72% 写在「放弃追踪」子句当假实质锚 |

**噪声剥除（附属）**：`T0`/`T1`、`20xx` 年份、`N 月` 日历不得当实质数值锚。

**未入表（预登记否决）**：单独 `已过时`——易误伤「价格已过时且 T1 给新价」合法 stale；本跑「已过时」子句在缺口标记剥除 + 算法 A（450 回声）后不再构成放行锚。

## 附属：T0/T1 噪声剥除

实录 reason 常以「T1 原文…」起句。`T1` 中的数字会被旧 `_DIGIT` 误当实质锚，导致缺口形在传入 `claim_statement` 后仍放行。本票将 `T0`/`T1` 与既有 `cN` 主张编号一并剥除后再做数字判定（误伤方向仍单向）。

## 误伤方向

单向：`stale` → 打回 / `unknown`。绝不向绿灯开口。c3/c7 合法数值锚回归测锁死。

## 与 #241 边界

| | #241 | 本补丁 |
|--|------|--------|
| 逃逸 | 标记已命中 + 数字回声 | **标记未命中**的缺口 paraphrase |
| 手段 | 算法 A（statement 回声） | 词表增补 |

## 未声称

不改 `gold.json`；不声称 Hard-Gold；全量 `all_hit` 非本票硬 Exit。
