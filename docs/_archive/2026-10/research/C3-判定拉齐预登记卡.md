## 1. 纪律（Anthropic 清单合入）

1. 每条验收必须标层：`invariant` / `smoke` / `demo` / `instrument`；禁止跨层升格。
2. 失败只改**实现**，不改本卡判据；改判据 = Batch 3 验收作废（HARKing）。
3. 涉 LLM 的条目：写明模型 / 温度 / 日期；n 小则框定**冒烟**，不报方差、不报统计显著。
4. γ 通过 **≠** 假绿对照成立；假绿旧图结论仅上下文指针；与假绿仪器/消融规格**分条**措辞见 docs/research/γ-与假绿仪器分条措辞设计评估.md。
5. 禁止升格句：不得把 γ-SMOKE 说成「判定已统计证明 / 产品已验证 / 假绿已根治」；完整禁句清单见分条评估 §4.2。

## 2. 禁改 gold 凑绿（操作化四条款）

1. Batch 3 验收窗内：**禁止**为凑 γ 通过线修改 `data/eval/gold.json`（含 must_stale / must_fresh / must_unknown / must_quarantine 等）。
2. 合法改金标：须**另开工单**，写明动机与影响面，并**声明本卡（Batch 3 γ）预登记作废且须重登**后，方可改文件。
3. 验收窗内允许：改评测 harness / 闸 / Auditor / 维度路径的**实现**；改文档笔误（不改变判据语义）。
4. **违例**：放宽闸阈值、删除或改写 must_*、改因果金标、用改 gold 冒充「判定拉齐」——一经发现本批验收作废。

## 4. 采样口径（本卡）

- **invariant 条**：确定性；逐位一致；无随机容差。
- **smoke 条**：可涉 LLM；须记录模型、温度、日期、n；默认框定冒烟检查；**不**在本卡锁多 seed 方差通过线。
- **demo / instrument**：本卡不设 γ-demo 通过线（避免与 α-demo / 假绿仪器混淆）。

## 5. 失败与止损

- 实现未过：修实现，重跑；**不**改本卡、**不**改 gold。
- 判据发现错误：走 §2.2——作废本卡并重登，不得静默改句后宣称仍绿。
- 与假绿旧图冲突时：以「分条」处理（#102），不得用改 γ 通过线吞掉假绿诚实边界。
