## §候选路线(每个决策维度的全部候选,含被否项)

### D1 主失败模式(票面类别)

- **(a)** 闸压绿:Lead+Auditor 已双 fresh,闸打成 unknown/红。

## §拍板 + 逐项子决策

**拍板:D1-(b′) + D2-(2) + D3-(B) + D4-(iii) + D5-(β)。**

1. **主因**:行为层——维度预检/异议打回后,**「同维度复验 → `reverify_claim(fresh)` → 双判一致」路径未走**(5/6 主导);出口 `mark_gap→unknown`。
2. **排除**:非闸压绿;非双判不一致;非维度异议环;非金标/通过线错误。
3. **次型**:c6×1 同维自标下的错 stale;同挂行为层;不另立根因;不进 #53 处置档判据。
4. **层结论(可引用)**:机制层本批 intact(K6-2 倾向过 / 预检按设计拦截);**K6-4 行为冒烟未愈**。不得升格为判定层证书或一期评测闭合。不得反向解释为「闸误伤 must_fresh」。
5. **给 #53 的依据**(本票唯一交付):
   - 依据句:行为层冒烟未愈 + 主因 = 同维复验路径未走(+ 次型一句可选线索)。
   - #53 只按 §7.5 / K6-3 裁「只登记 / 开一次性修复窗 / 其他已锁止损」。
   - 本票**不断言**必须开窗或必须修到过线。
   - 禁区:不改 `gold.json`、不改通过线、不以人格/提示词/探针第三次重试当修复。
6. **词表 / ADR**:不新增;不新开 ADR。
7. **本工单**:不改代码、不重跑 LLM、不关地图、不决议 #53。

## §面试讲法(grilling 预案)

**Q:K6-4 为什么没过?是闸把该活的绿压死了吗?**
A:不是闸压绿。六遍里 `reverify_claim(fresh)` 次数是零;unknown 遍次 Auditor 根本没上场。五遍是预检按设计拦住错维 stale 之后,Lead 走 `mark_gap→unknown`,没有走同维复验再申 fresh。机制层本批 intact;坏在行为层恢复路径。

**Q:那和「Lead 没干活」有什么区别?**
A:有 retrieve,有 mark_gap,所以不是零动作。空转的是 ADR-0012 写明的合法恢复:`同维证据 → reverify_claim(fresh) → 双判一致`。标签必须钉在这条路径,否则面试一对轨迹就穿帮。

**Q:c6 有一轮 stale,是不是另一条根因?**
A:是次型(1/6):Critic 自标维度碰巧等于登记维,定价反证过了预检,Lead/Auditor 双 stale——金标已写明客单价变化不推翻市场窗口。n=3 temp=0,不另立主因,不拿它裁 #53 处置档。

**Q:是不是该改 gold 或放宽通过线?**
A:不。金标锚仍在语料里;仪器定义预登记。改线凑绿 = HARKing,验收作废。

**Q:下一张 #53 该依据什么?是不是必须开两周修复窗?**
A:只依据「行为层冒烟未愈 + 同维复验路径未走」。开窗还是只登记,整段由 #53 按 §7.5 裁。本票不断言必须开窗,也不断言必须修到过线。禁区照旧:不改 gold/线、不以人格第三次重试当修。

**Q:为什么不新开 ADR?**
A:难反转的是事后改判据(0007)和同仪器三次重试(0011)以及同维复验契约(0012)。本次只是对已落盘轨迹的归因分类,易反转,三条件不齐。
