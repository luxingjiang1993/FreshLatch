# C5 二修方向设计评估

> 决议日期:2026-09-20。工单性质:§7.5 修复窗口内的二修方向拍板(背离三处置的第二步)。
> 前置记录:`docs/evidence/w4/repro-check.md` 背离三(c5 翻转 = checkpoint 介导的维度混淆)、
> checklist.md(判据锁定版)。本评估遵循 CLAUDE.md 决议文档纪律四件套;ADR 三条件不满足,不记 ADR(理由见 §4)。

## §1 问题与前置约束

**问题**:c2 修复(背离二处置)引入的 fresh 前 Critic 自动 checkpoint,在冒烟运行(run-223219)中
介导了新背离:c5(must_fresh,「我方单会话成本仍低于竞品」)被翻成 stale。机制链逐步可追:
Critic 检索到竞品 notes(Lite 版门售价 39 美元/月/店,**定价维度**),把它当作主张(**成本维度**)
的反证 mark_stale(维度混淆);Lead 未独立核对即镜像 Critic 框架改判。错误有两处独立失效点:
生产侧(Critic 产出维度不符的反证)+ 消费侧(Lead 未核对即采纳)。

**前置约束(先前沿工单/签认钉死,本决议不得触碰)**:

1. **判据锁定**:checklist.md 判据 W4 验收前锁定,事后修改 = 验收作废(HARKing)。本决议只改
   人格/口径/工程注入,判据一字未动。
2. **通过线已预登记**:窗口关闭验收 n=3 temp=0,c2 3/3 stale;12 条零 must_stale→fresh;
   c9/c5 按已签口径记背离不升级。二修不改变通过线。
3. **违例定义已签认**:预登记违例 = must_stale 被判 fresh。c5 fresh→stale 非违例级,
   这决定了「不做二修」在验收数学上可行——本决议是在「可行」与「应当」之间拍板。
4. **c2 归因已钉住**:c2 修复生效由冒烟 n=1(run-223141/223309)独立证实(Lead 直接走
   mark_stale,未进 fresh 路径、checkpoint 未触发)。c2 的机制链不经过 checkpoint,
   c5 二修触碰的是 Critic 人格与 checkpoint 观察注入,c2 归因面不受污染。
5. **「一次只改一个变量」的适用范围**:该约束针对的是 c2 修复的归因窗口(冒烟先于二修),
   已由提交顺序(04be99d c2 修复 → cbaae98 冒烟记录 → 本会话 c5 二修)保证;不是禁止
   本决议同时补两个失效点——两个失效点同属背离三一个事故,机制链分别可追。

## §3 逐路线评估

| 维度 | ① Critic 生产侧 | ② Lead 消费侧 | ③ 机器闸 | ④ 不做 |
|---|---|---|---|---|
| 根因覆盖 | 除污染源:Critic 不再(应不再)产出维度混淆反证 | 只挡采纳:污染源仍在,其他消费路径(人审直读 Critic 报告、未来 Auditor)仍会被污染 | 覆盖若可行 | 均不覆盖 |
| 失效模式 | 人格提示不是保证,模型仍可能产错——但产错后还有②兜底 | 核对负担压在 Lead 自己身上;c2 事故已证明同一主体的「自信推理」会错(三次引用致死段落仍判 fresh),同构失效可复现 | — | checkpoint 结构性副作用留在生产:每条 fresh 主张过闸都有被维度混淆带翻的风险 |
| 工程可行性 | 高:人格 + rubric + 测试守卫,与 c2 修复同款 | 高:人格 + SKILL + checkpoint 观察确定性注入(不依赖模型自觉的指令在场) | 低:维度对应是语义判断,正则/词表只能拦已见案例(39 美元),对新维度混淆(客单价≠毛利)恒漏;误杀真反证的风险不可评估 | — |
| 代价 | token 略增(Critic 多一轮自查语义) | token 略增(Lead 多一次核对);checkpoint 观察变长 | 维护一个词表军备竞赛,且给假安全感 | 把已知结构缺陷带进「只此一次、不得续杯」的窗口关闭验收;W12 再修则归因空间消失 |
| 与既有架构咬合 | rubric 单一真相 natural extension(干扰项正反例已有「亏损新闻≠客单价」) | §8.5 checkpoint 的配套:对冲给了反对派发言权,采纳侧必须补「独立判断」一环 | 与规则闸定位冲突(闸管不变量,不管语义质量) | — |

**被否理由写透**:

- **③ 被否**:维度对应是开放语义判断,不存在封闭的机器可查不变量;硬校验只能枚举已见
  案例,属于「把 demo 层判据伪装成闸」(Anthropic 纪律 #1 的反面)。维度质量归人格/rubric
  (生产侧自我约束 + 消费侧核对),机器层只做「指令确定性注入」(checkpoint note 必含核对
  要求),不假装能判定语义。
- **④ 被否**:验收数学上可行(非违例级),但有两条不可接受:其一,checkpoint 是结构性常驻
  (每条 fresh 主张都触发),维度混淆是每条主张都要过的真实风险,不是 c5 孤例;其二,止损线
  的语义是「把已知可修缺陷在窗口内修掉」,把缺陷带进终验赌运气,与「止损优先于演示打磨」
  的既定纪律相反。
- **单做②被否**(Anthropic 清单否决的原推荐):本评估初稿原推荐「只做②」,理由是先前的
  「一次只改一个变量」。被清单 #5/#7 挑战后修正:该约束服务的是 c2 归因,c2 归因已由冒烟
  n=1 与提交顺序钉死(约束 4);且②单做把核对负担压在 c2 已证明会「自信地错」的同一主体上,
  污染源(Critic 产出)不除——清单 #2(随机/自信系统单次判断不可信)直接命中。原推荐撤销,
  改①+②分层。

## §4 拍板与子决策

**拍板:做二修,①为主、②为配套,同一提交内分层落地,走 c2 同款三层 TDD 结构。**

子决策:

1. **Critic 人格 + rubric 落维度锚定铁律**(生产侧):反证必须锚主张同一前提/度量维度,
   定价≠成本类维度混淆不得 mark_stale,应在 report_finding 如实说明未见同维度推翻证据。
2. **Lead 人格 + SKILL + checkpoint 观察注入**(消费侧):采纳前强制独立核对维度对应;
   `_spawn_critic` 回吐 Lead 的 note 确定性携带核对指令(结构注入,不依赖模型自觉);
   核对通过也要用自己的 reason 与证据 id 落 mark_stale,不得镜像 Critic 框架。
3. **rubric 单一真相同步**:stale 定义补「互斥须锚同一度量维度」;干扰项正反例落 c5 类反例。
4. **词表同步**:CONTEXT.md 有效反证定义 + Critic 条目补维度锚定(四件套 #3)。
5. **不记 ADR**:三条件自检——难反转?人格/rubric 文字随时可改,不难反转。反直觉?否,
   与既有「亏损新闻≠客单价」干扰项口径同构延伸。真实取舍?有取舍但已在本评估写透,且
   不涉及架构。三条件不齐,按规则不记;若日后把维度校验升格为机器闸(③ 复活),届时三条件
   齐备须补 ADR。
6. **Issue tracker 关闭件**:本决议无对应 GitHub 工单(tracker 无 open issue),决议评论以
   repro-check.md 背离三补「拍板」节 + 本评估 + git 提交为留档载体,不虚构工单状态。

## §6 面试讲法(grilling 预案)

**Q:为什么 c5 要二修?签认口径里它不是违例级,不修复也能过验收。**
A:验收数学上确实能过——这正是预登记止损线的价值,它让「过与不过」不依赖事后解释。但
checkpoint 是每条 fresh 主张都要过的结构,维度混淆不是 c5 孤例而是每主张的真实风险;把
已知结构缺陷带进「只此一次、不得续杯」的终验,赌的是端点心情,违反「止损优先于演示打磨」。

**Q:为什么不只做①或只做②?**
A:只做工是压力测试——c2 事故已经证明同一主体的自信推理会错,把核对全压给 Lead 是同一个
会犯错的主体既当运动员又当裁判;只做①,人格提示不是保证,漏出的错反证在消费侧无人拦截,
且污染源还会经人审直读、未来 Auditor 等路径扩散。①除源、②兜底,两层都便宜,没有为省
token 牺牲纵深的合理理由。

**Q:为什么不做个机器闸硬拦维度不符?**
A:维度对应是开放语义判断,机器只能枚举已见案例(39 美元),对新混淆恒漏,还误杀真反证。
规则闸的定位是不变量强制,不是语义质量裁判——把语义判据塞进闸,就是把 demo 层判据伪装
成确定性检查。

**Q:一次只改一个变量,你一次改了①②两处,不违规吗?**
A:该约束服务的是 c2 修复的归因,已由冒烟 n=1 与提交顺序钉死,c2 的机制链不经过 checkpoint,
二修不污染 c2 归因。①②同属背离三这一个事故的两个失效点,机制链(轨迹 run-223219)逐步
可追,归因不需要靠「只改一处」来保证。

**Q:怎么证明修好了?**
A:结构断言(13 用例:四处口径落齐、checkpoint 注入在场、事故 fixture 形状钉住)+ 窗口关闭
验收 n=3 temp=0 活跑,同一份检查表、同一批判据,只换新证据。n=3 诚实框定为冒烟层,不报
方差;结构副作用若复发,c5 按已签口径记背离不升级,判据不动。
