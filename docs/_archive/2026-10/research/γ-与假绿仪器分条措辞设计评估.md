## 4. 拍板：三句模板 + 禁升格清单

### 4.1 可引用句（各条一句，细节指向既有文档，不重写结论）

1. **假绿仪器**：以已关假绿相关图之**仅表明句 / 诚实边界**为准；本批**不重审**对照是否成立。  
2. **γ 判定拉齐**：以 `docs/research/C3-判定拉齐预登记卡.md` 之 γ-INV/SMOKE + 禁改 gold（ADR-0018）为准；**γ 通过 ≠ 假绿对照成立**。  
3. **消融 / 多 seed**：规格已锁（`docs/research/γ-消融表与多seed规格时序设计评估.md`）、**实跑未做**；**未跑 ≠ 已证明**。

### 4.2 禁止升格句

- 「γ 通过 ⇒ 假绿对照成立 / 假绿已根治」  
- 「消融规格已锁 ⇒ 消融已证明 / 测量闭合」  
- 「主链抗假绿仅表明句 ⇒ 可升格为 γ-INV 通过线」  
- 「α-demo / γ-SMOKE ⇒ 产品已验证」

### 4.3 Batch 3 `/to-spec` 硬要求

验收节必须**分列三小节**（假绿仪器指针 / γ 拉齐 / 消融规格），各贴 §4.1 对应句；**禁止**合成一段「抗假绿总通过」。

本会话不 `/implement`、不改 gold、不重跑假绿对照。

## 6. 面试讲法

**Q:你们 Batch 3 是不是把假绿做掉了？**  
A:不是。假绿仪器是一条线，γ 拉齐是另一条，消融规格是第三条。我们分条引用，禁止互相顶替。假绿是否成立以旧图诚实边界为准，本批不重审。

**Q:消融表都写了怎么还说没证明？**  
A:只锁了规格，实跑未做。未跑 ≠ 已证明——写在预锁句里。
