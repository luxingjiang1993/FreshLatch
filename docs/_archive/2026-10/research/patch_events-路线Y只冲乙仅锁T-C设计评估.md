## 1. 问题 + 前置约束

### 1.1 要拍什么

在路线 B 正式主跑已判**丙**、路线 C 抄句主跑亦**丙**且**禁止以 C 为主路径**的前提下，新开预注册 **只冲乙**：成立尺**仅锁 T−C**；机制绑 **B 软对齐**；B1/B2 仍计算上表但不参与成立；放弃甲。

四道 frontier（grilling 已拍）：

1. 乙页命名与 B/C 归档关系  
2. n 与止损预登记原文（含解码锁定串）  
3. 门闩：克隆 `GATE-K-PROBE` · 层身份 · 人令顺序  
4. 甲防火墙叙事  

### 1.2 目标分层（禁止混为一谈）

| 层 | 内容 | 承诺强度 |
|---|---|---|
| **纪律目标** | 新预注册；选取 R 继承；只抄同一次 `compare_primary`；真数据门闩；一次正式；止损预登记 | 必须做到 |
| **求验目标** | **结果乙** = 仅 T−C 成立（点估计 **>0.05** 且 95% bootstrap 下界 **>0**） | 尽量抬高，**不保证** |
| **诚实收口** | 丙仍合法；**放弃甲**（即便 B1/B2 两行均过也不得称甲） | 预注册允许 |

禁止把「设计冲乙」写成「将得到乙」。禁止「接近甲 / soft-甲」。

### 1.4 Anthropic 清单主动评审（推荐前已过 · 合入拍板）

1. **demo≠统计**：门闩/短测/夹具 ≠ RESULT-Y 成立；成立只抄 formal 同一次 `compare_primary`。  
2. **单次运行勿判生死**：正式一次 + 跑前止损；短测 pass-rate 不得写入成立格；禁事后加 n。  
3. **默认不是规格**：解码串显式锁死（沿用 B）。  
4. **词表纪律**：成立加严与止损阈值不进 `CONTEXT`；只收产品级「路线 Y / PREREG-Y」。  
5. **止损预登记**：点≤0.05 或下界≤0 → 丙；禁 HARKing 改尺/加 n。  
6. **复现两层**：R/种子/配额确定性；API 随机层容差。  
7. **ADR 三条件**：放弃甲 + 新页 + 点>0.05 止损 = 难反转/反直觉/真取舍 → **新开 ADR-0037**；R/同 after **引用** 0034/0035，不重复造。

被否的原冲动：回写 B；以 C 抄句为主；升格旧 GATE 绿；同页二跑加 n；三线都过就称甲；新造 `compare_*`。

## 4. 拍板 + 逐项子决策

**拍板：2.1-(A) + 2.2-(A) + 2.3-(A) + 2.4-(A)。**

### 4.1 文件与归档

- 协议：`docs/evidence/patch-events/PREREG-Y.md`（未激活）  
- 结果：`RESULT-Y.md`（壳；成立格未跑前为空）  
- 生成：`formal-generations-y.jsonl`（实现票；禁写 b/c）  
- 门闩：`GATE-Y-PROBE.md` + `gate-y-probe-generations.jsonl`  
- B/C 全套冻结只读；附录固定引用 RESULT-B 丙与 RESULT-C「非乙主路径」  

### 4.2 成立尺（预注册口径 · 不改比较器）

- 仍调用同一次 `compare_primary`（R），三行都抄进 RESULT-Y。  
- **参与成立**：仅 **T−C**，且点估计 **>0.05** 且 ci95_low **>0**。  
- B1/B2：**报告-only**；不参与成立、不参与止损、不得据此称优于 RARR·KPR。  
- 分层：只可能 **乙或丙**；**不得**改判甲。  

### 4.3 功率 / 止损 / 解码

- n=400（层配额 100×4；余数规则继承 B；名单针实现票）。  
- 止损：正式后若 T−C 点≤0.05 或下界≤0（含无定义）→ **丙**；禁加 n / 改 R / 改成立尺 / 同页二跑。  
- 一次正式主跑。  
- 解码：`qwen-flash` / temp=0 / Decoding.seed=`20261007` / API seed=`None`；bootstrap 种子同 B。  

### 4.4 门闩与人令

过门须同时：k≥10；T−C 固定 k 误放差点估计>0。  
层：夹具冒烟 ≠ 过门；`GATE-Y-PROBE` 真数据可扔 ≠ 成立。  
人令：机制齐 →（可选夹具）→ 人授发模型探针 → 人审报告 → 激活批注 → 人授正式主跑 → formal-y 一次。  

### 4.5 投稿映射

乙成立 → 继承 `DECISION-LOG` **结果乙**（arXiv + ACL Industry/Demo；不默认 EMNLP Findings；贡献句只写相对无证据改写的 fail-closed）。  
丙 → 不得称主实验成功。  

### 4.6 `/to-spec` 边界

- **可**：协议骨架完善、formal-y 旁路、GATE-Y 克隆缝、n=400 名单针、RESULT-Y 抄表（Acceptance：成立格只认 T−C∧点>0.05∧下界>0）。  
- **不可**：未过门激活；未人授发模型；回写 B/C；以 C 抄句为主路径。

## 6. 面试讲法

**Q: B 已经丙了，为什么不直接改 B 的成立尺只认 T−C？**

> 那是同页 HARKing。B 预注册求验是甲，正式一次已抄表。改尺重跑 = 看结果改判据。乙必须新开 `PREREG-Y`，B 冻结作负结果附录。

**Q: 为什么不用 C 的强制抄句？C 的 k 不是到 93 了吗？**

> C 点估计更小、下界贴零，是抄句压差反模式。人已钉乙主路径=B 软对齐。C 只作「非主路径」对照引用与层身份教材。

**Q: 点估计还要 >0.05，不是把成立定义改矮/改严了吗？**

> 相对经典「点>0」是**加严**，写进止损预登记，不是事后看到微弱正效应再抬杠。比较器仍返回原点估计；预注册决定「算不算乙成立」。

**Q: B1/B2 都过了能不能称甲？**

> 不能。本页求验目标放弃甲。上表是诚实，不是甲后门。

**Q: 门闩为什么不再要求 T−B1/T−B2 方向为正？**

> 过门条件必须对齐求验。冲乙只锁 T−C，继续拿 B1/B2 当激活闸是甲门闩错位。两差仍必报，供人审，不作过门。

**Q: n=400 会不会变成「加 n 充数」？**

> 跑前锁死单一 n，正式一次，止损后禁再加 n。这与见下界贴边再扩样的钓鱼相反。
