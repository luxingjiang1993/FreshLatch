### 1.5 Anthropic 清单主动评审（推荐前已过 · 合入拍板）

1. **demo≠统计**：扩语料 Acceptance / `construct_samples` 满额 ≠ RESULT-Y 乙成立；名单针从「不可激活」翻成可加载 ≠ 过门。  
2. **单次运行勿判生死**：解锁后仍是**一次**正式主跑；禁「先用 178 冒烟当正式」。  
3. **默认不是规格**：正式 n 继续显式 **400**；不得口头「先跑现有再看」。  
4. **词表纪律**：缺额停泊、扩容解锁是产品操作态；点>0.05 / 止损频率仍不进 `CONTEXT.md`。  
5. **止损预登记**：本窗**不改**成立尺/止损；否决「为凑数改小配额」。激活前透明修订正式 n **仅**在人选 B 且新 ADR 时允许——且须写明放弃功效理由（见下否决）。  
6. **复现两层**：扩容须继承 #371 式 provenance（URL/抓取时间/许可/sha256）；随机层仍是评委 API。  
7. **ADR 三条件**：解锁主路径难反转（后续 corpus 票与 PE-Y-05 闸引用）；「未跑却拒改 n」反直觉；扩语料成本 vs 改 n 功效 vs 停泊 = 真取舍 → **新开 ADR-0038**。

被否的原冲动：静默把 `PREREG-Y` 400→178；表仍写 400 实际喂不足；新开第二领域凑数；未扩语料就派 PE-Y-05；把 #368「方案 0 不扩充」误套为「Y 也该不扩充直接丙」（Y 尚未激活正式，缺的是库存不是已跑结果）。

## 6. 面试讲法

**Q: 协议还没激活，为什么不可以直接把 n 改成 178？**

> 未激活只说明还没污染 RESULT，不说明可以悄悄改预注册功率。Y 开页的核心动机就是 RESULT-B 在 n=100 功效不足。把正式 n 改成现有库存，等于否决开页理由却沿用页名。要改必须新决议写明「放弃功效」，不能装成同一预注册的小修补。

**Q: 那岂不是「未跑也永不可改」？**

> 不是。跑数据前透明修订（新 grill + ADR + 修订记录）合法，但是**另一次决议**。本窗拍板的是：默认解锁走扩语料，不把改 n 当缺省逃生口。

**Q: 扩语料算不算看完缺额再改样本框的 HARKing？**

> 相对「激活后/见 RESULT 后加 n」不是同一类。诚实做法：配额锁死 → 缺额不可激活 → 扩库存直到配额可执行。改的是 corpus，不是成立尺、不是 n。须记跑数据前偏离指针（#371 同级），论文不装「一开始就有 500 条」。

**Q: 为什么不选方案 0「不扩充、主比较不成立」？**

> 那是旧 `PREREG.md` 在**已锁样本框且准备跑**时的缺额处置。路线 Y 正式主跑**尚未激活**；纪律目标是保全 n=400 可执行，不是用空跑制造丙。停泊（C）已经覆盖「现在不跑」；丙留给真正一次正式主跑之后。

**Q: 共形预留不够怎么办？**

> 预注册已写：不够写「未做」，主比较照常。不得为共形从 400 主配额挖条，也不得把共形欠账当成改小 n 的理由。
