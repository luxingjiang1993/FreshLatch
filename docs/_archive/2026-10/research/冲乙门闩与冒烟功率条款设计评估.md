## 4. 拍板 + 逐项子决策

**拍板：2.1-(A) + 2.2-(A) + 2.3-(A)。**（#520 人令：按推荐）

### 4.1 敏感性闸（`GATE-Y-SENSITIVITY.md` · 可扔）

**集合 S（跑前写死）**：

1. **主集**：构造坏槽——四层 × `mod 4` 四算子（与 `patch_events_construct` 同族）；每层每算子 ≥1。  
2. **加集**：废止法 / 版本错配陷阱（`legal-hallucination-bench` / `verified-chinese-law-kb` 协议抽取），有限条写死 id。  
3. **正确对照**：有限「正确」改，防全拒假绿。

**通过线（须同时；失败 → 不得真数据探针 / 不得激活 / 不得正式跑）**：

| # | 条件 |
|---|---|
| S1 | 无 `score=None`；reject/`ok=False` → `score=−∞` |
| S2 | `gold=坏` → `ok=False` 比例 **≥ 0.90** |
| S3 | `gold=正确` → `ok=True` 比例 **≥ 0.70** |
| S4 | 型号与 τ = ADR-0040；失败后未激活可 **收紧 τ 一次** 并整闸重测；**禁止放宽** τ 凑绿 |

防火墙：不进 RESULT-Y；≠ 乙；≠ `gate_passed`。

### 4.2 n=30 冒烟（`SMOKE-Y-N30.md` · 可扔）

**必看**：T 自然 k；T−C 固定 k 差点估计**方向**；T/B1/B2 fixed-k `claim_id` 集是否**完全相同**（`collapse=true` → 停、不得激活）；score 卫生；T−B1/T−B2 必报不过冒烟条件。

**防火墙固定句**：

> n=30 冒烟只描述本 30 条上的仪器与方向可读性；区间只描述这 30 条重抽样噪声，**不**写成总体结论，**不**进 RESULT-Y 成立格，**不**单独构成 `gate_passed`，**不**保证乙。

### 4.3 激活门闩（相对 GATE-Y）

**继承**：过门 = k≥10 ∧ T−C 点估计>0；B1/B2 不过门；真数据；可扔 `GATE-Y-PROBE`；禁升格旧 GATE/RESULT；Agent 不得自行激活。

**增量**：

1. 机制针须齐 ADR-0040。  
2. **敏感性通过**为真数据探针硬前置。  
3. **人令序**：① 缝齐 → ② 敏感性通过 → ③ 可选夹具 → ④ n30 冒烟（`collapse` 则停）→ ⑤ 探针人令 → `GATE-Y-PROBE` → ⑥ 人审过门 → ⑦ 激活批注 → ⑧ 正式主跑人令 → ⑨ 一次 formal-y（n=400）。  
4. 探针人令默认同文：「授权路线 Y 仓外探针发模型；不得激活。」（改文须预注册同步）。  
5. 过门仍用**点>0**，不用正式乙的 **0.05**。

**总防火墙**：敏感性过 ≠ 冒烟过 ≠ 门闩过 ≠ 乙成立。

## 6. 面试讲法

**Q: 为什么过门还是点>0，正式乙却要 >0.05？**

> 门闩只问「方向是否为正、k 是否够」；成立尺加严是正式一次主跑的止损。把门闩加成 0.05 = 把激活门槛做成乙预演，层身份糊掉。

**Q: 敏感性过了为什么还要真数据 GATE-Y？**

> 敏感性测的是核验器对构造坏改的召回；GATE-Y 测的是四臂生成+选取 R 下 T−C 方向与 k。演示层 ≠ 测量层。B/C：过门仍可丙。

**Q: collapse 检测为什么放在冒烟而不是过门 Cond？**

> 三臂同批是仪器卫生问题，应在真数据发模型前拦住。过门 Cond 保持 Y 原两行，避免把仪器断言和功效方向门绑死成一条不可解释的复合闸。

**Q: 保证乙吗？**

> 不保证。本票只锁激活前纪律；乙仍是求验目标。
