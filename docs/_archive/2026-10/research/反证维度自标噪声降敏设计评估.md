## §1 问题与前置约束

**问题**:#30 行为验收通过线②未达成——c3(访谈改口,must_stale)三遍全被不变量 8

自标)自身噪声的降敏方向。

**#30 留档 + 代码勘察给出的五个硬事实**(均可在仓内复核):

1. **锚对、标签错**:c3 轨迹(reports/trajectories/run-20260921-133923.jsonl)
   mark_stale `dimension=cost_model`,evidence=`t0-channel-interviews#p2@T1`,
   reason 指向访谈口径反转(「3 月纪要『均明确接受 30%』的口径已不成立」);登记维度
   `interview_reversal`(docket 回填,依据 gold §2.6 + why_fresh)。反证本身是对
   主张前提(访谈纪要口径)的合法推翻,错的是维度自标。
2. **误标是确定性系统偏置,不是随机噪声**:temp=0 下 3/3 一致。六枚举中
   `interview_reversal` 是证据机制维度,其余五个(competitor_pricing /
   regulatory_stance / cost_model / market_structure / tech_ecosystem)是主题
   维度——**但词表在「前提出处」语义下是自洽的**:c3 的前提住在访谈纪要里 →
   interview_reversal;c5 的前提住在成本模型里 → cost_model;c6 的前提住在竞品
   动态里 → competitor_pricing。真正缺的是文档:模型侧 schema 描述
   (tools.py:59-60)只有裸枚举清单、零定义,模型只能按主题显著性选标签,c3 反证
   主题(30% 收入分成)撞 `cost_model`。这是**欠定义枚举(underspecified enum)**
   问题,不是模型抽风。
3. **闸在机械层结构上无法区分误伤与正确拦截**:c3(误伤)与 c5/c6(定向正确拦截)
   在闸眼里同为「登记维度 ≠ 自标维度」,唯一差别是语义的(c3 的反证真攻击了主张
   前提,c5/c6 的是维度混淆)。闸定位是零语义(三次拍过)——**这个分辨能力闸永远
   不会有**,答案只能来自模型侧标签质量或人审吸收。
4. **「降级转语义层」有仓内反证**:#30 运行里 Auditor 对 c5/c6 同样
   `dimension_match=true`(reports/trajectories/run-20260921-133957.jsonl /
   run-20260921-134010.jsonl,#26 同错的延续)——维度不符若降级给不变量 7 而
   不硬拒,c5/c6 全数漏放,拦截线当场破。
5. **登记侧零过错**:docket 回填值、gold.json、ADR-0011 §2 字段语义(「本反证
   自身攻击的维度」)全部不动——错的是模型侧规格没有写出这个语义的读法。

**乙被否写透(三个变体各自死因)**:
- **乙-a(不一致降级转语义层/不变量 7)**:被事实 4 实锤——#30 运行 Auditor 对
  c5/c6 同样 `dimension_match=true`,降级 = c5/c6 全数漏放,拦截线当场破。
  这是 #26 双层同错的直接延续。
- **乙-c(双填对账,不一致才降级)**:同端点 temp=0 下系统性误标两侧恒一致——
  对账抓的是随机分歧,而 c3 型噪声是确定性系统偏置,两侧「一致地错」。
  **agreement ≠ verification**:两个同分布样本的一致会被洗成虚假信心,
  成本翻倍零收益。要独立性就得换分布(异源端点),那是 #28 §3-G1 已登记的
  未论证候选,不在这里复活。
- **乙-b(转人审)**:这就是丙,不独立成项。

**戊被否写透**:能区分误伤(c3)与正确拦截(c5/c6)的信号是「反证是否锚定金标
段落」(J1)——那是评测仪器,生产闸没有金标。生产闸可机械检查的「可点回」
(evidence id 可解析)在二者间**无区分度**:c3 与 c5/c6 的反证 id 都是真实
retrieve 返回的 T1 片段。豁免 = 拆不变量 8 + 违反闸零语义定位 + 触发 ADR-0011
后果条款,三重不合法。

**己被否(本轮)写透**:词表在前提出处语义下自洽(事实 2),缺的是文档不是结构;
重构要动签发 schema、作废 12 条回填、碰金标邻近语义,用大锤砸文档缺失。
且**重构不许作为预登记逃生舱**(D2 被否的理由):若登记成「甲失败后的下一档」,
止损条款名存实亡(HARKing 邻避)。重构永远走新 grilling 工单、全量重开(含回填
复核),不计入机器防线重试额度——改规格不是加防线。

**丁的定位**:作为主路线被否(误伤是系统性、可预测的类别税,不是随机损耗——
等于签长约常付人审税);作为**预登记终点**采纳(D1)。

**维度 B(验收仪器)**:B2 胜。清单 #1(演示可过 ≠ 测量可信)与 #2(单次运行判

## §4 拍板 + 逐项子决策

**拍板:甲为主(模型侧规格锚定:六枚举补前提出处逐值定义+消歧指令,字段语义不动,

逐项子决策:

1. **模型侧规格锚定(甲)**:字段语义不动(ADR-0011 §2 原文有效);六枚举定义
   单一真相住 `tools.py`,三处模型侧消费点注入:mark_stale tool schema 描述
   (tools.py:59-60)、Lead SOP(roles/lead.py:20)、Critic SOP
   (roles/critic.py:31)。闸、路由、登记侧(docket 回填值 / gold.json)一律
   不碰。
2. **锁定规格文本(逐字,pre-registered,实现不得改写)**:
   - 六枚举定义(前提出处语义):
     - `competitor_pricing` 竞品价格:主张前提建立在竞品定价/价格对标数据上;
     - `regulatory_stance` 监管口径:主张前提建立在监管政策/官方口径上;
     - `interview_reversal` 访谈改口:主张前提建立在访谈/纪要/口头口径上
       (机制维度);
     - `cost_model` 成本模型:主张前提建立在成本/费用结构测算上;
     - `market_structure` 市场结构:主张前提建立在市场规模/格局/份额判断上;
     - `tech_ecosystem` 技术生态:主张前提建立在技术栈/生态位判断上。
   - 消歧指令(逐字):「维度 = 本反证所攻击之主张前提的证据出处类型,不是
     反证内容的主题词。判法:问『原主张凭什么为真?』——答所依赖的证据类型
     即维度。interview_reversal 是机制维度:凡证据出自访谈/纪要/口头口径,
     无论其内容谈的是定价、成本还是监管,一律填 interview_reversal。」
3. **丙的处置**:不新建机制——黄卡+人审(ADR-0011 子决策 8)登记为生产侧
   误伤吸收层;依赖 #23 续命闭环建成生效,排序登记,不在本单实装。
4. **验收判据(#33,判定人触发,pre-registered,事后改 = 作废)**:

     附表只登记;must_unknown 不跑(同 #26/#30 口径);
   - 采样:n=3、temp=0、qwen-flash 显式锁定、版本当场登记;冒烟读数框定,
     不报方差(清单 #2/#3 继承);
   - 归因登记:拦截落 error_code 区分机械(`DIMENSION_CROSSCHECK_MISMATCH`)

- **反直觉?** 存在(「为什么不修词表而要改提示」)但可由本评估 §3/§6 承担,
  不需要 ADR 级别的留档义务。
- **真实取舍?** 存在(模型侧规格 vs 词表重构 vs 人审税),同上。
- 结论:三条件不齐,不记;红线入档(子决策 6),ADR-0011 后果条款本就覆盖
  「动不变量 8 须走新评审」。

## §6 面试讲法(grilling 预案)

**Q:c3 误伤的根因到底是什么?**
A:不是模型噪声,是**欠定义枚举**。六枚举的真实语义是「主张前提的证据出处」
(premise provenance):c3 的前提住在访谈纪要里 → interview_reversal;c5 的
前提住在成本模型里 → cost_model。词表本身自洽,但模型侧 schema 描述只有六个
裸词、零定义,模型只能按主题显著性选标签——c3 反证内容是「30% 收入分成」,
主题撞 cost_model,temp=0 下 3/3 一致误标,是确定性系统偏置。通用教训:
**任何模型消费的枚举都是规格,必须逐值带定义**——枚举词表只给值不给定义,
等于把语义解释权留给模型的主题直觉。

**Q:为什么不双人标注对账(乙)?**
A:两个变体各有实锤死因。转语义层:#30 运行里 Auditor 对 c5/c6 同样
dimension_match=true(#26 同错的延续),降级 = 拦截线当场破。双填对账:
同端点 temp=0 下系统性误标两侧恒一致——它抓随机分歧,而这里根本没有随机
分歧;**agreement ≠ verification**,两个同分布样本的一致会被洗成虚假信心。
要独立性就得换分布(异源端点),那是 #28 已登记的未论证候选,不在这里复活。

**Q:为什么不在闸侧豁免——机器层有效的反证免跨检(戊)?**
A:能区分误伤与正确拦截的信号是「反证是否锚定金标段落」,那是评测仪器,
生产闸没有金标。生产闸可机械检查的只有「证据 id 可点回」,而 c3 与 c5/c6
的反证 id 都是真实 T1 片段——**无区分度**。豁免等于拆不变量 8,还违反闸
零语义定位,三重不合法。

**Q:验收怎么防「修复只是让闸碰巧松了」?**
A:两层验收。e2e 三线看判决(c3 恢复 3/3 / c1/c2/c7 回归 / c5/c6 拦截
≥4/6);**标注器探针**直接测标注层——12 条合成反证片段、六枚举各 2、必含
c3 型机制-主题分离样本,隔离标注不过闸,0/12 误标才过。端到端绿掩盖不了
标注层未愈,这正是 #21「结构断言全绿 ≠ 行为生效」的同款假信心的解药。

**Q:为什么不顺手把词表拆成主题+机制两个正交字段(己)?**
A:词表在前提出处语义下是自洽的,缺的是文档不是结构——用大锤砸文档缺失,
还要动签发 schema、作废 12 条回填、碰金标邻近语义。而且**重构不许当预登记
逃生舱**:若登记成「甲失败后的下一档」,止损条款名存实亡。它永远走新
grilling 全量重开(含回填复核),不计入机器防线重试额度——改规格不是加防线。

**Q:这次改动为什么不记 ADR?**
A:三条件不齐。措辞消歧在 ADR-0011 §2 已钉语义的包络内(「反证自身攻击的
维度」原文未动,动的是消歧),改起来便宜,且不破坏任何已跑实验的意义——
#30 判据判读一字未动,#33 独立预登记。红线已入档:改字段语义、放宽不变量 8、
让登记维度对模型可见 = 修改 ADR-0011,必须走新评审。

**Q:误伤由人审吸收,是不是放行权旁落给人?**
A:不是。黄卡落点是 unknown 不是 fresh,零绿灯;人审看到的是纯结构事实
(登记维度 vs 自标维度,零模型意见污染);判断权本就在人——HumanLatch 是
产品的核心闭环(ADR-0006)。闸与 Auditor 依然无放行权,一个都没有多。

**Q:探针的 0/12 是不是又拿小样本拍板?**
A:冒烟读数,继承 #19/#25 的框定:判的是「标注器在这个端点上是否还存在
系统性误标」这一存在性问题,不是误标率的统计估计。temp=0 下 12 条跨六枚举、
含对抗性分离样本,足够暴露「机制-主题混淆」级别的系统性偏置(c3 的 3/3
就是这么读出来的)。要误标率的点估计是 W12 复盘的采样设计议题,已在地图
Fog 登记。
