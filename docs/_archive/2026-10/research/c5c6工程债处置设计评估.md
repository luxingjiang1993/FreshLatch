## §6 面试讲法(grilling 预案)

**Q:W4 已经验收通过了,c5/c6 又不是违例级,为什么还要开一张工单修?**
A:验收数学上确实能过——预登记止损线的价值正在于让「过与不过」不依赖事后解释。但 grilling
查实这不是「模型偶尔犯错」,是工程缺口:c5 二修落盘的教义表根本没接线,模型运行时从未见过
任何一条维度铁律,自主 mark_stale 路径三重硬校验里没有一条与维度有关。把「文件在盘」当
「约束在场」是最危险的一类假信心——结构断言全绿不等于行为生效,c5 二修自己就是这个教训。

**Q:为什么不直接在人格里把铁律写得更狠?**
A:修错了层。事故不是「铁律不够狠」,是「铁律到不了模型」。在内联 prompt 上加码还会制造
双拷贝漂移,且 prompt 越长关键约束越被稀释。所以拍板是接线为主、人格只留一句指向——
单一真相在教义表文件,内联不复制。

**Q:注入了核对指令,是不是就是把维度校验做成了机器闸?**
A:不是,分工很明确:注入保证「核对指令每回合在场」,这是结构问题;维度对不对是语义判断,
机器不判——机器闸③(硬判维度)在本工单和 c5 二修里被否了两次,理由相同:只能拦已见案例,
给假安全感。规则闸管不变量,人格管语义质量,这条边界没动。

**Q:通过线 2/3、5/6 是不是为了让修复容易过?**
A:初版确实是拍脑袋值,被 Anthropic 清单(容忍度须实证依据,否则是 HARKing 软形态)打回重拟。
重拟依据是实测数据:同一端点 temp=0 下 c9 三次运行翻了一次,单跑翻转基率约 1/3——在这个
基率下要求 3/3 会纯因端点抖动误杀,2/3 单条容差 + 5/6 总线防「单条恒翻被吸收」。线没变,
依据补实了。这也是 pre-registration 纪律要求的形态:判据先于结果写死,依据公开可复核。

**Q:三层一起改,归因怎么办?**
A:诚实框定:层间归因只靠单测(每层独立可断言),行为层只验 bundle——不声称 bundle 跑绿等于
每层行为生效。而且基线免费:W4 三跑就是修复前基线,修复后同口径 delta 直接兼作 c6「提示词

**Q:加新干扰项为什么不进判分矩阵?**
A:判分口径是 W4 判据锁定在 W12 的延伸,动它 W4↔W12 就不再同尺,而复述测试共用的恰恰是
「同仪器可比」这条命根子。新干扰项的使命是证明修复对未见混淆类型(客单价≠毛利、覆盖率≠
