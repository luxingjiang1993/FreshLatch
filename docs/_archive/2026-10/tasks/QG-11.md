### G1 stdout（只此一种）

一条，不拆拒绝率与放行率：

`metric id=G1-should-refuse-accuracy status=TBD value=<VALUE> baseline=none n=<N> scored=<S> correct=<C> unresolved=<U> n_should_refuse=<NR> n_should_pass=<NP> source=gold-bucket-agreement counted_as_pass=false`

`n_should_refuse` / `n_should_pass` 是 keep 条上 `label` 的计数，不是率，以后不得升成地板。

预测不得读 `label`，也不得读 `policy_id`（`policy_id` 是草稿时从分桶抄来的）。期望标签只来自 `data/eval/gold.json` 的分桶，对上 `source_refs` 里的主张 id：

- id 落在 `must_stale` 或 `must_unknown` → 期望 `should_refuse`
- id 落在 `must_fresh` → 期望 `should_pass`
- 没有命中，或命中了两个不同桶 → 该条不算 scored
- `must_fresh_distractor` 不算期望桶

`correct` = scored 条里 `label` 等于期望标签的条数。`value` = `correct / scored`。

这是正式文件相对 `gold.json` 三档的一致性描述，不是模型拒绝率，也不是 `tests/eval/test_gold_gate.py` 的 CI 机械闸。离线闸没有冻结的 refuse 回放。禁止调用 LLM 现编一个拒绝率。QG-12 必须把这句写进 RESULT。实现者不得再报第二个百分数。

### A1

两条，名字用代码里已有的 citation recall 与 citation precision。不写 Faithfulness 公式。

支撑集 `R` = 来源题在 `data/exp/x1/questions.json` 上的 `relevant`（id 字符串精确匹配，与 `recall_at_k` 相同）。`C` = 该条 `cited_ids`。`distractors` 不是支撑集。来源题 = `source_refs` 里第一个能对上题集 `id` 的引用。

- citation recall：`scored` = 对上来源题且 `|R|>0` 的 keep 条。`value` = `sum(|C ∩ R|) / sum(|R|)`
- citation precision：`scored` = 对上来源题且 `|C|>0` 的 keep 条。`value` = `sum(|C ∩ R|) / sum(|C|)`。空 `cited_ids` 不进 precision 分母，避免把 miss_cite 除零补成 1

```
metric id=A1-citation-recall status=TBD value=<VALUE> baseline=none n=<N> scored=<S> unresolved=<U> source=cited-vs-relevant counted_as_pass=false
metric id=A1-citation-precision status=TBD value=<VALUE> baseline=none n=<N> scored=<S> unresolved=<U> source=cited-vs-relevant counted_as_pass=false
```

这是正式引用行对题集 `relevant` 的集合重叠，不是生成式引用，不是 PE-Y 的 false-accept。

`correct` = scored 条里 `conflict_pair_correct` 为真的条数。`value` = `correct / scored`。

```
metric id=T1-new-over-old-accuracy status=TBD value=<VALUE> baseline=none n=<N> scored=<S> correct=<C> unresolved=<U> source=frozen-per-query-replay counted_as_pass=false
```
