# P1 QuoteTTL 薄（synthetic）

本目录是 FreshLatch 第二课题包的平行合成材料，**synthetic / 合成评测材料**，不是真实供应商报价，不是 QuoteTTL 产品表面。

- 问题句：9 月 1 日供应商报价是否仍可在 9 月 18 日转报客户？
- 主张为 claim 级（交期口径、单价、运费确认），映射进既有六维。
- 本包默认**未释放**。C4 卡在仓不等于数据集已对外可用。推进 main 不等于已释放。
- 本包不是「多垂类已 Port」，软 Port 过不等于产品已验证。

装载：`FRESHLATCH_ACTIVE_PACK=p1-quotettl`。未设置环境变量时默认包仍是第一课题 `thesis-1`。
